AI 생성 요약
JetPack 7.2.1은 agentic video skills와 통합 jetson-
videosdk를 도입했다. 개발자의 의도를 실제 디바이스 탐색,
지원되는 구성, 재현 가능한 실행, 성능 검증에 연결함으로써
Video Codec SDK와 PyNvVideoCodec 위에서 프로그래
밍 가능하고 디바이스를 인식하는 video workflow를 구현
한다.
Jetson의 PyNvVideoCodec 2.2 지원은 CUDA device
buffer와 DLPack을 활용해 Python 기반 hardware-
accelerated video encoding 및 decoding을 제공한다.
multi-mode frame sampling과 ThreadedDecoder로
pipeline 효율성을 최적화하고 decode latency를
inference와 분리한다.
JetPack 7.2.1은 Jetson Thor AGX Developer Kit에서
Jetson T5000을 사용해 Jetson T3000 성능을 에뮬레이션
할 수 있게 한다. 이를 통해 전력 효율이 높고 고성능인 AI
video pipeline 개발을 빠르게 시작할 수 있으며, 향후 기반
skills 계층은 더 광범위한 end-to-end 애플리케이션 지원으
로 확장될 예정이다.
AI 생성 콘텐츠는 정보를 불완전하게 요약할 수 있다. 중요한 정보는 확인해
야 한다.
본문
Video는 robotics와 지능형 video analytics부터 산업 자동화,
의료, 미디어 처리, 원격 작업에 이르기까지 NVIDIA Jetson 애
플리케이션 전반의 핵심 데이터 경로이다. 시스템은 여러 카메라
에서 영상을 캡처하고, 네트워크 스트림을 decode하고, AI
inference 또는 기존 vision 처리를 실행하고, 결과를 그린 다음,
저장하거나 전송할 video를 encode할 수 있다.
개별 호출 자체는 간단하다. 엔지니어링 작업의 핵심은 Jetson
디바이스에 적합한 interface, codec, pixel format, memory
path, rate control, buffering을 선택하고, 전체 경로가
latency, throughput, 품질 목표를 충족한다는 사실을 입증하
는 데 있다.
NVIDIA JetPack 7.1은 Jetson Thor에서 NVIDIA Video
Codec SDK 지원을 도입하여 C 및 C++ 개발자가 NVIDIA
Video Encoder(NVENC)와 NVIDIA Video Decoder(NVDEC)
에 직접 세밀하게 접근할 수 있게 했다.
JetPack 7.2.1은 Jetson 최초로 PyNvVideoCodec 2.2 지원을
추가한다. PyNvVideoCodec은 NVIDIA GPU에서 hardware-
accelerated video encoding 및 decoding을 제공하는
NVIDIA 
Python 
라이브러리이다. 
PyNvVideoCodec은
DLPack 프로토콜과 CUDA device buffer를 통해 노출되는
GPU 상주 device memory 형태로 video frame을 생성하고
소비한다. 
또한 
multi-mode 
frame 
sampling과
ThreadedDecoder처럼 AI pipeline에 적합한 기능을 포함한
다. ThreadedDecoder는 background thread에서 frame을
미리 decode하여 pipeline 효율성을 높이고, decode latency
와 inference latency를 분리한다.
JetPack 7.2.1은 이러한 SDK 위에 기반 agentic video skills
도 제공한다. SDK는 프로그래밍 가능한 video primitive를 제
공하며, skills는 개발자의 목표를 실제 디바이스 탐색, 지원되는
구성, 작동하는 recipe, 실행, 측정, 재현 가능한 증거와 연결한
다. 이들은 함께 Jetson에서 open model 및 agent 개발을 가
속하고, 어디서나 모든 개발자가 프론티어급 AI 성능을 활용할 수
있게 한다.

Prompt에서 검증된 pipeline까지
“이 Jetson은 low-latency 사용 사례에서 H.264 1080p30 스
트림을 몇 개나 실행할 수 있는가?”와 같은 prompt에는 코드 생
성이나 data sheet의 한계 값만으로 답할 수 없다. 답은 설치된
software, 대상 디바이스에서 실제로 작동하는 codec 기능,
memory path, 그리고 latency와 throughput을 입증하는 통
제된 실행 결과에 따라 달라진다.
Jetson video skills는 이러한 의도를 반복 가능한 codec
workflow로 전환한다. 즉, 대상 디바이스를 검사하고, 지원되는
Video Codec SDK 또는 PyNvVideoCodec 경로를 선택하고,
테스트된 구성을 생성하고, 이를 실행한 다음, 경고 및 증거와 함
께 측정 결과를 반환한다.
Jetson video skills는 NVENC 및 NVDEC hardware engine
을 사용하는 Video Codec SDK와 PyNvVideoCodec 위에
agentic workflow 계층을 제공한다.

Jetson video workflow를 위한 기반 skills
JetPack 7.2.1은 통합 jetson-videosdk skill을 통해 기반
video workflow를 도입한다. 개발자는 각 workflow를 독립적
으로 호출하거나, 더 광범위한 pipeline 안에서 codec stage를
구성하고 검증하도록 이들을 조합할 수 있다. 향후 release에서
는 Jetson 개발자 workflow 전반에 추가 skills를 제공하여 이
기반을 확장할 예정이다.
1. 탐색, 설정 및 기능 보고: Jetson 플랫폼과 설치된 software
를 식별하고, 지원되는 설정 과정을 안내하며, 실제 대상 디바
이스에서 encode 및 decode codec, format, memory
path, session 기능을 조회한다.
2. Encoder recipe 생성: low latency, 일정한 품질, 제한된
bitrate, resolution, frame rate, codec 선택과 같은 목표
를 명시적 설정 및 실행 가능한 Video Codec SDK 또는
PyNvVideoCodec 경로로 변환한다.
3. 성능 및 품질 benchmark: throughput, latency,
utilization, bitrate, 출력 품질에 대해 반복 가능한 측정을
실행한다.
4. Codec workflow 검증: 설정, recipe 선택, encode 또는
decode, 측정, artifact 전달을 연결한 다음, 결과를 재현하
는 데 필요한 구성, 결과, 경고, 증거를 반환한다.
Skills가 SDK 위에 추가하는 가치
SDK는 가속된 video primitive를 제공하며, skills는 디바이스
를 인식하는 구성 및 검증 기능을 추가한다. Skills는 명시된 기능
과 대상 디바이스에서 실제로 성공하는 작업을 구분하고, 재현성
을 위해 recipe, 입력, 출력, 측정 결과를 보존한다.
PyNvVideoCodec과 Jetson video skills로 AI video pipeline 구축
“이 video를 decode하고, 내가 지정한 AI 또는 computer
vision 처리를 적용한 다음, codec stage가 내 성능 목표를 충족
하는지 검증하라”라는 prompt를 생각해 볼 수 있다. Coding
assistant는 Jetson video skill을 사용하여 PyNvVideoCodec
을 구성하고 검증하며, PyNvVideoCodec과 함께 제공되는
sample application은 reference application scaffold를 제
공한다.
1단계: 검사 및 구성. Coding assistant는 skill을 호출하여
Jetson 플랫폼, software, codec 기능을 검증한 다음
decoder, 출력 format, memory path, buffering을 선택한다.

2단계: Framework data로 decode. PyNvVideoCodec
sample은 background thread에서 frame을 준비하고, 애플
리케이션별 codec buffer 코드 없이 각 frame을 framework
tensor에 전달할 수 있다.
3단계: 애플리케이션 flow 완성. Codec stage를 구성한 후
coding assistant는 prompt가 요구하는 stage를 sample
application에 추가할 수 있다. 예를 들어 preprocessing,
detection 또는 classification, blurring과 같은 privacy
filtering, visualization, 출력 처리를 추가할 수 있다. 정확한 AI
또는 computer vision model과 애플리케이션 logic은 개발자
가 선택한다.
4단계: 측정 및 검증. Skill은 codec 구성을 기록하고 실행 상태,
throughput, latency, utilization, 경고, 증거를 검증한다.
그림 1. Jetson video skills는 PyNvVideoCodec stage를 구성하고 검증하며, coding assistant는 개발자의 prompt에 필요한 AI, computer vision
및 애플리케이션 stage를 추가한다.
범위 참고: JetPack 7.2.1 video skills의 범위에는 Video
Codec SDK와 PyNvVideoCodec이 포함된다. 이번
release에서는 GStreamer, V4L2, AI model 또는 애플리
케이션 수준의 pipeline 구축 skills를 추가하지 않는다. 이
skills는 codec stage에서 coding assistant를 보완한다.
향후 release에서 제공될 추가 Jetson skills를 이들과 조
합하면 더 광범위한 end-to-end 애플리케이션을 지원할
수 있다.
각 pipeline stage에 적합한 Jetson video interface 선택
Jetson은 상호 보완적인 software 계층을 통해 video 기능을
제공한다. GStreamer는 high-level pipeline 조합을 제공하고,
V4L2는 Linux video device 및 buffer 제어를 제공하며,
Video Codec SDK는 NVENC와 NVDEC에 대한 lower-level
C/C++ 접근을 제공한다. PyNvVideoCodec은 핵심 Video
Codec SDK API를 기반으로 더 간단한 Python interface를 제
공한다. Workflow가 capture, codec, AI, 전송 stage를 가로지
르는 경우 이러한 계층을 조합할 수 있다.

JetPack 7.2.1은 이 모든 기능을 통해 의도에서 증거로 이어지는
더 명확한 경로를 개발자에게 제공한다. 적절한 Linux, C/C++ 또
는 Python interface를 선택하고, 가속된 데이터를 GPU 가까이
에 유지하며, 기반 video skills를 사용하여 Video Codec SDK

또는 PyNvVideoCodec stage를 구성하고 검증할 수 있다. 이
기반은 현재 coding assistant를 보완하며, 향후 release에서
추가 Jetson skills와 조합되어 더 광범위한 end-to-end 애플리
케이션을 지원할 수 있다.
JetPack 7.2.1을 사용하여 Jetson T5000에서 Jetson T3000 성능 에뮬
레이션
Jetson T3000은 humanoid 및 robotics workload를 위한 컴
팩트하고 전력 효율이 높은 플랫폼에서 865 FP4 TFLOPS를 제
공한다. 이 제품은 multimodal AI에서 T5000에 준하는
inference 성능을 제공하면서 footprint, 전력 소비, 비용을 줄
인다. 이제 JetPack 7.2.1을 사용하면 Jetson Thor AGX
Developer Kit의 Jetson T5000 module에서 최근 발표된
T3000 성능을 에뮬레이션하여 개발을 빠르게 시작할 수 있다. 에
뮬레이션 구현에 대한 자세한 내용은 Jetson Linux Developer
Guide에서 확인할 수 있다.
