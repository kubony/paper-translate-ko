6.8 MoE 설계: Dense 모델과의 비교

아키텍처 비교를 동등한 조건에서 수행하기 위해, decoder 수준의 Mixture-of-Experts 모델(이하 MoE-Decoder)을 parameter 수가 유사한 dense baseline과 비교한다. 두 모델은 동일한 encoder backbone을 공유하며 reward-prediction head만 다르다. 이 head는 차원이 (N + 3)d = 3072인 fused feature vector에 timestep마다 한 번 적용되며, 여기서 N = 3개의 camera stream과 language, task 및 state token을 합하면 길이 T인 modality stream이 (N + 3) = 6개가 된다. Dense baseline은 width 512인 3-hidden-layer MLP를 사용하여 scalar reward를 계산한다. MoE-Decoder variant는 이 MLP를 E개의 deep expert로 구성된 sparse top-k mixture로 대체하며, 각 expert 자체는 width 256인 3-hidden-layer MLP이고 동일한 fused vector에 적용된다. MoE는 timestep마다 E = 10개의 expert 중 k = 2개만 활성화하므로, 적절한 비교 대상은 total parameter 수가 아니라 activated parameter 수이다. 이 configuration에서 MoE-Decoder는 activated parameter와 FLOPs 모두에서 Dense baseline과 약 10% 이내로 일치하므로(표 5 및 6), quality 차이는 capacity 또는 compute 여유가 아니라 sparse routing structure에 기인한다.

6.9 MoE 설정 Ablation 연구

Default configuration인 T2E10은 가장 우수한 overall demo loss(0.020)와 가장 높은 T1 rollout success(0.833)를 달성하며, 이는 E = 10개의 expert에 대해 k = 2를 사용하는 설정이 이 sweep 내에서 사실상 optimum에 도달함을 보여준다. Multi-gate 설계와 load-balance auxiliary loss 덕분에 모든 variant는 유의미한 load score(0.02–0.20)를 유지하고 routing collapse를 피하므로, 관찰된 차이는 degenerate gating이 아니라 specialization quality를 반영한다. 실험적으로 top-k를 변경하는 경우(T1E10: 0.026, T4E10: 0.029), expert 수를 변경하는 것보다 overall demo loss가 더 크게 저하된다.
