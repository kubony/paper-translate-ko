한 그룹 내의 primitive들은 유사한 progress signature를 나타내므로 동일한 gate의 routing distribution을 공유하는 것이 타당하다. 표 4에는 그 결과로 얻은 그룹, 각 그룹에 속하는 primitive, 그리고 각 그룹이 포착하는 motion pattern에 대한 간략한 설명을 제시한다.

표 4: Multi-gate MoE decoder를 위한 action-primitive 그룹화. 공유된 시각적·motion 특성에 따라 K + 1 = 22개의 primitive를 M + 1 = 8개의 semantic group으로 clustering한다. 각 그룹은 MMoE decoder의 gate 하나에 mapping되며 expert pool은 공유된다. Other는 정의되지 않았거나 task-specific인 action을 포괄하는 범주이다.
그룹명 Action primitive 설명
획득(Acquire) 퍼내기(scoop), 당기기(pull), 집기/잡기(pick/grab) 대상 object를 초기 support surface에서 들어 올리거나 이동하여 robot이 제어할 수 있는 상태로 만든다.
해제(Release) 놓기(place), 붓기/쏟기(pour/dump) 제어 중인 object를 아래로 이동하여 목표 위치, container 또는 support surface에 둔다.
병진(Translate) 지우기(erase), 지퍼 열기/닫기(zip/unzip), 쓸기(sweep), 건네기(pass) end-effector 또는 object를 주로 선형인 trajectory를 따라 이동한다.
삽입(Insert) 설치하기(install), 삽입하기(insert) spatial alignment를 유지하면서 object를 제약된 목표 영역 안으로 유도한다.
의류 형태 조정(Shape Clothes) 걸기(hang), 접기/평평하게 펴기(fold/flatten) 천과 유사한 object를 원하는 geometric state 또는 arrangement로 재구성한다.
회전(Rotate) 감싸기(wrap), 말기(roll), 묶기/풀기(tie/untie), 회전하기/돌리기(rotate/turn) angular motion을 통해 object의 orientation 또는 configuration을 변경한다.
힘(Force) 고정하기(clamp), 누르기(press) gripper 또는 end-effector를 통해 제어된 contact force를 가한다.
기타(Other) 더미(dummy) 주요 primitive taxonomy에 포함되지 않는, 정의되지 않았거나 task-specific인 action을 나타낸다.

6.5 보상 유도 로봇 자기 개선 루프의 Algorithm

Algorithm 1 보상 유도 로봇 자기 개선 루프

입력: 인간 demonstration Ddemo; pretrained VLA model πVLA; pretrained multi-task reward model RM1; reward-model pretraining set DRM; 최대 iteration 수 N

출력: 개선된 policy πN+1

1:// Stage 1: Behavior cloning
2:π1 ← FINETUNE(πVLA, Ddemo) ▷ 지도 BC fine-tuning

7:RM2 ← FINETUNE(RM1, Dadapt) ▷ pretraining cost의 약 1/10
8:// Stage 2b: Pretrained reward model을 사용한 초기 residual RL
9:D̃demo ← LABELREWARDS(Ddemo, RM1)
10:π2 ← SPIRAL(π1, D̃demo)
11:R2 ← ROLLOUT(π2, n=100)
12:// Stage 4: On-policy self-improvement loop
13:for i = 2, 3, ..., N do
14:R̃i ← LABELREWARDS(Ri, RM2)
15:πi+1 ← SPIRAL(πi, R̃i)
16:Ri+1 ← ROLLOUT(πi+1, n=100)
17:if SUCCESSRATE(Ri+1) ≥ τsuccess then
18:break
19:end if
20:end for
21:return πi+1
