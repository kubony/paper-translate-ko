초록

효율성과 시간적 일관성을 높이기 위해 Vision-Language-Action(VLA) 모델은 흔히 action chunk를 예측한다. 그러나 이러한 action chunking은 inference delay와 긴 horizon에서 반응성을 해친다. 본 연구는 매 control step마다 실행되며 어떤 기성 VLA의 action chunk에도 시간 인지형 보정을 더하는 경량 실시간 chunk correction head인 Asynchronous Action Chunk Correction(A2C2)을 제안한다. 이 모듈은 최신 observation, VLA가 예측한 action(base action), chunk 내 base action의 index를 encoding하는 positional feature, 그리고 base policy의 일부 feature를 결합하여 step별 보정을 출력한다. 이를 통해 base model의 역량을 보존하면서 closed-loop 반응성을 회복한다. 이 접근법은 base policy의 재학습이 필요하지 않으며 Real Time Chunking(RTC) 같은 asynchronous execution 방식과 직교한다. 동적인 Kinetix task suite(12개 task)와 LIBERO Spatial에서 본 방법은 delay와 execution horizon이 증가해도 RTC보다 각각 +23%p와 +7%p 높은 일관된 success rate 향상을 보이며, 인위적으로 주입한 delay가 0인 경우에도 긴 horizon에 대한 강건성을 높인다. correction head는 작고 빠르므로 대형 VLA 모델의 inference와 비교한 overhead가 미미하다. 이 결과는 A2C2가 고용량 chunking policy를 실시간 제어에 배치하기 위한 효과적인 plug-in 메커니즘임을 보여준다.

1. 서론

대형 vision–language–action(VLA) 모델의 최근 발전은 robot이 task와 environment 전반으로 generalize하는 능력을 크게 확장했다. 그러나 큰 모델 크기는 각 step의 action을 출력하는 데 높은 계산 비용을 요구하고, 이는 높은 inference latency로 이어진다. 특히 동적 제어에서는 이러한 delay가 치명적이다. 오래된 observation에서 예측된 긴 action sequence에 의존하는 robot은 궤도에서 벗어나거나 단서를 놓칠 수 있으며, 움직이는 물체를 잡거나 불안정한 system을 안정화하는 것처럼 빠른 반응이 필요한 task에서 실패할 수 있다.

foundation model을 사용해 neural network policy를 scale up하는 추세는 표현상의 이점을 제공하지만 latency 문제도 초래한다. 예를 들어 π₀나 OpenVLA 같은 대형 VLA는 수십억 개 parameter를 가지며 하나의 action chunk를 생성하는 데 흔히 수백 ms가 필요하다. 이 action chunk는 오직 이전 observation에서 예측된 뒤, 실행 중 새로운 sensory input을 반영하지 않은 채 open-loop 방식으로 실행된다. 또한 latency는 실행을 지연할 뿐 아니라 policy가 최신 observation을 반영하지 못하게 하여 반응 행동을 생성하는 능력을 약화한다. 이는 inference 도중 environment가 빠르게 변하는 task에서 특히 문제다. 예를 들어 복잡한 table 위의 움직이는 물체를 따라가거나 다른 물체가 놓이는 동안 utensil을 grasp할 때 robot은 새로운 sensory input에 맞추어 action sequence를 조정해야 한다. 이런 상황에서 오래된 observation으로 계산한 action은 시간에 따라 error를 누적하여 success rate를 낮추며, 때로는 task failure로 이어진다. 이것이 본 연구가 다루는 핵심 과제다.

전통적 접근은 action chunking으로 대형 모델의 latency를 완화하려 한다. 긴 action sequence를 한 번에 예측하면 비용이 큰 inference call의 빈도를 줄일 수 있다. 그러나 chunking 전략은 성능에 영향을 줄 수 있다. robot은 inference 동안 대기 시간을 겪을 수 있고 연속 chunk 사이에 불일치가 생길 수 있다. 이를 해결하기 위해 SmolVLA는 policy의 synchronous execution을 도입하고, RTC는 diffusion 기반 action 생성에서 asynchrony하의 chunk 간 연속성을 더 매끄럽게 보장한다. 그러나 이들 방법도 여전히 모델이 고정 길이 horizon을 예측한다고 가정하므로 새로운 sensory input에 대한 반응성은 제한된다.

또 다른 연구 흐름은 dual-system reasoning에서 영감을 얻은 hierarchical architecture를 채택한다. 대형 모델은 high-level planner(System 2), 작은 policy는 빠른 executor(System 1) 역할을 한다. 예로 high level의 VLM과 low level의 VLA를 결합하는 Hi Robot, compact policy로 continuous action chunk를 정제하는 GR00T-N1이 있다. 그러나 low-level executor가 high-level model의 예측을 기다려야 하므로 latency는 여전히 남는다. 따라서 chunking과 hierarchical 접근은 일부 문제를 완화하지만, parameter가 많은 VLA에 내재된 inference delay 아래에서 새 observation에 대한 반응성을 유지하는 과제를 근본적으로 해결하지 못한다.

이를 완화하기 위해 본 논문은 대형 VLA의 출력을 보완하도록 매 timestep 실행할 수 있는 경량 correction head인 Asynchronous Action Chunk Correction(A2C2)을 제안한다. action chunking이나 asynchronous inference 같은 기존 방식과 달리, 본 방법은 high-level model이 출력한 action chunk를 참조하면서 가장 최근 observation을 직접 통합하는 lower-level correction layer를 도입한다. 이 correction head는 diffusion 또는 VLA 기반 chunk generator 같은 base(high-level) policy와 경쟁하지 않고, inference delay와 긴 horizon에서도 반응성을 유지하도록 실시간 feedback을 주입해 이들을 강화한다. 이 설계로 제안 framework는 동적인 environment 변화와 외부 disturbance에 강건하며, 대규모 VLA를 실시간 robot control에 배치할 때의 핵심 latency bottleneck을 완화한다.

Kinetix 실험에서 delay가 존재할 때 naive execution보다 success rate가 35%p, RTC보다 23%p 높았다. 긴 execution horizon에서는 naive execution보다 12%p, RTC보다 7%p 높았다.

본 연구의 기여는 다음과 같다.

  • action chunk를 생성하는 VLA의 policy inference delay를 최초로 정식화한다.
  • underlying architecture와 무관하게 어떤 VLA에도 적용 가능한 경량 add-on action correction policy인 A2C2을 도입해 반응성을 높인다.
  • 다양한 inference delay를 둔 dynamic task와 robot manipulation benchmark에서 success rate가 크게 향상됨을 보인다.

2. 문제 정식화

imitation learning(IL) policy를 사용하는 action chunk execution을 고려한다. 그림 1처럼 IL policy π는 observation oₜ와 language instruction l에 근거해 action chunk Aₜ={aₜ,…,aₜ₊H₋₁}를 생성한다. H는 horizon length, 즉 IL model π의 training sequence length다. action chunk 중 e step을 사용한다고 가정하고 이를 execution horizon이라 정의한다. Policy는 매 e step마다 다음처럼 action chunk를 예측한다.

Aₜ = {aₜ, …, aₜ₊H₋₁} = π(oₜ, l).                                      (1)

또한 inference latency가 존재한다. observation oₜ를 받은 시점부터 대응 action chunk Aₜ를 얻는 시점까지의 control step 수를 delay d로 정의한다. 형식적으로 다음과 같이 계산한다.

d = ⌊δ / Δt⌋,                                                        (2)

여기서 δ는 inference와 communication time의 합이며 Δt는 control step 하나의 duration이다.

delay가 있는 chunked action execution을 제어하기 위해 agent는 새 chunk가 asynchronously 도착할 때까지 step마다 action 하나를 실행한다. 또한 policy server는 한 번에 하나의 inference만 처리할 수 있다고 가정한다. execution horizon e가 delay d보다 짧으면 model inference 동안 실행할 action이 없어 대기 시간이 생긴다. 반대로 e가 H−d보다 길면 inference 시간 동안 남은 action이 없다. 따라서 e는 d 이상이고 H−d 이하여야 한다(d ≤ e ≤ H−d).

이 설정에서 agent는 항상 과거 observation에 근거한 action을 사용해야 한다. 실행되는 각 action은 적어도 d step 전 observation에 대응한다. 최악의 경우 agent는 d+e step 전 observation에서 생성된 action을 실행해야 할 수 있다.

3. 방법

3.1 개요

action chunk 기반 policy π에 Asynchronous Action Chunking Correction(A2C2)을 확장하여, 가장 최근 observation, base policy feature, temporal position feature로 예측 chunk 내 각 action을 정제하는 경량 correction head πa2c2를 도입한다. 이 framework는 base policy를 재학습하지 않고 step별 online correction을 가능하게 하며 RTC와 상호 보완적이다.

시간 t에 observation oₜ를 policy server로 보낸다. base policy π는 inference delay d 안에 다음 action chunk를 생성한다.

Aₜ = {aᵇᵃˢᵉₜ, …, aᵇᵃˢᵉₜ₊H₋₁} = π(oₜ, l).                           (3)

그 뒤 시간 t+k(d ≤ k ≤ d+e)에 time feature τₖ, base action aₜ₊ₖ, 최신 observation oₜ₊ₖ, base policy의 최신 representation zₜ, language instruction l을 correction head πa2c2에 넣는다. positional feature τₖ는 chunk length에 걸친 주기 구조를 제공하는 sinusoidal embedding, 즉 (sin(2πk/H), cos(2πk/H))로 표현한다. correction head는 이 정보를 통합하여 residual action을 예측한다.

Δaₜ₊ₖ = πₐ₂꜀₂(oₜ₊ₖ, aᵇᵃˢᵉₜ₊ₖ, τₖ, zₜ₊ₖ, l).                       (4)

residual action Δaₜ₊ₖ를 base action에 더해 environment에서 실행할 action을 출력한다.

aᵉˣᵉᶜₜ₊ₖ = aᵇᵃˢᵉₜ₊ₖ + Δaₜ₊ₖ.                                      (5)

Base policy π는 d delay를 두고 매 e step마다 action chunk를 inference한다. 반면 correction head πa2c2는 매 step 실행할 만큼 작고, head의 inference time은 control step duration Δt보다 작다고 가정한다. 전체 개요는 그림 2와 같다.

본 방법은 기존 asynchronous inference 방식과 다음 측면에서 다르다.

  • Time-aware correction: correction head는 temporal feature를 통해 action-chunking VLA의 chunk 내 위치를 명시적으로 조건화한다.
  • Chunk-level smoothness: chunk의 어느 원소를 보정하는지 지정하여 horizon 전반에서 더 매끄러운 보정을 만든다.
  • Data compatibility: base VLA policy와 같은 demonstration dataset으로 학습하므로 reinforcement learning fine-tuning이 필요 없다.
  • Real-time feedback: 항상 새 observation을 반영하여 dynamic task의 inference delay 아래에서 강건성을 높인다.

3.2 모델 학습 절차

먼저 다음 dataset으로 base policy π를 학습한다.

D_base = {{{oₜ, aₜ}ₜ₌₀…Tₙⁿ, lⁿ}ₙ₌₁…N},                            (6)

여기서 N은 dataset의 episode 수다. 이후 D_base의 각 step에 base policy π의 inference output action chunk Âₜ를 추가한다.

Âₜ = {âₜ, …, âₜ₊H₋₁} = π(oₜ, l).                                    (7)

이 inference 결과로 correction head training을 위한 새 dataset을 만든다.

D_cor = {{{oₜ, aₜ, âᵏₜ₋ₖ, τₖ}ₜ₌₀…T₀, 0≤k≤min(t,H−1)ⁿ, lⁿ}ₙ₌₁…N}.   (8)

âᵏₜ₋ₖ는 시간 t−k의 observation에서 base policy가 inference한 action chunk의 k번째 action이다. 이어 correction head πa2c2를 target action과 base policy output의 차이인 residual action을 예측하도록 학습한다. target action은 expert demonstration에서 원래 수집된 dataset의 action이다. target action과 base policy output이 주어졌을 때 residual target은 다음과 같다.

Δa_residual = a − â.                                                  (9)

â는 base policy가 inference한 base action이다. 서로 다른 time feature τ와 base action의 여러 조합이 가능하다. 예측 residual action은 Δa_residual로 나타낸다. loss function은 mean squared error(MSE)다.

L_MSE = (1/N) Σᵢ₌₁ᴺ ‖Δa_residual⁽ⁱ⁾ − (a⁽ⁱ⁾ − â⁽ⁱ⁾)‖₂².             (10)

여기서 N은 batch size, 즉 mini-batch의 training sample 수다.

4. 실험 설정

4.1 Benchmark와 dataset

실험에는 Kinetix와 LIBERO Spatial이라는 두 simulation environment를 사용한다. 먼저 Kinetix로 매우 동적인 manipulation 및 locomotion task에서의 성능을 평가한다. 둘째, robot manipulation의 표준 benchmark로서 LIBERO Spatial을 사용한다. 특히 SmolVLA 연구가 긴 horizon이 LIBERO Spatial의 성능을 크게 떨어뜨린다고 보고했으므로, 이 task는 긴 horizon에서의 강건성을 평가하기에 자연스러운 선택이다.

Kinetix

12개의 매우 동적인 task에 대한 demonstration을 제공하는 Kinetix를 사용했다(부록 A.1 참조). locomotion과 grasping부터 game과 유사한 설정까지 다양한 environment를 포함한다. 본 설정에서 중요한 점은, Kinetix가 지연되거나 일관되지 않은 action generation이 곧바로 failure로 이어지는 매우 동적인 environment를 포함한다는 것이다. 따라서 action chunking의 한계를 연구하고 latency 아래에서 반응성과 연속성을 보존하려는 RTC 같은 inference-time algorithm을 benchmark하기에 자연스러운 testbed다.

quasi-static benchmark와 달리 Kinetix environment는 torque 및 force 기반 actuation을 사용하므로 asynchronous inference가 중요하다. Kinetix는 language input이 없는 12개 task로 구성된다. expert model로 100만 step의 data를 수집했다. RTC 실험을 따라 먼저 RPO와 binary success reward를 사용해 expert policy를 학습했다. 각 environment마다 expert policy로 100만 transition dataset을 생성했다.

LIBERO

LIBERO는 task 사이의 knowledge transfer에 초점을 맞추어 lifelong robot learning을 연구하도록 설계된 benchmark suite다. 여러 task suite와 dataset을 제공한다. 본 연구는 robot manipulation에서 널리 쓰이는 benchmark이자 manipulation task의 spatial reasoning을 강조하는 LIBERO Spatial dataset을 사용한다.

3D robot manipulation benchmark를 위해 10개 task에 걸쳐 432 episode와 52,970 frame을 제공하는 LIBERO Spatial을 사용했다. dataset은 상단·손목 RGB image(256×256), 8-dimensional state, language instruction을 포함하는 multimodal input으로 구성된다.

4.2 모델 학습

Kinetix에서는 RTC 선행 연구를 따라 flow-matching policy를 base model로 사용했다. Correction head network는 3-layer MLP다. input layer는 state vector(2722-dim), base action(6-dim), 2-dimensional sinusoidal positional feature의 concatenation을 받는다. task별로 모델을 따로 학습·평가했으므로 language instruction이나 base policy latent representation은 사용하지 않았다. hidden layer는 각각 512 unit이며 ReLU activation과 layer normalization을 사용한다. output layer는 base action에 element-wise로 더하는 6-dimensional residual vector를 생성한다. 총 parameter 수는 0.31M이다. 그림 3이 구현 세부사항을 보인다.

LIBERO Spatial에서는 VLA 중 경쟁력 있는 성능을 제공하는 SmolVLA(450M parameters)를 base로 채택했다. correction head는 transformer encoder와 경량 MLP로 구성된다. visual observation(상단 및 손목 camera)은 ImageNet으로 pretrain한 ResNet-18을 사용해 512-dimensional token으로 encoding한다. language instruction은 base policy가 제공하는 smolVLM encoder로 embedding한다. base action, base policy latent feature, sinusoidal time embedding도 512-dim token으로 projection한다. 모든 token을 concatenate하여 6-layer transformer encoder로 처리한다. pooled embedding을 base action 및 state vector와 함께 3-layer MLP(hidden size 512)에 전달해 residual action을 예측한다. 총 parameter 수는 32M이다. 그림 4에 구현을 제시한다. Kinetix와 LIBERO 실험의 source code도 공개했으며 자세한 내용은 부록 A.3에 있다.

5. 결과

5.1 Kinetix

다양한 inference delay d와 execution horizon e에서 제안 action chunk correction framework를 Kinetix benchmark로 평가한다. 그림 5는 12개 task 전체의 집계 success rate를 보고한다. 두 baseline을 비교한다. 첫째는 Naïve async로, 새 action chunk를 만들 때 이전 chunk를 전혀 고려하지 않고 새 chunk가 준비되는 즉시 순진하게 전환한다. 둘째는 RTC다. 예상대로 naive async와 RTC baseline은 delay d 또는 horizon H가 증가하면 크게 저하된다. 특히 d≥3에서 naïve baseline은 오래된 action chunk 실행으로 인한 error 누적 때문에 success rate가 급락한다. RTC inference는 prediction과 execution을 overlap하여 이 문제를 일부 완화하지만 execution horizon이 늘면 여전히 성능이 낮아진다.

반대로 action chunk correction은 모든 설정에서 일관되게 더 높은 success rate를 유지한다. 최신 observation을 사용해 각 action을 정제하므로 inference delay가 만든 temporal misalignment와 긴 action horizon 안에서 누적되는 drift 모두에 대응할 수 있다. 예를 들어 delay d=4에서 제안법은 naïve baseline보다 success가 거의 35% 높고, horizon H=7에서도 85%를 넘는다. 이는 action chunk의 실시간 보정이 inference delay와 long-horizon execution 모두에서 성능을 유지함을 보여준다.

6. 관련 연구

Imitation learning과 VLA

Imitation learning(IL)은 사람이나 expert policy가 제공한 demonstration으로 agent를 학습하며 robot control 학습의 대표적 접근이다. 최근에는 일관성과 scalability를 높이기 위해 generative sequence model이 도입되었다. Diffusion Policy는 action generation에 diffusion model을 사용하여 imitation learning data distribution의 multimodality를 다룬다. Action Chunking Transformer(ACT)는 single-step action 대신 action chunk를 출력하는 transformer 기반 policy를 제안해 더 빠른 inference와 일관된 행동을 가능하게 한다. Flow Policy 같은 flow 기반 접근은 iterative denoising 대신 continuous transport map을 학습하여 action을 생성한다.

이 토대 위에서 π₀, OpenVLA, GR00T, SmolVLA를 포함하는 새로운 vision–language–action(VLA) foundation model 계열이 등장했다. 이 모델들은 ACT와 유사하게 chunk 기반 prediction을 inference의 사실상 표준으로 채택한다. VLA는 multimodal input을 align하여 폭넓은 task generalization을 달성하지만 architecture는 diffusion 또는 transformer 기반 imitation policy보다 훨씬 크다. 예를 들어 π₀는 약 3B, OpenVLA는 약 7B parameter이므로 최신 GPU 가속 hardware에서도 inference latency가 크다. scaling과 multimodal grounding의 가능성을 보여주지만 계산 footprint는 실시간 제어의 latency 문제를 악화한다.

Asynchronous chunk execution

모델 크기가 커지면 inference latency가 주요 bottleneck이 되어 asynchronous policy framework가 필요해진다. SmolVLA는 inference delay를 완화하는 server–client architecture를 제안했다. server는 observation을 받아 communication latency를 포함한 d control step delay로 inference한 뒤 horizon H의 action chunk를 client에 전송하고, client는 이를 순차 실행한다. 그러나 d만큼 지연된 action은 실행 시점에 아직 없으므로 client는 새 chunk가 도착할 때까지 이전 chunk의 action을 계속 실행한다. 이는 연속성을 보장하지만 연속 chunk 사이의 불일치 위험을 낳는다. 예컨대 이전 chunk는 왼쪽으로 움직여 장애물을 피하라고 예측하는데 새 chunk는 오른쪽을 제안할 수 있다. 이런 불일치는 특히 dynamic environment에서 jerky motion과 뚜렷한 성능 저하를 일으킨다.

chunk mismatch를 고치기 위해 RTC가 제안되었다. 이는 chunk switching을 inpainting 문제로 정식화해 action-chunking policy의 매끄러운 asynchronous execution을 가능하게 하는 inference-time algorithm이다. 구체적으로 현재 chunk를 실행하면서 다음 chunk를 생성하고, 반드시 실행될 action은 “freezing”하며 나머지는 “inpainting”한다.

Inference latency 감소

실시간 성능을 높이는 자연스러운 방법은 inference time을 줄이는 것이다. Streaming Diffusion Policy와 Streaming Flow Policy는 더 빠른 inference를 가능하게 하는 새 training procedure를 제시한다. 더 일반적으로 model compression이나 memory optimization도 inference speed를 높일 수 있다. 그러나 model scale과 communication overhead 때문에 action generation이 control step보다 빨라지지 못하는 한, 본 연구가 지적한 과제는 해결되지 않는다.

7. 결론

본 논문은 VLA 같은 대형 base policy에 경량 action correction head를 추가하는 Asynchronous Action Chunk Correction(A2C2)을 제안했다. A2C2는 action-chunking policy의 inference delay와 긴 execution horizon 아래에서 반응성을 보존하는 과제를 해결한다. correction head는 base policy와 같은 dataset으로 학습하며 원칙적으로 어떤 기성 VLA에도 추가할 수 있다. Kinetix simulation suite와 LIBERO Spatial benchmark 실험에서 A2C2는 naïve 또는 RTC가 크게 저하되는 설정에서도 높은 success rate를 일관되게 유지했다.

full model inference와 비교해 overhead는 미미하지만, 더 풍부한 language instruction, out-of-distribution 설정, LIBERO Spatial보다 더 동적인 task로 scalability를 검증하는 후속 연구가 필요하다. 이 과제를 해결하면 action chunk correction의 적용 범위를 넓히고 대형 policy architecture의 반응성을 높이는 일반 메커니즘으로서 역할을 강화할 수 있다.

최근 LLM과 VLM은 neural scaling law가 보여주듯 parameter scaling으로 향상된 일반성을 입증했다. 최근 VLA policy가 이들 모델 위에 구축되므로 다양한 environment와 task에 배치하기 위해 미래 VLA가 계속 커질 것이라 보는 것이 타당하다. 본 연구는 inference latency의 영향을 완화하는 경량 correction mechanism을 도입하여, 이렇게 확장된 VLA가 반응성을 희생하지 않고 실시간으로 작동하게 하는 한 단계로 볼 수 있다.

더욱이 수십억 parameter 모델의 inference는 이미 대부분 robot platform의 onboard processor 계산 능력을 넘어선다. 실무에서는 VLA를 remote server에서 실행하고 robot이 network로 query하는 client–server architecture가 필요하다. 본 정식화는 communication delay를 inference latency의 일부로 명시하므로, framework는 대형 VLA를 원격 실행하는 client–server architecture로 자연스럽게 확장된다. 따라서 본 framework는 real-world deployment에서 반응성을 유지하면서 대규모 VLA의 generalization 이점을 활용하는 경로를 제공하며, scalability와 responsiveness를 결합한 차세대 VLA system 설계를 가능하게 한다.

먼저 SmolVLA를 base policy로 학습했다. policy를 scratch부터 학습하거나 pretrained model을 fine-tuning하는 option이 있다. 본 설정에서는 SmolVLA가 주로 S0-101로 pretrain되었고 이는 LIBERO benchmark의 Franka arm과 다른 embodiment이므로 scratch training을 선택했다.

Kinetix에서는 correction head training 중 매번 base policy가 action chunk를 예측한다. 그러나 대형 VLA에서는 지나치게 시간이 많이 걸린다. 따라서 dataset의 각 step에 대해 SmolVLA inference 결과를 추가해 correction head를 학습했다. 새 dataset은 모든 LIBERO Spatial data, action chunk 결과, SmolVLA policy의 VLM latent representation을 포함한다. 이후 이 dataset으로 correction head를 학습했다.
