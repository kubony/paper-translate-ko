초록

generalist 로봇은 다양한 환경에서 효과적으로 수행해야 한다. 그러나 기존 접근법 대부분은 능력을 향상하기 위해 action annotation이 달린 데이터의 규모 확대에 크게 의존한다. 그 결과 하나의 물리적 사양에 제한되는 경우가 많고, 서로 다른 embodiment와 환경 사이에서 전이 가능한 지식을 학습하는 데 어려움을 겪는다. 이러한 한계에 맞서기 위해 cross-embodiment VLA policy를 학습하는 새 프레임워크 UniVLA를 제안한다. 핵심 혁신은 latent action model을 이용해 비디오에서 task-centric action representation을 도출하는 것이다. 따라서 매우 넓은 범위의 embodiment와 관점에 걸친 방대한 데이터를 활용할 수 있다. task와 무관한 dynamics의 영향을 완화하고자 language instruction을 결합하고 DINO feature space 안에 latent action model을 구축한다. 인터넷 규모 비디오에서 학습한 generalist policy는 효율적인 latent action decoding을 통해 여러 로봇에 배치할 수 있다.

여러 조작·내비게이션 벤치마크와 실제 로봇 배치에서 state-of-the-art 결과를 얻는다. UniVLA는 pretraining compute가 1/20 미만이고 downstream data가 1/10인데도 OpenVLA보다 우수하다. 인간 비디오까지 포함한 이질적 데이터를 training pipeline에 추가할수록 성능이 계속 향상된다. 결과는 확장 가능하고 효율적인 로봇 policy 학습을 촉진할 UniVLA의 잠재력을 뒷받침한다.

1. 서론

대규모 로봇 데이터셋의 등장에 힘입어 VLA 기반 로봇 policy는 최근 고무적인 진전을 이루었다. 하지만 보통 supervision을 위해 ground-truth action label에 의존하므로, 다양한 환경의 인터넷 규모 데이터를 활용하는 확장성이 제한된다. 또한 서로 다른 embodiment(예: Franka, WidowX, 심지어 사람 손)와 task(예: 조작과 내비게이션) 사이의 action space와 observation space 이질성은 효과적인 지식 전이에 큰 난제를 제기한다.

이에 중요한 질문이 생긴다. generalist policy가 효과적으로 계획하도록 하는 통합 action representation을 학습하여 인터넷 규모 비디오의 잠재력을 열고, 서로 다른 embodiment와 환경 사이의 지식 전이를 촉진할 수 있는가?

이를 위해 여러 embodiment와 환경에서 확장 가능하고 효율적인 계획을 지원하는 generalist policy 학습 프레임워크 UniVLA를 제안한다. LLM이 언어 간 공유 지식을 학습하듯 여러 로봇 demonstration과 1인칭 인간 비디오를 포함한 비디오 데이터 사이의 지식 전이를 촉진하는 통합 action space를 구축한다.

generalist policy를 만드는 방법은 세 단계이다. 1) Task-centric Latent Action Learning: VQ-VAE를 사용해 frame pair의 inverse dynamics에서 latent action을 이산화함으로써 방대한 cross-embodiment 비디오에서 task 관련 action representation을 비지도 방식으로 추출한다. 2) Next-latent action prediction: 이산 latent action token으로 auto-regressive vision-language model을 학습하여 embodiment 비의존적 계획 능력을 부여한다. 3) Latents decoding: latent plan을 물리적 behavior로 decode하고, pretraining된 generalist policy를 보지 못한 task에 효율적으로 특화해 배치한다.

최근 연구도 웹 규모 비디오에서 latent action을 학습할 가능성을 조사했지만, 단순 reconstruction objective는 비자기 agent의 움직임이나 예측 불가능한 camera shift처럼 task와 무관한 dynamics를 포착하는 중대한 한계가 있다. 이런 노이지 representation은 task와 무관한 방해 요인을 끌어들여 policy pretraining을 저해한다. 이에 pixel에서 patch-level representation을 추출하는 pretrained DINOv2 feature를 활용하여 task 관련 정보를 더 잘 포착하는 spatial·object-centric prior를 제공한다. 쉽게 얻을 수 있는 language instruction을 condition으로 사용해 움직임을 상호 보완적인 두 action representation으로 분리하며, 그중 하나가 task-centric action을 명시적으로 나타낸다.

UniVLA는 여러 조작 벤치마크와 내비게이션 task에서 state-of-the-art 성능을 달성하며, pretraining 비용(GPU 시간)은 1/20뿐인데도 OpenVLA를 큰 폭으로 능가한다. 이 효율성은 task 관련 dynamics와 부수적 시각 변화를 분리하는 task-centric latent action space에서 나온다. 데이터셋이 커질수록 성능이 향상되며 cross-embodiment·cross-view 로봇 데이터셋과 label 없는 인간 비디오까지 활용해 pretraining corpus를 확장하고 전이 가능한 지식을 추출한다. Bridge-V2만으로 pretraining해도 더 큰 Open X-Embodiment로 학습한 OpenVLA와 LAPA를 능가하여 제한된 데이터에서 지식을 증류하는 능력을 보여준다.

또한 10.8M parameter뿐인 경량 decoder로 latent action을 실행 가능한 trajectory로 바꾸어 광범위한 fine-tuning의 필요를 크게 줄인다. task-centric latent action space의 압축성과 정보성을 이용하므로 최소 downstream data로 다양한 task와 embodiment에 효율적으로 적응한다. 조작, 내비게이션, 실제 배치를 아우른 평가는 효율성·확장성·일반화 가능성을 입증한다.

기여. (1) 통합되고 embodiment 비의존적인 action space에서 계획하여 웹 규모 비디오로부터 확장 가능하고 효율적으로 의사결정하는 generalist policy 방법 UniVLA를 제안한다. (2) cross-embodiment 비디오에서 task-centric dynamics와 무관한 시각 변화를 분리해 task 관련 latent action을 추출하는 새 방법을 제안하고 정성·정량 실험으로 장점을 보인다. (3) 여러 벤치마크와 실제 로봇에서 state-of-the-art를 달성하며 OpenVLA 대비 LIBERO 성공률 18.5%, 내비게이션 29.6%, 실제 배치 36.7% 향상을 얻는다.

2. 관련 연구

2.1 Vision-language-action 모델

pretrained vision 파운데이션 모델, LLM, VLM의 성공을 토대로 VLA는 visual observation과 language instruction을 처리하고 embodied task를 완수할 robotic action을 생성하도록 도입되었다. RT-1과 Octo는 task·object·환경·embodiment가 다양한 robot trajectory를 통합하는 transformer policy를 사용한다. 반면 RT-2, OpenVLA, RoboFlamingo 등은 대규모 vision-language 데이터셋의 world knowledge를 끌어와 pretrained VLM으로 action을 만든다. RT-2와 OpenVLA는 action을 language model vocabulary의 token으로 취급하고, RoboFlamingo는 action prediction용 policy head를 추가한다. RoboDual은 generalist와 specialist policy의 강점을 합치는 이중 시스템을 제안한다. 다른 연구는 goal image 또는 video prediction으로 language-conditioned 실행 가능 plan을 만들고, 그 시각 단서로 action 생성을 안내한다.

하지만 이들은 ground-truth action label이 있는 interactive data에 크게 의존해 확장성이 제약된다. 우리는 action label과 무관하게 시각 변화에서 통합 latent action representation을 학습하여 인터넷 규모 action-free 비디오를 활용한다.

2.2 Cross-embodiment 학습

로봇 시스템마다 camera 관점, proprioceptive input, joint 구성, action space, control frequency가 달라 범용 policy 학습이 어렵다. 초기 연구는 내비게이션과 조작 사이 action space를 수동 정렬했지만 조작의 wrist camera에 제한되었다. 최근 transformer 접근은 가변 observation/action을 수용하며, CrossFormer는 observation space 제약이나 명시적 action-space alignment 없이 네 action space를 공동 학습한다. image 또는 point cloud의 query point 미래 trajectory를 포착하는 flow representation도 널리 연구되었다. ATM은 인간 demonstration에서 flow generation을 배우고, Im2Flow2Act는 in-domain data 없이 인간 비디오에서 object flow를 예측한다. object-centric representation도 대안이며 SPOT은 embodiment action과 sensory input을 분리하고자 SE(3) object trajectory를 예측한다.

기존법은 가능한 state-transition pattern을 포괄하는 방대하고 다양한 데이터와 명시적 annotation이 필요해 데이터 활용이 비효율적이다. 우리는 discrete codebook으로 latent action을 비지도 인코딩한다. 시각 noise를 걸러내고 vector quantization으로 정보를 효율적으로 압축하여 학습 효율을 높이고 데이터 다양성 의존을 줄인다.

2.3 Latent action 학습

VQ-BeT, Quest 등은 raw action trajectory에 variational autoencoder를 학습해 behavior 생성과 task 적응을 돕는 compact latent action space를 구성한다. 강화학습의 수렴 가속에도 쓰이며, 최근에는 vector quantization을 action-space adapter로 사용해 action과 LLM의 결합을 개선한다. 그러나 ground-truth action label 의존이 확장성을 제한한다.

더 넓은 비디오를 쓰기 위해 Genie는 next-frame prediction을 조건으로 causal latent action model에서 latent action을 추출한다. LAPO와 DynaMo도 명시적 action label 없이 visual data에서 직접 학습한다. LAPA와 IGOR는 human video에서 지식을 전이하도록 VLA에 discrete latent action을 가르치는 비지도 pretraining을 제안한다. 하지만 raw pixel의 모든 변화를 인코딩하여 camera shakiness, 타 agent 움직임, 새 object 등장 같은 task-irrelevant dynamics까지 포착하고 성능을 떨어뜨린다. 우리는 task-centric dynamics를 무관한 변화에서 분리하여 견고한 policy planning을 위한 더 효과적 latent action space를 만든다.

3. 방법론

UniVLA는 세 단계로 구현한다. 1) language-based goal specification을 사용해 방대한 비디오의 inverse dynamics를 비지도 추출하고, 다양한 embodiment와 domain에 일반화되는 이산 task-centric latent action을 얻는다. 2) visual observation과 task instruction을 받아 통합 latent space의 latent action token을 예측하는 auto-regressive transformer VLA를 학습한다. 3) 여러 robotic control system에 효율적으로 적응하도록 latent action을 실행 가능 control signal로 decode하는 specialized policy head를 둔다.

3.1 Task-centric Latent Action Learning

첫 단계는 이후 generalist policy의 기반이 되는 pseudo action label, 즉 latent action token을 생성한다.

Latent action quantization.

그림 2는 2단계 pipeline과 latent action model 구조를 보인다. frame interval k만큼 떨어진 연속 video frame pair {ot, ot+k}에서 시작한다. 데이터셋별 recording frequency에 따라 interval을 보정해 약 1초로 통일한다. Inverse Dynamics Model(IDM) encoder I(at|ot,ot+k)와 Forward Dynamics Model(FDM) decoder F(ot+k|ot,at)를 구성한다. encoder는 연속 observation에서 latent action을 추론하고 decoder는 latent action으로 future observation을 예측한다. encoder는 causal temporal mask를 둔 spatial-temporal transformer이다. dimension d의 learnable action token aq∈RN×d를 video feature 뒤에 순차 연결해 dynamics를 추출한다.

정보를 더 압축하고 auto-regressive transformer policy objective에 맞추기 위해 action token을 quantize한다. az∈RN×d는 vocabulary size |C|인 codebook과 VQ-VAE objective로 최적화한다. spatial transformer decoder는 quantized token만으로 future frame을 예측한다. context 과의존이나 데이터 암기를 막기 위해 historical frame을 decoder에 주지 않는다.

raw pixel prediction은 texture와 lighting 같은 task-irrelevant detail에 주의를 강제하며, 통제되지 않은 웹·crowd-sourced 비디오에서 더 심각하다. JEPA에서 착안해 semantic이 풍부한 DINOv2 spatial patch feature를 input과 prediction target으로 쓴다. object-centric이고 spatially aware하기 때문이다. self-supervised objective는 embedding reconstruction error ||Ôt+k−Ot+k||²를 최소화한다. O는 frame o의 DINOv2 feature이며 compact latent action은 observation 사이 transformation을 인코딩해야 한다.

Latent action decoupling.

웹 비디오의 robot action은 무관한 환경 변화와 얽힌다. Stage 1에서는 T5 text encoder의 language instruction ℓ을 encoder·decoder context condition으로 넣는다.

Encode: â_TI = I([O_t ; O_(t+k) ; a_TI ; ℓ]),   ã_TI = VQ(â_TI)
Decode: Ô_(t+k) = F([O_t ; ã_TI ; ℓ])

[;]는 sequence-wise concatenation, VQ는 vector-quantized action codebook, ℓ은 T5 instruction embedding이다. task instruction이 decoder에 underlying action의 high-level semantic guidance를 제공한다. codebook capacity가 제한되므로 quantized latent action은 고수준 task 관련 정보가 아니라 환경 변화와 시각 detail만 인코딩하도록 최적화된다. Stage 1은 새 object 등장, 외부 agent 움직임, camera motion artifact 같은 task-irrelevant 정보를 담는 latent action 집합을 만든다. 이는 visual environment grounding에는 중요하지만 task objective와 직교한다.

Stage 2에서는 Stage 1의 task-irrelevant codebook과 parameter를 재사용하고, policy 학습에 쓸 새 task-centric latent action âTC를 학습한다.

Encode: {â_TI, â_TC} = I([O_t ; O_(t+k) ; a_TI ; a_TC])
        ã_TI = VQ(â_TI),   ã_TC = VQ_TC(â_TC)
Decode: Ô_(t+k) = F([O_t ; ã_TI ; ã_TC])

VQTC는 task-centric dynamics를 학습하도록 새로 초기화한 codebook이다. 획득한 task-irrelevant representation과 codebook을 freeze하여 모델이 새 latent action의 정제와 특화에 집중하게 한다. 따라서 object manipulation이나 goal-directed trajectory 같은 task 관련 dynamics를 정밀하게 모델링한다. 이 명시적 분리는 여러 환경·task에 대한 generalist policy의 일반화를 높인다. LAPA 같은 naive latent action learning보다 task-centric representation만 쓴 학습이 더 빨리 수렴하고 견고하여 후속 policy 학습에 더 유익함을 보인다.

3.2 Generalist Policy의 Pretraining

학습한 latent action model로 ot+k가 주어질 때 video frame ot에 latent action az label을 붙이고 generalist policy를 학습한다. Prismatic-7B VLM을 기반으로 SigLIP와 DINOv2의 fused visual encoder, visual embedding을 language modality에 맞추는 projection layer, LLaMA-2를 결합한다. RT-2와 OpenVLA가 LLaMA tokenizer의 드문 단어를 [−1,1]의 균등 action bin으로 대응시켜 low-level action space에서 직접 계획하는 것과 달리, vocabulary에 |C|개 특수 token {ACT_1,…,ACT_C}을 추가하고 codebook index로 latent action을 투영한다. 원래 VLM 구조와 objective를 보존해 pretrained knowledge를 robotic control에 온전히 전이한다.

L = E_(o_t,l,a_z,<i) [ − Σ_(i=1)^N log π_φ(â_(z,i)=a_(z,i) | o_t,l,a_(z,<i)) ]

policy πφ는 observation ot, instruction l, 이전 latent token az,<i를 받아 next-latent-action negative log-probability 합을 최소화한다. 모든 실험에서 N=4이다. compressed action space는 OpenVLA의 2567에서 |C|=16일 때 164로 줄어 수렴을 크게 가속한다. OpenVLA의 21,500 A100-hours에 비해 960 A100-hours만으로 경쟁력 있는 결과를 낸다. 통합 latent action space로 cross-domain data의 전이 지식을 활용하며, 시각적으로 유사한 egocentric motion으로 action space를 수동 정렬할 필요가 없다.

3.3 배치를 위한 Post-training

Latent action decoding.

downstream adaptation 동안 pretrained policy는 next latent action을 예측해 embodiment 비의존성을 유지한다. latent action과 executable behavior를 잇기 위해 action decoder를 추가한다. visual embedding sequence를 multi-head attention pooling으로 한 token에 모으고, 이를 query로 latent action embedding에서 정보를 추출한다.

Visual Embed.: E′_v = A(Q=q_v, K=V=E_v)
Action Embed.: E′_a = A(Q=q_a+E′_v, K=V=E_a)

A는 multi-head attention, {Ev,Ea}는 VLM 마지막 layer의 visual·latent action embedding, {qv,qa}는 각각의 정보를 추출하는 random-initialized query이다. E′a를 target robot의 action space로 선형 투영한다. latent action은 약 1초 구간의 action이므로 action chunk로 자연스럽게 decode할 수 있고 embodiment별 control frequency에 맞게 chunk size를 조절한다. LoRA로 parameter-efficient fine-tuning하며 action head는 12.6M, 총 trainable parameter는 약 123M이다. next-latent prediction loss와 ground-truth/predicted low-level action 사이 L1 loss를 함께 end-to-end 최적화한다.

과거 출력에서 학습.

historical observation은 sequential decision-making에 중요하지만, 여러 frame을 큰 VLA에 직접 주면 inference latency와 visual token 중복이 커진다. LLM의 Chain-of-Thought에서 착안해 historical latent action output을 사용한다. rollout의 매 timestep에서 과거 action을 input prompt에 넣어 policy가 자기 결정을 통해 배우고 동적 환경에 적응하는 feedback loop를 만든다. latent action model로 historical frame의 action을 annotate하고 LLaMA token vocabulary에 mapping하여 instruction 뒤에 붙인다. post-training에는 이를 input으로 포함해 in-context learning 능력을 부여한다. inference 때 최초 step을 제외하고 한 step의 history(N=4 token)를 넣는다. 특히 long-horizon task가 향상된다.

4. 평가

LIBERO, CALVIN, SimplerEnv 조작 벤치마크, R2R 내비게이션, 실제 환경에서 평가한다. task-centric 특성을 정량화하고 핵심 설계를 ablation한다. 질문은 다음과 같다. (1) 성능과 적응성: pretraining 지식을 새로운 embodiment·task에 전이하고 효율적으로 적응하는가? (2) 일반화: 보지 못한 scenario에 일반화하는가? (3) 확장성: 인간 비디오를 포함한 다양한 출처를 활용하고 계속 커지는 데이터에서 이익을 얻는가?

4.1 주요 결과

4.1.1 LIBERO 조작 벤치마크

실험 설정.

full latent action model은 OpenX 일부의 조작 데이터, GNM의 내비게이션 데이터, Ego4D human video로 pretraining한다. LIBERO는 lifelong manipulation 연구용 네 task suite로 이루어진다. target suite 안에서 성공 demonstration에 behavioral cloning을 적용한 supervised fine-tuning만 수행한다. 각 suite는 task 10개, task당 human-teleoperated demonstration 50개이다. Spatial은 bowl을 정확히 놓도록 spatial relationship과 geometry reasoning을 요구한다. Object는 scene layout은 같고 object type을 바꿔 object instance generalization을 본다. Goal은 object와 layout은 유지하고 goal을 다양화한다. Long은 여러 sub-goal, 이질적 object·layout·sequence를 포함한 long-horizon planning을 본다.

OpenVLA processing pipeline으로 failure case를 제외한다. LIBERO-Long은 40k, 나머지는 30k step, global batch 128로 학습한다. third-person image와 language만 input으로 쓴다. LIBERO sample은 policy와 latent model 어느 pretraining에도 포함되지 않았다. Full 외에 Bridge-V2만, human data만 쓴 모델도 보고한다. suite당 500 trial(task당 50)을 3 seed로 평가한다.

4.1.2 Room2Room 내비게이션

설정.

Baseline.

4.3 추가 Ablation

데이터 확장성.

5. 결론

통합 task-centric latent action space에서 계획하여 새로운 로봇 setup에 효율적으로 적응하는 VLA UniVLA를 제시했다. 광범위한 평가에서 여러 조작·내비게이션 벤치마크의 state-of-the-art를 세웠다. 이질적 pretraining data를 늘리면 downstream 성능이 확장되며, 데이터가 제한된 상황에도 높은 적응성을 유지한다. embodiment gap이나 action label 유무와 관계없이 웹 규모 비디오를 학습에 활용하는 차세대 generalist policy의 길을 열고자 한다.

6. 한계와 향후 연구

Latent action 설계.

고정 granularity와 predefined codebook size는 모든 task·embodiment에 최적이 아닐 수 있다. 환경 조건에 따라 동적으로 조절하는 adaptive mechanism을 탐색하면 개선될 수 있다. 평가는 주로 single-arm manipulation이며 latent token의 action granularity가 비교적 고정적이다. dual-arm humanoid나 dexterous hand로 확장하려면 더 복잡하고 세밀한 action-space modeling이 필요하다.

Language annotation 요구.

task-relevant latent action은 task 완료에 중요한 ego-agent motion을 인코딩하고, “물 끓이기” 중 kettle의 steam 같은 non-ego dynamics는 제외한다. 데이터 대부분은 high-level goal보다 short-horizon action을 묘사하는 fine-grained instruction이다. 더 표현력 있는 instruction이 ambiguity를 줄일 수 있지만, 본 방법은 granularity가 다른 instruction에서도 확장 가능하다. 별도 처리 없이 naive 방법보다 우수하다.

World model과 통합.

latent action decoder는 본질적으로 latent action condition으로 future observation을 예측하는 world model이다. policy가 on-the-fly sample한 latent action을 조건으로 여러 visual plan을 만들 수 있다. 이는 강화학습의 reference alignment와 planning tree를 통한 test-time scaling으로 이어지며, VLM이나 heuristic function을 reward model로 쓸 수 있다.

In-context learning.

VLA 성능 상한을 높이는 데 중요하다. latent action model이 인간·로봇 조작을 잇는 transferable motion representation을 추출하므로, human demonstration video를 compact latent embedding sequence로 encoding해 in-context sample로 쓸 수 있다. latent model이 video tokenizer 역할을 하며 추가 fine-tuning 없는 zero-shot skill acquisition이 가능하다. 향후 탐색한다.
