초록

최근 대규모 vision-language model(VLM)이 vision-language navigation(VLN)의 일반화 성능을 향상시켰지만, 기존 방법은 대체로 vision-language 입력을 짧은 horizon의 이산 action으로 직접 매핑하는 end-to-end pipeline에 의존한다. 이러한 설계는 흔히 단절된 움직임을 만들고 높은 latency를 초래하며, 동적 장애물 회피 같은 현실 세계의 난제를 다루는 데 어려움을 겪는다.

본 연구는 고수준 reasoning과 저수준 action 실행을 상승적으로 통합하는 최초의 dual-system VLN 파운데이션 모델인 DualVLN을 제안한다. VLM 기반 global planner인 System 2는 image-grounded reasoning을 통해 중기 waypoint goal을 예측함으로써 “천천히 ground”한다. 가볍고 multimodal conditioning을 사용하는 Diffusion Transformer policy인 System 1은 명시적 pixel goal과 System 2의 latent feature를 함께 활용해 부드럽고 정확한 trajectory를 생성함으로써 “빠르게 움직인다”. 이 dual-system 설계는 복잡한 동적 환경에서 견고한 실시간 control과 적응적 local decision-making을 가능하게 한다. 학습을 분리함으로써 VLM은 일반화 능력을 유지하고, System 1은 해석 가능하면서 효과적인 local navigation을 달성한다. DualVLN은 모든 VLN benchmark에서 선행 방법을 능가하며, 현실 세계 실험에서도 견고한 장기 horizon planning과 동적 환경에 대한 실시간 적응성을 보인다.

1. 서론

Vision-Language Navigation(VLN)은 robotics의 핵심 과제이다. VLN system은 시각 관측과 언어 지시를 입력으로 받아 goal을 향한 trajectory를 계획한다. 최근 이 분야는 이산 goal planning에 초점을 둔 초기 benchmark에서 continuous action space formulation으로, 다시 locomotion controller를 갖춘 물리적으로 사실적인 simulation으로 상당히 발전했다. 한편 대규모 VLM의 강력한 사전 지식은 post-training을 거쳐 전이될 수 있으므로, 다양한 지시와 환경에 걸쳐 전례 없는 일반화를 VLN system에 부여할 새로운 가능성을 제공한다.

그러나 continuous VLN benchmark에서도 기존 Vision-Language-Action(VLA) model은 대체로 vision과 language 입력을 짧은 horizon의 이산 action(예: 앞으로 0.25 m 이동)에 직접 매핑하는 긴밀히 결합된 end-to-end paradigm을 채택한다. 이 설계는 현실 세계 배치에 중대한 한계를 만든다. 첫째, 분절되고 부자연스러운 움직임을 생성하며, 매 step마다 대형 VLM을 빈번히 호출해야 하므로 실행 latency가 높다. 둘째, vision-language reasoning, global planning, local control을 하나의 pipeline에 얽어 놓아 계층적 의사결정 수준 사이의 명시적 coordination이 부족하다. 따라서 민첩한 control과 동적 장애물 회피 같은 고급 요구사항을 충족하지 못한다.

이러한 한계를 극복하기 위해, 본 연구는 VLM의 reasoning 역량과 실시간 control에 필요한 민첩성을 명시적으로 연결하는 최초의 dual-system VLN 파운데이션 모델 DualVLN을 제안한다. DualVLN은 VLN pipeline을 상호보완적인 두 system으로 분리한다. 대형 foundation VLM인 System 2는 느리지만 견고한 reasoning을 수행하고 명시적인 중간 pixel goal을 낸다. 경량 diffusion-based policy model인 System 1은 ground된 target을 연속적이고 통과 가능한 trajectory로 변환해 동적 상황에서도 견고한 collision avoidance를 가능하게 한다. 두 system의 coordination을 개선하기 위해 latent representation으로 연결한다. pixel-goal grounding task로 System 2를 학습한 다음 그 weight를 고정한다. 이후 learnable latent query 집합을 도입하고 prompt tuning으로 최적화한다. 이 query는 compact latent feature를 추출하고 System 1의 implicit goal 역할을 한다.

왜 분리된 순차 학습인가?

분리는 각 system의 전문화를 가능하게 한다. System 2는 대규모 multi-source reasoning data로 scale할 수 있지만 System 1에는 소량의 low-level goal-reaching data만 필요하다. System 1은 추가적인 고주파 RGB 입력과 비동기 inference의 혜택을 받아 동적 환경에서 더 높은 control frequency를 달성한다. 무엇보다 이 분리는 downstream low-level planning에 적응할 때도 VLM의 일반화를 보존한다.

왜 명시적 pixel goal과 암묵적 latent goal을 모두 사용하는가?

System 1의 안내로 명시적 2D pixel goal에만 의존하면 VLM의 풍부한 hidden feature를 충분히 활용하지 못한다. reasoning과 local planning의 연결이 얕아지고 dual-system이 단순 modular pipeline으로 축소된다. 명시적 pixel goal 학습은 System 2의 해석 가능성과 일반화를 높인다. 그 위에서 implicit latent feature는 System 1에 더 풍부하고 적응적인 안내를 제공하며, VLM hidden state에 부호화된 이질적 정보에서 task-relevant representation을 자동 추출하게 한다.

실험 결과 DualVLN은 VLN-CE와 VLN-PE benchmark 모두에서 이전 state-of-the-art를 일관되게 능가한다. 현실 세계 평가는 여러 robot platform과 다양한 scenario에서 견고한 장기 horizon planning, 실시간 trajectory 실행, 동적 장애물 회피를 입증한다. 또한 task trajectory를 따라 humanoid agent를 배치한 동적 환경에서 navigation model의 social awareness와 task recovery를 평가하는 최초의 Social-VLN benchmark를 제안한다.

2. 관련 연구

Navigation을 위한 Vision-Language-Action Model

최근 연구는 multimodal large model을 navigation의 pretrained backbone으로 활용해 내재된 상식 지식으로 성능을 높이고자 한다. 일반적인 접근은 navigation action을 text로 formulation하여 LLM의 next-token prediction task로 다룬다. RoboPoint와 NaviMaster 같은 방법은 navigation을 pixel grounding으로 다루지만 실행을 위한 추가 module이 여전히 필요하다. UniVLA와 TrackVLA 같은 end-to-end 방법은 VLM latent feature를 continuous trajectory로 직접 매핑하지만, 동기식 framework 때문에 동적 환경에서 고주파 의사결정이 제한된다. 최근 일부 dual-system architecture가 slow-fast reasoning을 탐구하지만 tabletop task에 집중하며 장기 horizon planning이나 건물 간 navigation은 다루지 않는다. 본 연구는 장기 horizon instruction following, 정확한 planning, 미관측 환경에서의 navigation을 지원하는 최초의 비동기 dual-system architecture를 제안한다.

Visual Navigation Policy Learning

Visual navigation은 실시간 장애물 회피를 수행하면서 명시적인 goal에 도달하게 한다. 전통적인 modular 접근은 명시적 localization과 mapping에 의존하지만 누적 오차, latency, 광범위한 hyperparameter tuning 문제를 겪는다. 이를 해결하려 end-to-end learning-based 방법이 제안되었다. GNM, X-Nav, RING, X-Mobility는 embodiment 전반의 zero-shot generalization을 개선하고, iPlanner, ViPlanner, FDM, S2E는 효율적 학습과 sim-to-real transfer에 집중한다. Image-goal navigation 역시 SLING, ViNT, NoMaD, NaviDiffuser에서 탐구되었다. 본 연구의 System 1은 VLM의 latent goal을 조건으로 하는 RGB-only visual navigation policy이다.

3. 방법

그림 2와 같이 framework는 고수준 reasoning과 저수준 action 실행의 synergy를 실현하는 dual-system 설계를 사용한다. VLM-based planner인 System 2는 image pixel space에서 중기 waypoint를 예측해 spatially grounded target을 제공하는 global planning을 수행한다. multimodal goal-conditioned diffusion policy인 System 1은 현재 관측과 System 2의 비동기 latent feature를 조건으로 continuous trajectory를 생성해 복잡한 환경에서 견고한 실시간 control을 가능하게 한다.

3.1 System 2: Self-Directed View Adjustment를 사용하는 VLM 기반 Pixel-Goal Grounding

System 2는 반복 과정에서 고수준 pixel-goal grounding과 self-directed view adjustment를 통합한다. 각 navigation step에서 agent는 현재 RGB frame과 history를 관측하고 view를 조절할지 pixel goal을 출력할지 결정한다. 이로써 pixel goal 예측이 정보성 높은 관점에 기반하며 occlusion과 까다로운 viewpoint를 처리한다.

가장 먼 Pixel Goal Grounding

Goal planning module은 image pixel coordinate 관점의 spatial grounding이 가능한 강력한 open-source VLM Qwen-VL-2.5를 토대로 한다. Qwen-VL-2.5를 VLN에 적응시키기 위해 high-level planning을 가장 먼 pixel goal grounding 문제로 formulation한다. 모델은 언어 지시와 egocentric RGB image sequence를 입력받아 다음으로 선호되는 navigation waypoint에 대응하는 image 내 2D coordinate를 예측한다. 학습 sample을 만들기 위해 agent의 3D trajectory를 2D egocentric observation에 projection하고 agent 위치에서의 visibility를 측정한다. 구체적으로 trajectory를 projection하기 전에 depth map과 camera–point distance를 함께 사용해 현재 view의 visible region 안에 드는 point를 판별한다. 거리가 대응 depth 값을 넘는 trajectory point는 occluded로 보고 제거한다. 이 projection에 따라 원래 VLN-CE trajectory를 pixel-goal grounding sample로 분할한다.

Self-Directed View Adjustment

3D trajectory를 2D pixel coordinate로 projection하는 데는 문제가 생길 수 있다. agent의 viewpoint가 너무 높으면 바닥 point가 가려질 수 있고, 이를 인위적으로 들어 올리면 depth ambiguity가 생겨 실제 target 위치가 불명확해진다. 또한 agent가 잘못된 방향을 바라보면 다음 waypoint가 현재 field of view 밖에 있을 수 있다. 사람이 다음 waypoint를 고르기 전에 주변을 둘러보고 바닥 쪽으로 시선을 낮추는 행동에서 영감을 받아, System 2는 Turn Left/Right 15°, Look Up/Down 15° 같은 discrete action으로 환경을 scan하고 camera angle을 조절할 시점을 자율적으로 결정한다. 즉 다음 pixel goal을 예측하기 전에 정보성 높은 관점을 능동적으로 찾는다.

3.2 System 1: Multimodal Conditioning을 사용하는 Diffusion Transformer Policy

Latent Goal Representation

System 2가 다음 pixel goal을 autoregressive하게 생성하면, 모델은 자연스럽게 언어 지시, historical image, 현재 관측, view-adjustment action, pixel-goal 정보를 아우르는 context feature sequence X를 생성한다. 이후 무작위 초기화되고 prompt tuning으로 갱신되는 learnable latent query 집합 Z를 덧붙인다. 결합 sequence [X; Z]를 VLM으로 처리하면 Z가 X의 task-relevant semantic information에 attention하여 이를 추출할 수 있다. 결과 Z′는 System 1이 정밀한 저수준 trajectory를 생성하는 조건이 되는 중간 latent goal representation을 이룬다.

Multi-Modal Conditioning Diffusion Transformer

System 1은 robot이 따라갈 부드러운 trajectory(조밀한 waypoint 32개)를 생성하는 Diffusion Transformer(DiT)로 구현되며, 두 조건 source를 사용한다. 첫째는 System 2의 저주파 trajectory latent Z′이고, 둘째는 고주파 RGB 입력이다.

Dual-system inference는 비동기(느린 System 2, 빠른 System 1)로 수행되므로 time t에서 생성된 latent goal은 고정된 채 남는다. time t+k에서 System 1은 이미 이동한 거리를 추정하고 동적 변화에 적응하면서도 이 오래된 latent goal을 해석해 trajectory를 정확히 갱신해야 한다.

이를 위해 System 1은 time t에서 System 2가 마지막으로 본 frame에 대응하는 RGB feature와 time t+k의 현재 관측을 모두 encode한다. 두 image를 먼저 ViT encoder로 처리해 high-dimensional visual feature를 추출하고, self-attention module로 두 time step에 걸쳐 fuse한다. 빠른 inference를 유지하기 위해 fused feature를 Q-Former로 compact한 32 token으로 더 압축하며, 이 token이 DiT의 고주파 visual conditioning 역할을 한다.

Flow Matching

ground-truth trajectory waypoint X₀와 두 conditioning signal인 trajectory latent Z′ 및 fused RGB token F가 주어지면, 각 training step에서 먼저 diffusion timestep u ~ U(0,1)과 noise vector ε ~ N(0,I)를 sample한다. noisy trajectory는 다음과 같이 정의한다.

Xᵤ = αᵤ X₀ + σᵤ ε                                      (1)

여기서 αᵤ는 u의 감소 함수이고 σᵤ는 u의 증가 함수이다. Diffusion Transformer는 Z′와 F를 조건으로 timestep u에서 trajectory velocity Ẋᵤ를 예측하도록 학습한다.

Ẋ̂ᵤ = fθ(Xᵤ, u, Z′ ⊕ F)                                 (2)

⊕는 concatenation이고 fθ는 transformer network이다. 학습 objective는 예측 velocity와 true velocity 사이의 mean squared error를 최소화한다.

L_flow = E_(u,X₀,ε) [ ‖Ẋ̂ᵤ − Ẋᵤ‖₂² ]                    (3)

3.3 구현 세부사항

System 2는 StreamVLN의 data recipe를 따라 QwenVL-2.5(7B)를 한 epoch finetuning한다. finetuning 중 vision encoder와 LLM backbone을 모두 완전히 unfreeze한다. System 1에는 pixel goal 예측 뒤에 네 개의 learnable latent query를 붙여 compact latent goal embedding을 추출한다. RGB encoder는 DepthAnythingV2-Small의 ViT backbone으로 구현한다. low-latency inference를 위해 hidden dimension 384, transformer layer 12개, attention head 6개의 compact DiT 설계를 채택한다. latent embedding size는 DiT와 cross-attention하기 전에 3584에서 768로 linear projection한다. 자세한 내용은 부록 A에 제시한다.

4. Social Vision-and-Language Navigation Benchmark

Generalist navigation model이 최근 발전했음에도 task-oriented navigation을 수행하면서 동적 장애물을 처리하는 능력을 평가하도록 설계된 benchmark는 없다. 사람이 중심인 환경에서는 robot이 collision을 피하고 detour 뒤 원래 task trajectory로 돌아와야 하므로 이 능력이 중요하다. VLN-CE benchmark는 정적 layout에 집중해 동적 환경의 social awareness와 trajectory recovery를 평가하는 데 공백이 있다.

Benchmark 구축

Dual-system 설계의 중요성을 부각하고 generalist navigation agent의 발전을 촉진하기 위해 고전적 VLN 평가를 정적 setting에서 동적 scenario로 확장한다. Social-VLN은 R2R-CE 위에 구축한 새 benchmark로, Habitat 3.0의 humanoid로 모델링한 여러 dynamic agent를 simulation에 포함한다. humanoid agent를 임의 start와 goal 사이에서 무작위로 돌아다니게 하지 않고 ground-truth VLN trajectory를 따라 전략적으로 배치한다. 대부분의 VLN task는 비교적 단거리이므로, 이 표적 배치는 interaction 가능성을 크게 높여 도전적이고 현실적인 social VLN test를 만든다.

그림 3과 같이 Social-VLN은 다양한 상황에서 socially-aware obstacle avoidance behavior를 포괄적으로 평가하게 한다. 또한 agent가 길을 완전히 막지 않도록 episode마다 면밀히 검증하여, 실패가 단순한 물리적 폐색만 반영하지 않게 한다. 표준 VLN metric에 더해 dynamic pedestrian과의 unsafe interaction에서 생기는 실패를 명시적으로 수량화하는 Human Collision Rate(HCR) metric을 도입한다. Social-VLN은 task completion뿐 아니라 동적 환경에서 agent의 safety awareness도 평가한다.

학습 데이터 수집

동적 obstacle-avoidance trajectory를 수집하는 pipeline도 개발한다. 각 training episode에서 human detection sensor를 설정해 egocentric view를 계속 감시한다. human mask pixel ratio가 사전 정의한 threshold를 넘으면 수정 A* algorithm을 작동시켜 collision-free trajectory를 다시 계획한다. 이 과정으로 60개 MP3D scene에서 763K social navigation episode를 생성했으며, socially compliant agent 학습을 위한 기반 resource를 형성한다.

5. 실험

5.1 Simulation 실험

VLN-CE Benchmark와 Metric

먼저 Habitat simulator의 VLN-CE setting으로 구축된 표준 R2R-CE와 RxR-CE benchmark에서 평가한다. 이 benchmark는 Matterport3D 환경의 현실적인 실내 navigation을 simulation하며 agent는 continuous control 아래 자연어 지시를 따른다. 일반화를 평가하기 위해 모든 실험은 validation unseen split에서 수행한다. 선행 연구를 따라 표준 VLN metric을 채택한다. Navigation Error(NE)는 goal까지의 최종 거리, Success Rate(SR)는 agent가 goal 3 m 이내에서 멈춘 episode 비율, Oracle Success Rate(OSR)는 trajectory 중 goal과 가장 가까운 point를 고려한 성공률, Success weighted by Path Length(SPL)은 불필요하게 긴 path에 penalty를 주는 성공률이다.

Humanoid Unitree H1 robot으로 R2R dataset 결과를 보고한다. 위 표준 VLN metric 외에 Trajectory Length(TL), robot fall 빈도를 측정하는 Fall Rate(FR), agent가 움직이지 못한 경우를 나타내는 Stuck Rate(StR)를 보고한다. 이 metric은 continuous하며 물리적으로 사실적인 navigation scenario에서 system의 효과와 견고성을 함께 포괄적으로 평가한다.

5.2 현실 세계 Cross-Embodiment 실험

실험 설정

Wheeled(Turtlebot4), quadruped(Unitree Go2), humanoid(Unitree G1) robot에서 현실 세계 실험을 수행한다. 모든 robot은 서로 다른 높이에 장착되고 아래로 15° 기울인 Intel RealSense D455 camera를 갖춘다. 전체 모델은 RTX 4090 GPU가 있는 remote server에서 실행되며 약 20GB memory를 차지한다. VLN 지시가 주어지면 robot은 동기화한 RGB-D image를 remote server로 stream하고 dual-system model이 비동기 inference를 수행한다. server가 출력한 trajectory 또는 discrete view-adjustment action은 odometry를 통해 world coordinate로 변환되고 MPC controller로 tracking된다. System 2는 KV-cache reuse로 trajectory token inference를 1.1초에서 0.7초로 줄이고, System 1은 TensorRT로 0.03초 안에 32개 trajectory를 병렬 생성한다. 이 비동기 pipeline은 항상 최신 trajectory를 사용할 수 있게 하여 부드럽고 거의 실시간인 navigation을 제공한다.

정량 분석

현실 환경에서 DualVLN의 견고성과 일반화를 정량적으로 평가하기 위해 CMA와, discrete action을 출력하는 VLM 기반 NaVid, NaVILA, StreamVLN을 상대로 benchmark했다. 각 model 및 scenario마다 20회씩 hallway(쉬움), bedroom(중간), office(어려움, room-to-room) scenario에서 평가하고 SR과 NE를 측정했다. 그림 6의 VLM baseline 중 NaVid는 복잡한 task에서 고전하고, NaVILA는 장기 horizon task를 처리하지만 office scenario에서 최종 goal을 자주 놓친다. StreamVLN은 일부 경우 장애물을 피하지만 task completion을 희생한다. Dual-system DualVLN은 정적·동적 scenario 모두에서 일관되게 높은 SR과 낮은 NE를 달성한다.

정성 분석

보충 video를 참조한다. Scene-specific finetuning 없이 zero-shot setting에서 office, canteen, street, convenience store를 포함한 다양한 현실 scenario로 평가한다. DualVLN은 cluttered environment에서 올바른 pixel goal을 선택하고 안전한 trajectory를 만들며, 원하는 모든 landmark를 통과하는 부드러운 path를 계획하고 staircase와 dynamic pedestrian을 처리한다. 또한 camera height, vibration, tracking의 차이에도 여러 robot platform에서 견고하게 동작한다.

5.3 Ablation Study

명시적 Pixel Goal 및 Latent Goal의 영향

DualVLN의 System 1을 conditioning하는 서로 다른 goal representation의 역할을 평가하기 위해 그림 7과 같이 일련의 ablation study를 수행한다. 먼저 순차 학습을 사용하지 않고 System 1과 System 2를 end-to-end로 함께 학습하며 명시적 pixel goal에 의존하지 않는 대안 설계(w/o Sys.2 Train)를 고려한다. 이 설정에서 diffusion policy의 수렴이 현저히 느려지고 System 2의 일반화 능력이 저하된다. 이는 intermediate pixel goal을 사용하는 분리 학습이 효율적 학습과 VLM의 reasoning 역량 보존 모두에 중요함을 확인한다.

둘째, System 1 학습 단계에서 latent query Z를 붙이기 전에 context sequence X에서 명시적 pixel-goal text를 제거한다. 이 경우(w/o Pixel Goal) latent goal feature가 명시적 pixel-goal 정보에 attention할 수 없다. 성능이 분명히 하락하며, 명시적 pixel goal이 diffusion policy에 가치 있는 안내를 제공하는 동시에 해석 가능성과 일반화를 높임을 확인한다.

마지막으로 pixel-goal text의 VLM 마지막 layer hidden state만 System 1의 conditioning signal로 사용하는 변형을 고려한다. 이 설정(w/o Latent Goal)은 더 낮은 성능을 낸다. latent goal query가 없으면 System 1은 어떤 hidden state를 conditioning으로 삼을지 학습하지 못하고 고정된 VLM feature를 수동적으로 소비하는 데 제한되기 때문이다. 이는 System 2에서 System 1로 흐르는 정보의 적응성을 제한한다.

System 1 대 SOTA Point-Goal Navigation Policy

Dual-system joint training framework의 이점을 검증하기 위해 latent goal을 제거하고 추가 depth 정보로 명시적 pixel goal을 point goal로 변환한다. 그런 다음 iPlanner와 NavDP 같은 state-of-the-art point-goal navigation policy를 통합해 System 1을 local planner로 대체한다. 표 4는 oracle depth를 사용해도 이 modular pipeline이 dual-system 접근보다 낮은 성능을 냄을 보여준다. 이 격차에는 두 가지 핵심 요인이 있다. (1) point-goal planner가 만드는 trajectory와 System 2의 training data 사이의 distribution gap이 pixel-goal prediction을 저하시킨다. (2) System 1의 강한 vision-based obstacle-avoidance behavior는 올바른 방향의 작은 pixel-goal deviation에도 정확하고 obstacle-aware한 trajectory를 유지하게 하지만 크거나 의미론적으로 잘못된 goal에는 그렇지 않다(그림 8). 반대로 point-goal은 pixel goal을 world-coordinate point로 직접 projection하므로 사소한 pixel error에도 매우 민감하다.

System 1의 Data Scaling 분석

System 2의 data scaling에서는 NaVILA와 StreamVLN과 유사하게 data가 다양할수록 성능이 일관되게 좋아지는 추세를 관찰하며, 이는 VLM의 data-hungry 성격을 반영한다. 반면 그림 9의 System 1은 다른 scaling behavior를 보인다. 가볍고 빠르게 설계되었고 task 자체도 비교적 단순하므로 System 2를 위해 수집한 trajectory의 1%만 사용해도 경쟁력 있는 성능을 얻는다. 10%로 늘리면 거의 포화하고 50%로 더 늘려도 유의미한 추가 이득이 없다. 이는 System 2가 정하는 성능 상한에 도달했음을 나타낸다.

Pixel Goal과 Trajectory의 일관성

Trajectory prediction이 pixel goal의 강한 안내를 받는지 검증하기 위해 predicted trajectory point를 image plane에 projection하여 일관성을 분석한다. VLN-CE benchmark에서 서로 다른 SR을 보인 DualVLN model들로부터 random sample 1,000개를 사용해 두 metric, 즉 projected trajectory와 pixel goal 사이의 pixel distance와 평균 angular deviation을 계산한다. 그림 10에서 대부분 point가 plot의 왼쪽 아래에 집중되어 있어 trajectory가 pixel goal을 향하고 pixel goal 근처 영역에 도달함을 보여준다.

6. 결론

본 연구는 고수준 semantic grounding과 저수준 action 실행을 분리한 dual-system vision-language navigation 파운데이션 모델 DualVLN을 제시했다. 명시적 pixel-grounded waypoint와 암묵적 latent goal representation을 결합함으로써 DualVLN은 기존 end-to-end 및 modular 접근보다 더 견고하고 효율적이며 일반화 가능한 navigation을 실현한다. Dual-system joint training framework는 semantic reasoning과 motion control 사이의 간극을 연결하여 더 부드러운 trajectory를 만들고 다양한 환경과 task에서 강한 성능을 보인다. DualVLN이 미래 embodied navigation system을 위한 유연하고 확장 가능한 토대를 제공하며, 더 general-purpose하고 multimodal이며 현실 배치에 준비된 embodied agent를 향한 후속 연구를 촉진하기를 기대한다.

A.2 System 1: Diffusion-Based Trajectory Policy

Discrete Action Waypoint의 Smoothing 및 Resampling

Discrete action waypoint는 interpolation으로 부드럽고 고정 간격인 trajectory waypoint 32개로 변환한다.

QwenVL에서 Latent Representation 추출

System 1에 pixel goal의 정보성 높은 latent representation을 제공하기 위해 pixel-goal grounding data의 text sequence 끝에 특수 token <TRAJ> 네 개를 붙인다. 예시는 다음과 같다.

User: <observation t>
Assistant: ↓
User: <look-down observation t>
Assistant: (234, 447)
<TRAJ><TRAJ><TRAJ><TRAJ>

이 latent query는 forward pass 전에 QwenVL embedding에 삽입된다.

inputs_embeds = QwenVLModel.embed_tokens(input_ids)
traj_token_idx = (input_ids == TRAJ_TOKEN_INDEX)
inputs_embeds[traj_token_idx] = latent_queries
hidden_states = QwenVLModel.forward(inputs_embeds)
pixel_goal_latents = hidden_states[-1][:, -N_QUERY:, :]

추출한 latent representation은 DiT 기반 diffusion policy에 입력되어 부드럽고 obstacle-aware한 trajectory를 생성한다.

x = Trajectory_Encoder(gt_rel_pose_list)  # relative pose
noise_pred = DiT(x, timestep, pixel_goal_latents)

학습

Trajectory supervision에는 pixel-goal grounding sample만 사용한다. QwenVL은 freeze하고 다음 module만 학습한다.

  1. Latent Query: freeze한 QwenVL에서 latent goal representation을 추출하는 learnable embedding이다.
  2. DiT-Based Diffusion Policy: latent goal representation을 조건으로 부드럽고 obstacle-aware한 world-coordinate trajectory를 생성한다.

Stage 2는 parameter-efficient 방식으로 obstacle-aware trajectory를 예측하도록 latent representation과 diffusion policy를 end-to-end로 학습한다. DualVLN의 점진적 2-stage training은 일반화된 pixel-goal grounding과 견고한 trajectory 실행을 모두 보장한다. 초기 learning rate 1e-4인 AdamW optimizer, trajectory sample batch size 128을 사용해 총 15,000 step 학습한다.

B. Pixel-Goal Grounding의 Attention Map 분석

System 2(QwenVL)가 pixel goal을 어떻게 ground하는지 더 깊이 이해하기 위해 언어 지시와 historical video frame 및 현재 관측을 포함한 visual input 모두에 대한 attention map을 시각화한다. 그림 11에는 서로 다른 transformer layer의 attention map을 제시하여 다음 pixel goal을 예측할 때 모델이 multimodal context의 어떤 측면에 attention하는지 보여준다.

얕은 transformer layer에서 모델은 주로 language token과 visual token 모두에 나타나는 object, scene layout, directional clue 같은 일반적 context 및 spatial cue에 attention한다. Transformer layer가 깊어질수록 attention은 특정 target pixel-goal region에 점차 집중한다. 이는 넓은 scene 및 semantic context 이해에서 정확하고 goal-directed인 pixel localization으로 점진적으로 정제됨을 나타낸다.

가장 깊은 transformer layer에서는 다음 action을 예측할 때 모델이 STOP token에 상당한 attention weight를 부여하는 것도 관찰된다. 이는 모델이 모든 layer에 걸쳐 visual input과 language input의 cue를 통합하여 task completion에 대한 최종 결정을 내림을 보여준다.
