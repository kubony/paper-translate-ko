초록

최근 대규모 vision-language model(VLM)은 vision-language navigation(VLN)의 일반화 성능을 높였지만, 기존 방법은 대체로 vision-language 입력을 짧은 horizon의 이산 action으로 곧바로 변환하는 end-to-end pipeline에 의존한다. 이 구조는 움직임을 분절시키고 latency를 키우며, 동적 장애물 회피와 같은 현실 환경의 문제에 제대로 대응하기 어렵다.

본 연구는 고수준 reasoning과 저수준 action 실행을 상호보완적으로 결합한 최초의 dual-system VLN 파운데이션 모델 DualVLN을 제안한다. VLM 기반 global planner인 System 2는 image-grounded reasoning으로 중기 waypoint goal을 예측하여 “천천히 ground”한다. 경량 multimodal-conditioned Diffusion Transformer policy인 System 1은 명시적 pixel goal과 System 2가 추출한 latent feature를 함께 조건으로 사용하여 부드럽고 정확한 trajectory를 생성하고 “빠르게 움직인다”. 이 구조는 복잡하고 동적인 환경에서 견고한 실시간 control과 상황 적응형 local decision-making을 지원한다. 두 system의 학습을 분리하면 VLM의 일반화 성능을 보존하면서 System 1을 해석 가능하고 효과적인 local navigation에 맞게 훈련할 수 있다. DualVLN은 논문에서 평가한 모든 VLN benchmark에서 선행 방법을 능가했으며, 현실 실험에서도 견고한 장기 horizon planning과 동적 환경에 대한 실시간 적응성을 보였다.

1. 서론

Vision-Language Navigation(VLN)은 robotics의 핵심 과제이다. VLN system은 시각 관측과 언어 지시를 입력받아 goal까지 이동할 trajectory를 계획한다. 이 분야의 benchmark는 이산적인 goal planning에서 continuous action space로, 나아가 locomotion controller를 포함한 물리적으로 사실적인 simulation으로 발전해 왔다. 동시에 대규모 VLM이 보유한 풍부한 사전 지식을 post-training으로 전이하면, 다양한 지시와 환경에 걸쳐 VLN system의 일반화 범위를 크게 넓힐 수 있다.

그러나 continuous VLN benchmark에서도 기존 Vision-Language-Action(VLA) model은 대체로 vision·language 입력을 짧은 horizon의 이산 action(예: 0.25 m 전진)에 직접 매핑하는 강결합 end-to-end paradigm을 사용한다. 이 구조는 현실 배치에서 두 가지 중대한 한계를 드러낸다. 첫째, action이 잘게 끊겨 움직임이 부자연스럽고, 매 step마다 대형 VLM을 호출해야 하므로 실행 latency가 높다. 둘째, vision-language reasoning, global planning, local control을 한 pipeline에 묶기 때문에 서로 다른 의사결정 계층을 명시적으로 조율하기 어렵다. 그 결과 민첩한 control이나 동적 장애물 회피와 같은 요구를 충족하지 못한다.

이 한계를 해결하기 위해 본 연구는 VLM의 reasoning 능력과 실시간 control의 민첩성을 명시적으로 이어 주는 최초의 dual-system VLN 파운데이션 모델 DualVLN을 제안한다. DualVLN은 VLN pipeline을 상호보완적인 두 system으로 나눈다. 대형 foundation VLM인 System 2는 느리지만 견고하게 reasoning하여 명시적 중간 pixel goal을 출력한다. 경량 diffusion-based policy인 System 1은 이렇게 ground된 target을 연속적이고 주행 가능한 trajectory로 바꾸어 동적 상황에서도 collision avoidance를 수행한다. 두 system은 latent representation으로도 연결된다. 먼저 pixel-goal grounding task로 System 2를 훈련한 뒤 그 파라미터를 고정한다. 그 다음 learnable latent query를 추가하여 prompt tuning으로 최적화한다. 이 query는 System 2의 context에서 compact latent feature를 추출하며, System 1에는 implicit goal로 전달된다.

왜 분리된 순차 학습인가?

학습을 분리하면 두 system을 각 역할에 맞게 전문화할 수 있다. System 2는 대규모 multi-source reasoning data로 확장해 훈련할 수 있는 반면, System 1에는 비교적 적은 양의 low-level goal-reaching data만 필요하다. 실행 시 System 1은 빠른 갱신 주기의 추가 RGB 입력과 비동기 inference를 이용하여 동적 환경에서 더 높은 control frequency로 동작한다. 무엇보다 downstream low-level planning에 맞추는 동안 System 2의 파라미터를 고정하므로 VLM의 일반화 능력을 보존한다.

왜 명시적 pixel goal과 암묵적 latent goal을 모두 사용하는가?

System 1을 명시적 2D pixel goal만으로 안내하면 VLM의 풍부한 hidden feature를 충분히 활용하지 못한다. 그러면 reasoning과 local planning의 연결이 얕아져 dual-system이 단순한 modular pipeline에 머문다. 명시적 pixel goal을 학습하면 System 2의 판단을 해석하기 쉬워지고 일반화에도 도움이 된다. 여기에 implicit latent feature를 함께 제공하면 System 1은 더 풍부하고 상황 적응적인 안내를 받을 수 있으며, VLM hidden state에 들어 있는 여러 종류의 정보에서 task와 관련된 representation을 자동으로 추출할 수 있다.

실험에서 DualVLN은 VLN-CE와 VLN-PE benchmark 모두에서 기존 state of the art를 일관되게 앞섰다. 여러 robot platform과 다양한 scenario에서 수행한 현실 평가는 장기 horizon을 견고하게 계획하고 trajectory를 실시간으로 실행하며 동적 장애물을 피할 수 있음을 보였다. 또한 본 연구는 task trajectory를 따라 humanoid agent를 배치한 동적 환경에서 navigation model의 social awareness와 우회 후 task trajectory로 복귀하는 능력을 평가하는 최초의 Social-VLN benchmark를 제안한다.

2. 관련 연구

Navigation을 위한 Vision-Language-Action Model

최근 연구는 multimodal large model을 navigation의 pretrained backbone으로 삼고, 그 안에 축적된 상식 지식으로 성능을 높이려 한다. 대표적인 방법은 navigation action을 text로 표현하여 LLM의 next-token prediction 문제로 푸는 것이다. RoboPoint와 NaviMaster는 navigation을 pixel grounding 문제로 정의하지만, 실제 실행에는 별도 module이 필요하다. UniVLA와 TrackVLA 같은 end-to-end 방법은 VLM latent feature를 continuous trajectory에 직접 매핑하지만, 동기식 framework이므로 동적 환경에서 빠른 주기의 의사결정을 내리기 어렵다. 일부 최신 dual-system architecture도 slow-fast reasoning을 다루지만 tabletop task에 초점을 맞추며 장기 horizon planning이나 건물 사이의 navigation은 다루지 않는다. 본 연구는 장기 horizon instruction following, 정밀한 planning, 미관측 환경 navigation을 모두 지원하는 최초의 비동기 dual-system architecture를 제안한다.

Visual Navigation Policy Learning

Visual navigation policy는 명시적 goal로 이동하는 동시에 장애물을 실시간으로 피해야 한다. 전통적인 modular 접근은 명시적 localization과 mapping에 의존하므로 오차 누적, latency, 많은 hyperparameter 조정이라는 문제가 있다. 이를 해결하고자 end-to-end learning-based 방법이 제안되었다. GNM, X-Nav, RING, X-Mobility는 서로 다른 embodiment로의 zero-shot generalization을 개선하고, iPlanner, ViPlanner, FDM, S2E는 효율적인 학습과 sim-to-real transfer에 초점을 둔다. SLING, ViNT, NoMaD, NaviDiffuser는 image-goal navigation을 탐구했다. 본 연구의 System 1은 VLM에서 얻은 latent goal을 조건으로 사용하는 RGB-only visual navigation policy이다.

3. 방법

그림 2의 framework는 고수준 reasoning과 저수준 action 실행이 상호보완적으로 작동하도록 dual-system으로 설계되었다. VLM-based planner인 System 2는 image pixel space에서 중기 waypoint를 예측하여 공간적으로 ground된 target을 제공하는 global planning을 담당한다. multimodal goal-conditioned diffusion policy인 System 1은 현재 관측과 System 2가 비동기로 제공하는 latent feature를 조건으로 continuous trajectory를 생성하여, 복잡한 환경에서도 견고한 실시간 control을 수행한다.

3.1 System 2: 자율적 시야 조정을 결합한 VLM 기반 Pixel-Goal Grounding

System 2는 고수준 pixel-goal grounding과 자율적 시야 조정을 반복적 과정으로 통합한다. 매 navigation step에서 System 2는 현재 RGB frame과 이전 관측 이력을 보고, 먼저 camera 시야를 바꿀지 아니면 현재 frame에서 다음 waypoint의 pixel goal을 바로 출력할지를 결정한다. 따라서 목표 지점이 가려졌거나 camera가 부적절한 방향을 향한 경우에는 목표를 판별하기에 적합한 시야를 먼저 확보한 뒤 pixel goal을 예측할 수 있다.

현재 시야에서 확인 가능한 최원거리 Pixel Goal Grounding

Goal planning module은 image pixel coordinate 수준의 spatial grounding 능력을 갖춘 open-source VLM Qwen2.5-VL을 기반으로 한다. 이를 VLN에 적용하기 위해 high-level planning을 “현재 시야에서 확인 가능한 trajectory point 중 agent로부터 가장 먼 point의 pixel coordinate를 예측하는 문제”로 정의한다. 모델은 언어 지시와 1인칭 RGB image sequence를 입력받아 선호하는 다음 navigation waypoint의 image 내 2D coordinate를 출력한다. 학습 sample을 만들 때는 agent의 3D trajectory를 2D egocentric observation에 투영하기에 앞서 각 point의 가시성을 판정한다. label 생성 pipeline은 simulator depth map에서 해당 pixel의 depth 값과 camera–point 거리를 비교하며, point 거리가 depth 값보다 크면 다른 표면 뒤에 가려진 것으로 보고 제외한다. 이 projection 결과를 바탕으로 원래 VLN-CE trajectory를 pixel-goal grounding 학습 sample로 나눈다. 이 depth map은 pixel-goal grounding 학습 sample을 생성할 때 point의 가시성을 판정하는 데 사용된다.

자율적 시야 조정

3D trajectory를 2D pixel coordinate로 투영할 때는 몇 가지 문제가 발생한다. Camera가 지나치게 위를 향하면 바닥의 trajectory point가 가려질 수 있고, 이를 피하려 point의 높이를 인위적으로 올리면 depth ambiguity가 생겨 실제 target 위치가 불분명해진다. 또한 agent가 엉뚱한 방향을 바라보면 다음 waypoint가 현재 field of view 밖에 놓인다. 사람이 다음 waypoint를 정하기 전에 주변을 살피고 바닥 쪽으로 시선을 낮추는 행동에서 착안하여, System 2는 환경을 더 둘러볼지 camera angle을 바꿀지를 스스로 결정한다. 이때 Turn Left/Right 15°와 Look Up/Down 15° 같은 discrete action을 사용한다. 즉, System 2는 필요할 때 시야 조정 action을 먼저 출력하고, 목표 지점을 판별하기에 적합한 관측을 얻은 뒤 pixel goal을 출력한다.

3.2 System 1: Multimodal Conditioning을 사용하는 Diffusion Transformer Policy

Latent Goal Representation

System 2가 다음 pixel goal을 autoregressive하게 생성하는 과정에서 VLM은 언어 지시, 이전 image, 현재 관측, view-adjustment action, pixel-goal 정보를 포괄하는 context feature sequence X를 만든다. 여기에 무작위로 초기화하고 prompt tuning으로 업데이트하는 learnable latent query 집합 Z를 붙인다. 결합 sequence [X; Z]를 VLM에 통과시키면 Z가 X를 attention하여 task-relevant semantic information을 추출한다. 그 출력 Z′가 중간 latent goal representation이며, System 1은 이를 저수준 trajectory 생성의 조건으로 사용한다.

Multi-Modal Conditioning Diffusion Transformer

System 1은 robot이 따라갈 조밀한 waypoint 32개로 이루어진 부드러운 trajectory를 생성하는 Diffusion Transformer(DiT)이다. DiT는 두 종류의 condition을 받는다. 하나는 System 2가 느린 주기로 갱신하는 trajectory latent Z′이고, 다른 하나는 System 1의 빠른 실행 주기마다 최신 RGB로 갱신되는 visual condition이다.

두 system은 비동기로 inference한다. 따라서 System 2가 time t에 생성한 latent goal은 다음 planning update 전까지 고정된다. System 1은 time t+k의 fast-policy tick에서 그 latent goal을 계속 해석하되, 그동안 이동한 거리와 환경의 동적 변화를 반영하여 trajectory를 다시 생성해야 한다.

이를 위해 System 1은 time t에 System 2가 사용한 마지막 RGB frame과 time t+k의 현재 관측을 encode한다. 두 image는 먼저 ViT encoder로 처리되어 고차원 visual feature로 변환된다. 두 시점의 feature는 self-attention module로 결합되고, 결합된 feature는 Q-Former를 통해 compact한 32개 token으로 압축된다. 이 token은 DiT의 high-frequency visual condition으로 사용된다.

Flow Matching

다음 설명은 runtime sampling이 아니라 System 1의 학습 단계이다. ground-truth trajectory waypoint X₀와 두 condition인 trajectory latent Z′ 및 fused RGB token F가 주어지면, 각 training step에서 diffusion timestep u ~ U(0,1)과 noise vector ε ~ N(0,I)를 먼저 sample한다. noisy trajectory는 다음과 같이 정의한다.

Xᵤ = αᵤ X₀ + σᵤ ε                                      (1)

여기서 αᵤ는 u의 감소 함수이고 σᵤ는 u의 증가 함수이다. Diffusion Transformer는 Z′와 F를 조건으로 timestep u에서 trajectory velocity Ẋᵤ를 예측하도록 학습한다.

Ẋ̂ᵤ = fθ(Xᵤ, u, Z′ ⊕ F)                                 (2)

⊕는 concatenation이고 fθ는 transformer network이다. 학습 objective는 예측 velocity와 true velocity 사이의 mean squared error를 최소화한다.

L_flow = E_(u,X₀,ε) [ ‖Ẋ̂ᵤ − Ẋᵤ‖₂² ]                    (3)

3.3 구현 세부사항

System 2 학습에서는 StreamVLN의 data recipe에 따라 Qwen2.5-VL(7B)을 한 epoch finetuning하며, vision encoder와 LLM backbone을 모두 업데이트한다. 이어지는 System 1 학습에서는 pixel goal 예측 뒤에 learnable latent query 네 개를 붙여 compact latent goal embedding을 추출한다. System 1의 RGB encoder는 DepthAnythingV2-Small의 ViT backbone으로 구현한다. low-latency runtime을 위해 DiT는 hidden dimension 384, transformer layer 12개, attention head 6개로 작게 설계한다. latent embedding은 DiT와 cross-attention하기 전에 3584차원에서 768차원으로 linear projection한다. 자세한 학습 절차는 부록 A에 제시한다.

4. Social Vision-and-Language Navigation Benchmark

Generalist navigation model이 발전해 왔지만, task-oriented navigation을 수행하는 도중 동적 장애물에 대응하는 능력을 평가하도록 설계된 benchmark는 아직 없다. 사람이 함께 있는 환경에서 robot은 collision을 피해야 할 뿐 아니라 우회한 뒤 원래 task trajectory로 복귀해야 하므로 이 능력이 중요하다. VLN-CE benchmark는 정적 layout에 초점을 맞추기 때문에 동적 환경에서의 social awareness와 trajectory recovery를 평가하지 못한다.

Benchmark 구축

Dual-system 설계의 중요성을 보여 주고 generalist navigation agent의 발전을 촉진하기 위해, 기존의 정적 VLN 평가를 동적 scenario로 확장한다. Social-VLN은 R2R-CE를 바탕으로 만든 새 benchmark이며, Habitat 3.0의 humanoid로 모델링한 dynamic pedestrian agent 여러 명을 simulation에 넣는다. 이 humanoid들을 임의의 start와 goal 사이에서 무작위로 걷게 하지 않고 ground-truth VLN trajectory 주변에 전략적으로 배치한다. VLN task가 대부분 비교적 짧은 구간을 다루기 때문에 이러한 표적 배치는 robot과 humanoid의 조우 확률을 크게 높여 더 어렵고 현실적인 social VLN test를 만든다.

그림 3은 단일 또는 여러 humanoid가 등장하는 다양한 robot–humanoid interaction 상황을 보여 준다. Benchmark를 검수할 때는 각 episode에서 agent가 경로를 완전히 막지 않는지 확인하여, 실패가 단순한 물리적 방해만을 반영하지 않게 한다. 표준 VLN metric에 더해 dynamic pedestrian과의 unsafe interaction으로 인한 실패를 수량화하는 Human Collision Rate(HCR)를 도입한다. Social-VLN은 task completion과 함께 동적 환경에서 navigation agent의 safety awareness를 평가한다.

번역·원문 대조 메모(논문 본문 아님). 원문 제공 범위에서 HCR 산식의 분모/contact threshold/episode-vs-step 집계를 제시하지 않는다.

학습 데이터 수집

위의 benchmark curation과는 별도로, 동적 obstacle-avoidance trajectory를 만드는 학습 데이터 pipeline도 구축한다. 각 training episode에서 human detection sensor가 egocentric view를 계속 관찰한다. human mask pixel ratio가 미리 정한 threshold를 넘으면 modified A* algorithm을 실행하여 collision-free demonstration trajectory를 다시 계획한다. 이 절차로 60개 MP3D scene에서 763K social navigation episode를 생성했으며, socially compliant agent를 훈련하기 위한 기반 resource로 사용한다.

5. 실험

5.1 Simulation 실험

VLN-CE Benchmark와 Metric

먼저 Habitat simulator의 VLN-CE setting으로 구축된 표준 R2R-CE와 RxR-CE benchmark에서 모델을 평가한다. 두 benchmark는 Matterport3D 환경의 현실적인 실내 navigation을 simulation하며, agent는 continuous control로 자연어 지시를 따른다. 일반화 성능을 측정하기 위해 모든 실험은 validation unseen split에서 수행한다. Navigation Error(NE)는 episode 종료 시 goal까지 남은 거리이다. Success Rate(SR)는 agent가 goal 3 m 이내에서 멈춘 episode의 비율이다. Oracle Success Rate(OSR)는 실행 trajectory에서 goal에 가장 가까웠던 point를 기준으로 성공 여부를 판단한다. Success weighted by Path Length(SPL)은 성공 여부에 비효율적으로 긴 path에 대한 penalty를 함께 반영한다.

VLN-PE Benchmark와 Metric

현실 배치의 robot dynamics와 control error를 simulation하는 물리적으로 사실적인 VLN platform VLN-PE에서도 모델을 평가한다. R2R dataset에서 humanoid Unitree H1 robot을 사용한 결과를 보고한다. 표준 VLN metric에 더해 Trajectory Length(TL), robot이 넘어진 빈도인 Fall Rate(FR), agent가 움직이지 못한 경우의 빈도인 Stuck Rate(StR)를 측정한다. 이 지표들은 continuous하고 물리적으로 사실적인 navigation scenario에서 system의 task 수행 능력과 견고성을 함께 평가한다.

5.2 현실 세계 Cross-Embodiment 실험

실험 설정

현실 실험에는 wheeled robot(Turtlebot4), quadruped(Unitree Go2), humanoid(Unitree G1)를 사용한다. 각 robot에는 장착 높이가 서로 다르고 아래쪽으로 15° 기울어진 Intel RealSense D455 camera가 달려 있다. 전체 모델은 RTX 4090 GPU를 갖춘 remote server에서 실행되며 약 20GB memory를 사용한다. Runtime에는 robot이 동기화된 RGB-D image를 remote server로 전송하고 dual-system model이 비동기 inference를 수행한다. Server가 출력한 trajectory 또는 discrete view-adjustment action은 odometry로 world coordinate에 변환한 뒤 MPC controller가 tracking한다. System 2는 KV-cache reuse를 사용하여 trajectory token inference 시간을 1.1초에서 0.7초로 줄인다. System 1은 TensorRT를 사용해 0.03초 안에 32개 trajectory를 병렬로 생성한다. 이 비동기 runtime pipeline은 최신 trajectory를 계속 공급하여 부드럽고 거의 실시간인 navigation을 가능하게 한다.

정량 분석

현실 환경에서 DualVLN의 견고성과 일반화를 정량 평가하기 위해 CMA 및 discrete action을 출력하는 VLM 기반 NaVid, NaVILA, StreamVLN과 비교한다. Hallway(쉬움), bedroom(중간), office(어려움, room-to-room)의 세 scenario에서 model별로 각각 20회 실행하고 SR과 NE를 측정한다. 그림 6에서 NaVid는 복잡한 task에 어려움을 겪고, NaVILA는 장기 horizon task를 처리하지만 office scenario의 최종 goal을 자주 놓친다. StreamVLN은 때때로 장애물을 피하지만 그 대가로 task completion 성능이 낮아진다. DualVLN은 정적·동적 scenario 모두에서 일관되게 높은 SR과 낮은 NE를 기록했다.

정성 분석

정성 결과는 보충 video에 제시한다. Scene-specific finetuning 없이 office, canteen, street, convenience store 등 다양한 현실 scenario에서 zero-shot으로 평가했다. DualVLN은 cluttered environment에서 올바른 pixel goal을 선택하고 안전한 trajectory를 생성하며, 지시가 요구한 landmark를 모두 지나는 부드러운 path를 계획한다. Staircase와 dynamic pedestrian에도 대응하고, camera 높이·진동·tracking이 서로 다른 여러 robot platform에서도 견고하게 동작한다.

5.3 Ablation Study

명시적 Pixel Goal 및 Latent Goal의 영향

System 1에 어떤 goal representation을 조건으로 주는지가 미치는 영향을 그림 7의 ablation으로 분석한다. 먼저 w/o Sys.2 Train은 제안한 순차 학습을 쓰지 않고, 명시적 intermediate pixel goal 없이 System 1과 System 2를 한 stage에서 end-to-end 공동 훈련하는 조건이다. 이 조건에서는 diffusion policy의 수렴이 크게 느려지고 System 2의 일반화 능력도 저하된다. 따라서 intermediate pixel goal을 사이에 둔 분리 학습이 효율적인 훈련과 VLM reasoning 능력 보존에 모두 중요하다.

둘째, w/o Pixel Goal은 System 1 학습 단계에서 latent query Z를 붙이기 전에 context sequence X의 명시적 pixel-goal text를 제거한 조건이다. 따라서 latent query는 명시적 pixel-goal 정보에 attention할 수 없다. 성능 하락은 명시적 pixel goal이 diffusion policy에 유용한 안내를 제공하고 해석 가능성과 일반화에도 기여함을 보여 준다.

마지막으로 w/o Latent Goal은 learnable latent query를 사용하지 않고, 생성된 pixel-goal text에 해당하는 VLM 마지막 layer의 고정 hidden state만 System 1 condition으로 쓰는 조건이다. 이 변형의 성능은 더 낮다. Latent query가 없으면 어떤 context 정보를 condition으로 추출할지를 학습할 수 없고, System 1은 미리 정해진 VLM feature를 수동적으로 받아야 한다. 그 결과 System 2에서 System 1로 전달되는 정보의 적응성이 제한된다.

System 1 대 SOTA Point-Goal Navigation Policy

Dual-system joint training framework의 이점을 검증하기 위해 평가용 변형에서 latent goal을 제거하고, 추가 depth 정보로 명시적 pixel goal을 3D point goal로 바꾼다. 이어 iPlanner와 NavDP 같은 state-of-the-art point-goal navigation policy가 System 1 대신 local planner 역할을 맡는다. 표 4는 oracle depth를 제공해도 이 modular pipeline의 성능이 제안한 dual-system보다 낮음을 보여 준다. 저자들은 두 가지 이유를 제시한다. 첫째, point-goal planner가 생성한 trajectory와 System 2 학습 data의 trajectory distribution이 달라 pixel-goal prediction이 저하된다. 둘째, 원래 System 1의 vision-based obstacle avoidance는 올바른 방향을 가리키는 작은 pixel-goal 오차가 있어도 정확하고 obstacle-aware한 trajectory를 유지하지만, 크거나 의미상 틀린 goal까지 보정하지는 못한다(그림 8). 반면 point-goal 방식은 pixel goal을 world-coordinate point로 직접 projection하므로 작은 pixel 오차에도 민감하다.

System 1의 Data Scaling 분석

System 2는 NaVILA와 StreamVLN에서 보고된 것처럼 학습 data가 다양해질수록 성능이 꾸준히 향상되며, 이는 VLM이 많은 data를 필요로 한다는 특성을 반영한다. 반면 그림 9에서 System 1은 다른 scaling 양상을 보인다. 모델이 가볍고 빠르게 설계되었고 맡은 task도 비교적 단순하므로, System 2용으로 수집한 trajectory의 1%만 사용해 훈련해도 경쟁력 있는 성능을 얻는다. 비율을 10%로 높이면 성능이 거의 포화하며 50%까지 늘려도 의미 있는 추가 이득이 없다. 저자들은 이를 System 2가 정하는 전체 성능 상한에 도달한 결과로 해석한다.

Pixel Goal과 Trajectory의 일관성

예측 trajectory가 pixel goal의 안내를 실제로 따르는지 확인하기 위해 trajectory point를 image plane에 projection하여 둘의 일관성을 분석한다. VLN-CE에서 서로 다른 SR을 보이는 DualVLN model들에서 random sample 1,000개를 뽑고, projected trajectory와 pixel goal 사이의 pixel distance 및 평균 angular deviation을 계산한다. 그림 10에서 대부분의 point가 plot 왼쪽 아래에 모여 있다는 것은 예측 trajectory가 pixel goal 방향을 향하며 그 주변 영역에 도달한다는 뜻이다.

6. 결론

본 연구는 고수준 semantic grounding과 저수준 action 실행을 분리한 dual-system vision-language navigation 파운데이션 모델 DualVLN을 제시했다. 명시적 pixel-grounded waypoint와 암묵적 latent goal representation을 함께 사용함으로써, DualVLN은 기존 end-to-end 및 modular 접근보다 견고하고 효율적이며 일반화 가능한 navigation을 구현한다. 제안한 dual-system joint training framework는 semantic reasoning과 motion control 사이를 연결하여 더 부드러운 trajectory를 생성하고 다양한 환경과 task에서 높은 성능을 보였다. 저자들은 DualVLN이 미래 embodied navigation system을 위한 유연하고 확장 가능한 토대가 되고, 더 general-purpose하고 multimodal하며 현실 배치에 적합한 embodied agent 연구를 촉진하기를 기대한다.

A. 데이터 준비 및 학습 세부사항

A.1 System 2: Qwen2.5-VL

Stage 1에서 System 2는 agent의 관측과 지시를 바탕으로 self-directed view adjustment, pixel-goal grounding, STOP action 가운데 알맞은 출력 유형을 예측하도록 훈련된다.

Discrete Ground-Truth Action Set

0: STOP, 1: 앞으로 25 cm 이동, 2: 왼쪽으로 15° 회전, 3: 오른쪽으로 15° 회전

User Prompt Template

User: 당신은 자율 navigation assistant이다. 당신의 task는
<instruction>이다. 경로를 유지하려면 다음에 어디로 가야 하는가?
image에서 다음 waypoint의 coordinate를 출력하라.
task를 성공적으로 완료했다면 STOP을 출력하라.
다음은 historical observation이다: <history>.

Self-Directed View Adjustment

미래 trajectory를 현재 관측에 projection할 수 없는 경우, 예컨대 연속 turn action이 시작되는 지점에서는 System 2가 pixel goal 대신 앞으로 수행할 turn action을 예측한다. 한 chunk에서 연속 turn action은 최대 네 개까지 출력한다.

대화 예시는 다음과 같다.

User: 당신은 자율 navigation assistant이다. ... <history>.
      현재 관측은 <image>이다.
Assistant: → → → →  (오른쪽으로 60° 회전에 해당)

Pixel-Goal Grounding

미래 waypoint가 현재 관측에 하나 이상 보이면 System 2는 현재 image에 성공적으로 projection된 waypoint 중 agent로부터 가장 먼 waypoint를 pixel goal로 예측하도록 supervision을 받는다.

대화 예시는 다음과 같다.

User: 당신은 자율 navigation assistant이다. ... <history>.
      현재 관측은 <image>이다.
Assistant: ↓  (다음 pixel goal이 view 안에 있음을 나타냄)
User: 현재 관측은 <image>이다. (아래를 보는 action은 선택 사항)
Assistant: 234 447  # Pixel goal text

STOP

Trajectory의 마지막 step에서는 System 2가 STOP을 출력하도록 supervision을 받는다.

User: 당신은 자율 navigation assistant이다. ... <history>.
      현재 관측은 <image>이다.
Assistant: STOP

학습

Stage 1에서는 Qwen2.5-VL 전체를 finetuning하여 vision-language context에 따라 turn-action sequence, coordinate text, STOP 중 하나를 자율적으로 생성하게 한다. AdamW optimizer의 초기 learning rate는 2e-5이다. Batch 하나에는 conversation sample 128개가 들어가며 총 14,000 step 훈련한다.

A.2 System 1: Diffusion-Based Trajectory Policy

Discrete Action Waypoint의 Smoothing 및 Resampling

학습 trajectory를 준비할 때 discrete action waypoint를 interpolation하여 간격이 일정하고 부드러운 trajectory waypoint 32개로 변환한다.

Qwen2.5-VL에서 Latent Representation 추출

System 1에 pixel goal을 잘 나타내는 latent representation을 제공하기 위해 pixel-goal grounding data의 text sequence 끝에 특수 token <TRAJ> 네 개를 붙인다. 예시는 다음과 같다.

User: <observation t>
Assistant: ↓
User: <look-down observation t>
Assistant: (234, 447)
<TRAJ><TRAJ><TRAJ><TRAJ>

이 네 latent query embedding은 forward pass 전에 Qwen2.5-VL의 input embedding sequence에 삽입된다.

inputs_embeds = QwenVLModel.embed_tokens(input_ids)
traj_token_idx = (input_ids == TRAJ_TOKEN_INDEX)
inputs_embeds[traj_token_idx] = latent_queries
hidden_states = QwenVLModel.forward(inputs_embeds)
pixel_goal_latents = hidden_states[-1][:, -N_QUERY:, :]

추출된 latent representation은 DiT 기반 diffusion policy의 condition으로 전달되고, policy는 부드럽고 obstacle-aware한 trajectory를 생성하도록 학습된다.

x = Trajectory_Encoder(gt_rel_pose_list)  # relative pose
noise_pred = DiT(x, timestep, pixel_goal_latents)

학습

Stage 2의 trajectory supervision에는 pixel-goal grounding sample만 사용한다. 이 단계에서는 Qwen2.5-VL 파라미터를 고정하고 다음 module만 업데이트한다.

  1. Latent Query: 고정된 Qwen2.5-VL context에서 latent goal representation을 추출하는 learnable embedding이다.
  2. DiT-Based Diffusion Policy: latent goal representation을 조건으로 부드럽고 obstacle-aware한 world-coordinate trajectory를 생성한다.

즉, Stage 2의 “end-to-end”는 고정 VLM까지 다시 훈련한다는 뜻이 아니라, latent representation을 만드는 query와 diffusion policy를 하나의 trajectory objective로 함께 최적화한다는 뜻이다. 이 parameter-efficient 학습은 obstacle-aware trajectory 예측에 맞춰 두 module을 업데이트한다. DualVLN의 점진적 two-stage training은 Stage 1의 일반화된 pixel-goal grounding을 보존하면서 Stage 2에서 견고한 trajectory 실행을 학습하도록 설계되었다. AdamW optimizer의 초기 learning rate는 1e-4이고, batch size는 trajectory sample 128개이며, 총 15,000 step 훈련한다.

B. Pixel-Goal Grounding의 Attention Map 분석

System 2(Qwen2.5-VL)가 pixel goal을 ground할 때 무엇을 참조하는지 살펴보기 위해, 언어 지시와 이전 video frame 및 현재 관측을 포함한 visual input에 대한 attention map을 시각화한다. 그림 11은 서로 다른 transformer layer의 attention map을 보여 주며, 다음 pixel goal을 예측할 때 multimodal context의 어느 부분에 weight가 배분되는지 나타낸다.

얕은 transformer layer에서는 language token과 visual token의 object, scene layout, 방향 단서처럼 넓은 맥락과 공간 단서에 주로 attention한다. Layer가 깊어질수록 attention weight는 특정 target pixel-goal 영역에 점차 집중한다. 저자들은 이를 scene과 semantic context에 대한 폭넓은 이해가 goal-directed pixel localization으로 점진적으로 정제되는 과정으로 해석한다.

가장 깊은 transformer layer에서는 다음 action을 예측할 때 STOP token에도 큰 attention weight가 배분된다. 저자들은 이 관찰을 모델이 여러 layer에 걸쳐 시각·언어 단서를 통합하여 task 완료 여부를 최종 판단한다는 근거로 제시한다.
