초록

성공적인 범용(generalist) Vision-Language-Action(VLA) 모델은 대규모의 cross-embodiment, 이질적(heterogeneous) 데이터셋을 사용해 다양한 로봇 플랫폼에 걸쳐 효과적으로 학습하는 데 의존한다. 풍부하고 다양한 로봇 데이터 소스가 지닌 이질성을 촉진하고 활용하기 위해, 본 연구는 추가 파라미터가 최소한으로만 늘어나는 새로운 Soft Prompt 접근법을 제안한다. 이는 prompt learning 개념을 cross-embodiment 로봇 학습에 이식하고, 각각의 서로 다른 데이터 소스마다 별도의 학습 가능한 임베딩(learnable embedding) 집합을 도입하는 방식이다. 이러한 임베딩은 embodiment별 prompt로 기능하며, 하나로 결합되어 VLA 모델이 다양한 cross-embodiment 특징을 효과적으로 활용하도록 만든다. 본 연구의 새로운 모델 X-VLA는 flow-matching 기반의 간결한 VLA 아키텍처로서, 전적으로 soft-prompt가 적용된 표준 Transformer encoder에만 의존하여 확장성(scalability)과 단순성(simplicity)을 모두 누린다. 6개 시뮬레이션과 3개 실세계 로봇에서 평가한 결과, 본 연구의 0.9B 규모 인스턴스인 X-VLA-0.9B는 여러 벤치마크에 걸쳐 동시에 SOTA 성능을 달성하여, 유연한 손재주(dexterity)에서부터 embodiment·환경·과제 전반에 걸친 빠른 적응(adaptation)에 이르기까지 넓은 능력 축(axis)에서 우수한 결과를 보인다. 웹사이트: https://thu-air-dream.github.io/X-VLA/

1. 서론(Introduction)

다음 두 가지가 가능한 자율 에이전트(autonomous agent)를 구축하는 것은 로봇 학계의 오랜 핵심 목표였다: (1) 임의의 인간 지시를 유연하게 따르는 것, 그리고 (2) 다양한 환경과 이질적인 embodiment 전반에 걸쳐 능숙하게 조작(operate)하는 것. 최근 Large Language Model(LLM)과 Vision-Language Model(VLM)이 거둔 성공에 힘입어, 유망한 한 가지 방향은 이러한 진보된 아키텍처에 정밀한 action modality를 통합함으로써 이를 로봇공학으로 확장하고, 그렇게 하여 Vision-Language-Action(VLA) 모델을 탄생시키는 것이다. 이러한 대형 VLA 모델이, 단순한 pick-and-place 조작에서부터 복잡한 dexterous 과제에 이르기까지, 즉시 사용 가능한(out-of-the-box) 일반화 능력과 견고한 조작 능력을 결합할 수 있으리라는 기대가 본질적으로 깔려 있다.

VLA 모델의 성공, 특히 분포 외(out-of-distribution, OOD) 도메인에 빠르게 적응하는 능력은, 광범위한 로봇 시스템 아키텍처와 넓은 범위의 과제 시나리오를 포괄하는 대규모의 다양한 로봇 데이터셋으로 사전학습하는 데에 달려 있다. 여기서 핵심 난제는 VLA 모델이 하드웨어 구성에서부터 데이터 수집 전략에 이르기까지 상당한 이질성에 직면한다는 점이다. 이러한 이질성은 embodiment별 action space에서뿐만 아니라, 카메라 설정·시각 도메인(visual domain)·과제 분포 같은 설정(setup) 변이에서도 나타난다. 이처럼 다양한 차원의 다양성은 embodiment 전반에 심각한 분포 이동(distributional shift)과 유의미한 의미론적 불일치(semantic misalignment)를 유발하여 모델을 혼란시키고, 결국 만족스럽지 못한 사전학습·적응 성능으로 이어진다. 기존 VLA 방법들은 주로 embodiment별 action space를 수용하기 위해 별도의 action decoder head를 할당하는 데 초점을 두었고, 이질성의 다른 중요한 원천들은 불가피하게 간과되었다. 그러나 이러한 이질적 구성들 사이의 조정(reconciliation)은 proprioceptive(고유수용성)를 인식하는 추론과, 이질적이고 혼합된 도메인의 데이터셋으로부터 공유 지식을 증류(distill)하는 데 매우 중요하다. 이는 다음 이유들로 인해 여전히 미해결 문제로 남아 있다: (1) 하드웨어 플랫폼 간의 비일관성, (2) 표준화된 데이터 수집 프로토콜의 부재, 그리고 (3) embodiment와 환경 장벽을 가로질러 발생하는 본질적인 도메인 이동.

본 연구는 VLA 모델이 도메인별 하드웨어 구성을 단순한 Soft Prompt 메커니즘을 통해 학습하도록 허용함으로써, 이러한 장애물들을 최소한의 인간 노력으로 효과적으로 극복할 수 있음을 보인다. meta-learning과 multi-task learning의 통찰에서 영감을 받아, 우리는 로봇공학 영역의 다양한 하드웨어 구성과 데이터 유형을 과제 특화 특징(task-specific feature)의 틀로 재구성하며, 이는 prompt-learning 기법으로 효과적으로 포착될 수 있다. 구체적으로, 앞서 언급한 다양한 차원의 이질성을 모델링하기 위해, 우리는 각 데이터 소스에 학습 가능한 임베딩 집합을 Soft Prompt로서 할당한다. 이러한 임베딩은 feature fusion의 초기 단계부터 VLA 표현 공간을 구조화하기 위한, 이질성을 인식하는(heterogeneity-aware) 안내를 제공하여, VLA 모델이 cross-embodiment 변이를 활용·통합하는 능력을 강화하고 서로 다른 하드웨어·과제 구성 전반의 일반화를 개선한다.

공식적으로, 우리는 이질적 플랫폼 전반에서 동작하는 범용 flow-matching 기반 VLA 프레임워크인 Soft-prompted Transformer, 즉 X-VLA를 도입한다. Soft Prompt를 통해 X-VLA는 명시적으로 학습된 개별 하드웨어 설정에 의해 안내되어 다양한 시스템·데이터 구조를 수용할 수 있다. 다중 시점(multi-view) 이미지, 언어 prompt, proprioceptive 특징을 동시에 인코딩하기에 적합한 다재다능한 아키텍처를 갖춘 X-VLA는, 멀티모달 feature fusion과 정밀한 action 생성을 위해 표준 Transformer encoder를 단순히 쌓는 것만으로 확장 가능한 VLA 학습을 가능케 한다. 광범위한 실험은 Soft Prompt가 다양한 이질성 차원을 다루는 데 있어 다른 최신(SOTA) 방법들을 능가함을 보여준다. X-VLA는 안정적인 학습 과정과 우수한 점근적(asymptotic) 성능을 보이며, 더 큰 모델 크기와 혼합 로봇 데이터셋을 향한 유리한 확장 능력을 제공한다.

우리는 세심하게 설계된 데이터 처리 및 학습 레시피로 학습된 X-VLA의 0.9B 규모 인스턴스인 X-VLA-0.9B를 구현한다. 전체 학습 파이프라인은 두 단계로 구성된다. 1단계: 사전학습(Pretraining). 우리는 Droid, RoboMind, Agibot에서 가져온 290K개의 에피소드로 이루어진, 세심하게 선별된 이질적 데이터 혼합(data mixture)으로 X-VLA-0.9B를 사전학습한다. 이 데이터는 단일 팔(single-arm)에서부터 양팔(bi-manual) 설정에 이르는 5종 로봇 팔에 걸친 7개 플랫폼을 포괄한다. soft prompt를 활용해 embodiment별 변이를 흡수함으로써, 모델은 embodiment에 구애받지 않는(embodiment-agnostic) 범용 policy를 학습한다. 2단계: 도메인 적응(Domain adaptation). X-VLA-0.9B는 목표 도메인을 위한 배포 가능한 policy로 적응된다. 새로운 도메인의 하드웨어 구성을 인코딩하기 위해 새로운 soft prompt 집합이 도입·최적화되는 한편, 사전학습된 backbone은 동결(frozen)된 채로 유지된다. 이러한 prompt를 갖춘 상태에서, policy는 finetuning을 통해 새로운 embodiment에 효과적으로 특화된다.

광범위한 평가는 embodiment·환경·과제 전반에 걸친 강력한 적응력을 보여주며, 자율주행 벤치마크 1종을 포함한 6개 시뮬레이션 벤치마크와 3개 실세계 로봇 플랫폼에서 새로운 SOTA 결과를 달성한다. 나아가, 단 1,200개의 시연(demonstration)만으로 실세계에서 dexterous한 천 접기(cloth-folding) 조작 과제에 탁월하여, 천 1장을 2분 이내에 접는 평균 처리량(throughput)을 달성한다. 특히, 이전에 학습된 prompt의 도움을 받아 2단계 적응은 최소한의 학습 비용으로 파라미터 효율적 finetuning(parameter-efficient finetuning, PEFT)을 통해 효율적으로 실현될 수 있다. 모델 파라미터의 단 1%(9M)만 튜닝함으로써 X-VLA-0.9B는 LIBERO에서 93%, Simpler-WidowX에서 54% 성공률을 달성하는데, 이는 300배 더 적은 파라미터(3B 대 9M)를 요구하면서도 π0에 필적하는 수준이다.

2. 예비 지식(Preliminary)

VLA 모델. VLA 모델은 로봇 제어를 위해 멀티모달 이해와 action 생성을 통합하는 모델 부류이다. 전형적으로 VLA 모델은 대규모 이미지-텍스트 코퍼스로 사전학습된 VLM으로부터 초기화된 뒤, 전문가 궤적(expert trajectory)을 담은 로봇 데이터셋으로 finetuning된다:

D = { τ_j } (j=1..M),   τ_j = { (o_n, a_n) } (n=1..N_j)          (1)

여기서 on은 단계 n에서의 멀티모달 관측(예: 시각 입력, 언어 지시, proprioceptive 상태)을 나타내며, an은 이에 대응하는 전문가 action이다. 학습 목표는 전형적으로 behavior cloning으로 정식화되는데, θ로 매개변수화된 policy πθ(on)가 시연된 action chunk An := [an, an+1, …, an+T]T(여기서 T는 chunk 크기)를 예측하도록, 적절한 지도 손실(supervised loss) ℓ(·)을 최소화하여 최적화된다:

L_BC(θ) = E_{(o_n, A_n) ~ D} [ ℓ( π_θ(o_n), A_n ) ]              (2)

Flow-matching policy. 관측 o로부터 전문가 action chunk A를 직접 예측하는 대신, flow-matching policy는 노이즈 샘플을 목표 action chunk로 수송(transport)하는 velocity field(속도장)를 흔히 학습한다. 예를 들어, 가우시안 노이즈 A0 ~ N(0, I)에서 출발하여, 신경망으로 매개변수화된 velocity field vθ(At, o, t)를 통해 Euler-Maruyama 방법 같은 ODE solver로 이를 반복적으로 정제(refine)함으로써 action A를 생성할 수 있다:

A^{t+Δt} = A^t + v_θ(A^t, o, t) · Δt                            (3)

여기서 t ∈ [0, 1]은 연속 시간 변수이다. velocity field를 학습하기 위해, 우리는 노이즈와 전문가 데이터 사이의 선형 보간 경로에 velocity를 정렬시키는 OT(optimal transport, 최적 수송) 경로를 사용한다:

L^FM_BC(θ) = E_{ t~U(0,1),  (o,A)~D } [ || v_θ(A^t, o, t) − (A − A^0) ||^2 ]   (4)
A^t = (1−t)·A^0 + t·A,   여기서 U는 균등분포(uniform distribution).      (5)
수식 읽는 법 — 식 (3)~(5)
flow matching은 순수 가우시안 노이즈 A0에서 시작해 전문가 action A로 이어지는 직선 경로를 정의한다. 시각 t에서의 중간 샘플은 At=(1−t)A0+tA로, 노이즈와 정답을 t의 비율로 섞은 것이다. 신경망 vθ는 이 경로 위 각 점에서 "노이즈→정답으로 향하는 방향"인 목표 velocity (A−A0)를 예측하도록 MSE로 학습된다. 추론 시에는 식 (3)의 Euler 갱신으로 노이즈를 조금씩 action 쪽으로 밀어 최종 chunk를 얻는다. LFMBC를 최소화하면, policy는 관측 o에 조건부로 무작위 노이즈를 전문가 chunk로 점진적으로 수송하는 법을 학습한다.

cross-embodiment 학습에서의 이질성. H개의 이질적 데이터셋으로 구성된 혼합 데이터 레시피 DH = { Di }(i=1..H)로 학습하는 것은 범용 VLA 모델을 개발하는 데 필수적이다. 각 데이터셋 Di는 특정 하드웨어 구성 hi ∈ H 하에서 수집되는데, 여기서 H는 팔 운동학(arm kinetics), 제어 인터페이스, 카메라 구성, 배포 시나리오 등 가능한 하드웨어 설정의 공간을 나타낸다. 이러한 요소들은 저수준 action 신호와 분포에서뿐만 아니라 고수준 시각 이해에서도 상당한 이질성을 야기하며, 효과적으로 다루지 않으면 사전학습·적응이 부실해질 수 있다.

3. 이질적 Soft Prompt 학습(Heterogeneous Soft Prompt Learning)

이질성을 다루기 위해, 우리는 그림 2에 나타난 것처럼 잠재적 설계 선택지들을 탐구하는 포괄적인 실증 연구를 수행한다. 우리는 선행 연구를 따라, VLM을 멀티모달 지각(perception)에 활용하고 DiT 스타일 decoder를 action 생성에 활용하는 표준 이중 시스템(dual-system) 아키텍처를 출발점으로 삼는다. 그림 3에서, 우리는 AGIBOT-beta, RoboMind, Droid를 포함한 최근의 고품질 소스로부터 이질적 데이터 혼합을 구성한다. 이 데이터셋은 단일 팔에서 양팔 설정에 이르는 5종 로봇에 걸친 7개 하드웨어 설정을 포괄하여, 범용 policy 학습에 필요한 충분한 규모와 다양성을 제공한다. 우리는 공정한 비교를 보장하기 위해 완전히 정렬된(aligned) 학습 레시피로 모든 방법을 평가한다. 학습 세부 사항은 부록 I를 참조하라.

(a) 도메인 특화 action projection. 이 전략은 모델 출력단에 별도의 projection head를 할당하여 action token을 embodiment별 action space로 매핑함으로써 이질성을 다룬다. 이 접근은 선행 embodied foundation model에서 널리 쓰이지만, 그 효과가 최종 action 생성 단계에만 국한된다. 결과적으로 파이프라인 초기의 embodiment 인식 추론을 촉진하지 못하고, 서로 다른 카메라 설정·과제 분포의 변이 같은 다른 중요한 이질성 원천을 간과한다. 이러한 한계를 우회하기 위해, 우리는 그림 2에 요약한 것처럼 이질적 데이터셋에서 사전학습 안정성을 개선하는 세 가지 대표 전략을 식별한다. 우리는 다음 논의에서 이 전략들을 분석하며, 추가적인 실험적 시도는 부록 E에 보고한다.

(b) HPT 스타일 projection. 이 접근은 서로 다른 도메인의 관측을 공유 표현 공간으로 매핑함으로써 관측 입력의 도메인 불일치를 완화하고 범용 추론을 촉진하는 것을 목표로 한다. 구체적으로, backbone에 입력되기 전에 이를 정렬하기 위해 도메인 특화 projection layer가 멀티모달 입력 위에도 적용된다.

(c) 언어 prompt(Language prompts). 또 다른 전략은 사전학습된 VLM의 언어 추론 능력을 활용한다. 이 경우, 하드웨어 구성 hi에 대한 자연어 서술이 추가 입력으로 제공되어, 모델이 텍스트 서술을 통해 embodiment별 변이에 명시적으로 주의를 기울이도록 한다.

(d) Soft prompt. 마지막으로, 우리는 meta-learning 및 multi-task learning 철학을 따르는 soft-prompt 방법을 탐구하는데, 이는 데이터 소스 전반의 이질성을 흡수하기 위해 도메인 특화 학습 가능 파라미터 PH = { pi }(i=1..H)를 도입한다. pi는 기저의 하드웨어 구성을 인코딩하도록 기대된다:

p_i ≈ Φ(h_i),   여기서  Φ: H → R^k                              (6)

여기서 Φ는 하드웨어 구성으로부터 prompt 공간으로의 잠재 매핑(latent mapping)을 나타낸다. 특히 Φ는 언어 prompt (c)에서처럼 고정된 하드 템플릿으로 미리 정의되지 않고, 무작위로 초기화된 뒤 end-to-end 학습을 통해 암시적으로 최적화된다. 이러한 soft prompt는 action 생성의 초기 단계에서 모델에 주입되어, backbone을 embodiment 인식 학습으로 자동으로 안내한다.

(b) HPT 스타일 projection과 (c) 언어 prompt는 개념적으로 매력적이지만, 뚜렷한 한계를 지닌다. HPT 스타일 projection은 관측 처리의 중간에 서로 다른 projection layer를 도입하는데, 이는 feature 분포를 빈번히 변형시키고 사전학습된 VLM 표현을 손상시키기 쉬워 종종 불안정한 학습 동역학을 초래한다. 반면 언어 prompt는 하드웨어 구성에 대한 세심하게 작성된 텍스트 서술에 의존하는데, 이는 실제 적응성·확장성을 크게 저해한다. 이와 대조적으로 soft prompt는 도메인 특화 하드웨어 구성을 인코딩하기 위한 유연하고 확장 가능한 해법을 제공한다. soft prompt는 (b)와 (c)의 장점을 결합하여, backbone과 매끄럽게 통합되는 동시에 사전학습된 표현을 보존하고 수작업 주석(handcrafted annotation)의 필요를 없앤다. 그림 4의 실증 결과는 Soft Prompt가 이질적 데이터셋 전반에서 일관되게 훨씬 더 견고하고 안정적인 학습을 달성함을 확인해 준다.

4. X-VLA: Soft-Prompted Transformer 강화 VLA 모델

Soft Prompt를 토대로, 우리는 이질적 데이터셋에서의 안정적 사전학습과 새로운 도메인으로의 효율적 적응을 위해 설계된 간결한 VLA 아키텍처인 X-VLA를 도입한다. 우리는 먼저 전반적인 아키텍처 설계를 제시한 뒤, 대규모 사전학습을 위한 몇 가지 핵심 기법을 소개한다. 완전한 ablation 경로는 표 1에 제시되어 있으며, 이는 본 절에서 도입한 구성요소들의 기여를 강조한다.

4.1 아키텍처(Architecture)

우리 설계의 핵심 아이디어는 복잡한 멀티모달 입력을 위한 간소화된(streamlined) 인코딩 파이프라인을 구축하는 것이다. Soft Prompt 이외에, X-VLA는 (1) 고차원 입력(multi-view 시각과 언어)과 (2) 저차원 상태(proprioception과 action token)를 처리한다. 이러한 modality 전반에 걸쳐 의미론과 차원 모두에서 상당한 불일치가 존재하므로, 우리는 이들을 효과적으로 정렬하기 위한 전용 인코딩 전략을 채택하며, 그 뒤에는 표준(vanilla) transformer 스택만으로도 확장 가능한 policy 학습에 충분하다. 아래에서 인코딩 파이프라인을 상술하며, 완전한 아키텍처와 추가 설계 탐구는 부록 C와 부록 D에 제시한다.

1) 고차원 관측 스트림. 고차원 입력은 multi-view 이미지 Img = { imgi }와 과제 목표를 명시하는 언어 L을 포함한다. 모든 시점과 지시를 VLM에 직접 입력하는 대부분의 선행 접근과 달리, 우리는 서로 다른 encoder를 할당하여 스트림을 분리한다. 사전학습된 VLM encoder(X-VLA에서는 Florence-Large)는 주(main) vision-language 스트림(고정 시점과 지시)에 사용되고, wrist-view 같은 보조 시점은 공유 vision backbone으로 처리된다. 이 설계는 일반적 vision-language 추론과 embodied 추론 사이의 의미론적 간극을 완화한다. 고정 카메라 시점은 고수준 과제 추론을 위한 안정적이고 유용한 맥락을 제공하는 반면, wrist-camera 입력은 노이즈가 많고 빠르게 변하지만 세밀한 조작에 중요한 단서를 제공하므로 언어 스트림과 분리하여 인코딩된다.

2) 저차원 proprioceptive-action 스트림. 관절 위치나 end-effector 자세 같은 proprioceptive 상태 Rt는 추론·제어를 위한 embodiment별 근거(grounding)를 제공한다. action 관련 token At는 flow-matching 생성에 사용되는 노이즈 action 샘플로 구성된다. Rt와 At는 모두 물리적 의미가 밀접하게 연관된 조밀한(compact) 벡터이므로, 우리는 flow-matching 파이프라인 내에서 이들을 대응하는 시간 임베딩(time embedding) T와 함께 연결(concatenate)한다. 융합된 임베딩은 경량 linear layer를 통해 고차원 feature 공간으로 사영되어, 다른 modality와의 조기 융합(early fusion)을 가능케 하고 견고한 proprioceptive-시간 근거를 보장한다.

4.2 맞춤형 학습 레시피(Customized Training Recipe)

X-VLA의 잠재력을 온전히 이끌어내기 위해, 우리는 X-VLA 학습의 안정성과 효과성을 모두 높이도록 세심하게 설계된 학습 엔지니어링을 도입한다. 우리는 학습 레시피의 개요를 제공하고, 안정적이고 효율적인 학습에 결정적인 몇 가지 핵심 기법을 설명한다.

4.2.1 사전학습 및 finetuning 파이프라인

사전학습에서는 backbone πθ와 soft prompt PH가 flow-matching 목적 LFMBC 하에서 공동으로(jointly) 최적화된다. 상세한 사전학습 하이퍼파라미터는 부록 G를 참조하라. 사전학습 이후 backbone은 이질적 로봇 전반에 걸쳐 빠른 적응이 가능한, embodiment에 구애받지 않는 기반(foundation)이 된다. 새로운 하드웨어 구성 hnew를 지닌 새로운 도메인에 이 모델을 배포하기 위해, 우리는 경량의 2단계 적응 절차를 제안한다.

(1) Prompt warm-up. 우리는 hnew를 위한 새로운 학습 가능 prompt 집합 pnew ∈ Rk를 도입한다. 이 prompt는 사전학습된 가중치를 동결한 채로 먼저 warm-up된다. 그렇게 함으로써 prompt는 사전학습된 embodiment 무관 feature를 활용하도록 사영되어, 다음 라운드의 공동 학습을 위한 좋은 시작점을 제공한다.

(2) 공동 policy 적응(Joint policy adaptation). 그 다음, 우리는 backbone과 warm-up된 prompt를 함께 최적화하여 새로운 도메인에 공동으로 적응한다. 이 2단계 과정은 먼저 pnew가 hnew의 하드웨어 특화 설정을 인코딩하게 한 뒤, 효과적 특화를 위해 전체 policy를 finetuning하며, 이는 LLM을 VLM으로 적응시킬 때 사용된 것과 동일한 철학을 공유한다.

맞춤 학습률(Custom learning rate, LR). 사전학습과 적응 모두에서 핵심적인 안정화 기법은, soft prompt는 물론 시각·언어 입력의 인코딩을 담당하는 vision-language 모듈에 대해 감소된 학습률을 사용하는 것이다. 이 조정은 사전학습된 표현으로부터의 파국적 표류(catastrophic drift) 위험을 줄여, 사전학습 동안 더 매끄러운 최적화와 새로운 embodiment 적응 시 더 신뢰할 수 있는 특화를 이끈다. 이는 vision-language 모델에 인코딩된 일반 지식과, VLA 모델이 요구하는 세밀한 공간적 위치 지정(spatial localization) 및 action 근거를 효과적으로 잇는다.

4.2.2 향상된 데이터 처리(Enhanced Data Processing)

정렬된 action 표현(Aligned action representation). action은 VLA 모델의 핵심 지도 신호로서, 그 품질이 학습 결과를 직접적으로 좌우한다. 따라서 우리는 action space를 end-effector(EEF) 자세 표현으로 표준화하며, 이는 다음으로 구성된다: (1) 데카르트 EEF xyz 위치, (2) Euler angle 및 quaternion 표현에 내재된 불연속성을 피하기 위해 Rotate6D 표현으로 인코딩된 절대 EEF 회전, 그리고 (3) gripper의 이산화된 이진 상태. 위치와 회전은 평균제곱오차(MSE) 손실로, gripper 상태는 이진 교차 엔트로피(BCE) 손실로 최적화된다. 이는 embodiment 전반의 일관성을 보장하여 일반화 가능한 policy 학습을 위한 견고한 지도를 제공한다.

시간적 downsampling을 통한 의도 추상화(Intention abstraction through temporal downsampling). 저수준 action 궤적은 배포에 필요한 정밀한 조작 신호를 제공하지만, 종종 지나치게 세밀하고 인간의 무작위성으로 인해 노이즈가 많은 움직임을 다수 포함할 수 있어, 사전학습을 위한 고수준 근거·의도 모델링에 적합하지 않다. 이 문제를 완화하기 위해, 우리는 시연을 시간적으로 downsampling하여 action 의도의 추상적 표현을 구성한다. 구체적으로, 매 시간 단계에서 전체 end-effector 자세를 예측하는 대신, 파이프라인은 다음 4초 동안의 의도된 궤적을 요약하는 30개의 anchor point 시퀀스를 생성하도록 설계된다.

균형 잡힌 데이터 샘플링 전략(Balanced data sampling strategy). 흔한 round-robin 데이터 샘플링 전략과 대조적으로, 우리는 안정적 학습이 세심하게 설계된 데이터 셔플링 파이프라인을 요구함을 관찰했다. 우리는 서로 다른 도메인 전반에서뿐만 아니라 각 도메인 내의 궤적 전반에서도 샘플을 셔플하여, 매 iteration마다 다양하고 균형 잡힌 데이터 혼합에 노출되도록 보장한다. 이는 분포 편향(distributional bias)을 효과적으로 완화하고 지배적 도메인에 대한 과적합(overfitting)을 줄여, 대규모 사전학습 동안 더 매끄러운 수렴을 촉진한다.

5. 실험(Experiments)

본 절에서 우리는 다음을 규명하기 위해 광범위한 실험을 수행한다. 1. 확장 거동(Scaling behavior): X-VLA는 모델 크기, 데이터 다양성, 데이터 규모에 걸쳐 확장 특성을 보이는가? 2. 적응 성능(Adaptation performance): X-VLA는 다양한 특성을 지닌 새로운 도메인에 특화될 수 있는가? 3. 해석가능성(Interpretability): soft prompt는 혼합 데이터 소스의 이질성을 반영하는 유의미한 표현을 포착하는가?

5.1 확장 실험(Scaling Experiments)

먼저 우리는 (1) 모델 용량(capacity), (2) 데이터 다양성, (3) 데이터 부피의 세 축에 걸쳐 X-VLA의 확장 거동을 연구한다. 표 1에 보인 것처럼, 사전학습 동안 관찰된 예측 오차는 하류(downstream) 적응 성능과 강하게 상관된다. 따라서 우리는 held-out 검증 세트에서 (flow-matching 디노이징 이후의) 예측 action과 정답 action 사이의 ℓ1 오차를 주요 평가 지표로 채택한다. 대응하는 결과는 그림 5에 요약되어 있으며, 추가 학습 세부 사항은 부록 G에 제시한다. 특히, 가장 큰 시험 구성인 X-VLA-0.9B(hidden size 1024, 24개 Transformer block)를 7개 데이터 소스의 290K개 에피소드로 학습한 경우에도, 확장 추세는 포화(saturation)의 조짐을 보이지 않는다. 이는 이 세 축을 따라 더 증가시키면 추가적인 성능 이득을 얻을 수 있음을 시사한다. 자원 제약으로 인해, 우리는 이후 실험을 위한 기본 모델로 가장 큰 구성을 채택한다.

5.2 적응 실험(Adaptation Experiments)

우리는 5개 시뮬레이션 환경과 3개 실세계 로봇 플랫폼에 걸쳐 X-VLA-0.9B를 평가하는, 현재까지 가장 포괄적인 검증 연구 중 하나를 제시한다. 추가 실험 결과는 부록 D를 참조하라.

시뮬레이션 벤치마크. 우리는 Libero, Simpler, VLABench, RoboTwin-2.0, Calvin, NAVSIM에서 평가한다. 이 6개 벤치마크는 수백 개의 평가 설정을 포괄하며, 단일 팔·양팔 로봇 시스템과 자율주행을 아우르고, cross-embodiment·cross-environment·cross-task 적응을 포함한 다양한 일반화 축을 평가한다. 다섯 개 벤치마크에 걸쳐 우리는 새로운 SOTA를 확립하여, 집계된 선행 모델들 대비 상당한 개선을 달성한다. 특히 여러 벤치마크에서 90%를 넘는 성공률을 달성하는데, 예컨대 Simpler-WidowX(96%), Libero(98%), Calvin 1단계 등이다. 우리가 아는 한, 이토록 포괄적인 평가를 일관되게 유의미한 이득과 짝지어 보고한 선행 모델은 없으며, 이는 X-VLA-0.9B의 우수한 성능을 뒷받침한다. X-VLA-0.9B는 향후 연구가 진보된 모델을 개발하기 위한 강력한 기준선(baseline)이 될 수 있다(세부 사항은 부록 M 참조).

Dexterous한 천 접기 과제. 우리는 고도로 흐트러진 천을 펴서 매끄럽게 만들고(smoothing) 그것을 깔끔하게 접어야 하는, 도전적인 dexterous 천 접기 과제를 도입한다. 이 노력을 뒷받침하기 위해, 우리는 양팔 Agilex 플랫폼 위에 Soft-Fold라 명명한 고품질 천 접기 데이터셋을 구축했으며, 이는 세심하게 설계된 파이프라인을 통해 수집된 1,200개의 궤적으로 구성된다. 과제와 데이터셋 모두에 대한 상세 서술은 부록 F에 제시한다. 중요하게도, 우리는 dexterous 조작에 대한 향후 연구를 촉진하기 위해 이 데이터셋을 공개(release)할 예정이다. 이 데이터셋을 적응에 활용하여, 우리의 X-VLA-0.9B 모델은 거의 100%에 이르는 성공률과 시간당 33회의 완료 접기라는 처리량을 달성하는데, 이는 훨씬 크고 고품질일 것으로 추정되는 데이터셋으로 학습된 폐쇄형(closed-source) π0-folding 모델에 필적한다. 공정한 비교를 위해 우리는 Soft-Fold에서 π0-base를 finetuning하고 ACT 모델을 처음부터(from scratch) 학습시켰으나, 이들은 X-VLA-0.9B의 처리량에 미치지 못하여, 우리 모델의 강력한 dexterous 조작 능력을 부각시킨다. 추가 정성적(qualitative) 결과는 부록 F에 제시하며 웹 데모에서 시연한다.

파라미터 효율적 finetuning(PEFT) 실험. 사전학습된 X-VLA-0.9B backbone이 embodiment에 구애받지 않는 feature를 인코딩하고 새로운 설정에 효율적으로 적응될 수 있는지를 평가하기 위해, 우리는 Low-Rank Adaptation(LoRA) 같은 PEFT 기법을 채택한다. 우리는 세 벤치마크에서 적응을 시험한다: Libero, Simpler-WidowX, 그리고 사전학습 중 보지 못한 실세계 embodiment인 AIRBOT의 천 집기(cloth-pick) 과제. 표 4와 그림 7은 전체 모델의 약 1%인 단 9M개의 튜닝 가능 파라미터만으로 backbone을 강력한 도메인 특화 모델로 유도할 수 있음을 보이며, Libero와 Simpler-WidowX 벤치마크에서 각각 93%와 54% 성공률을 달성한다. 이 점수들은 완전 finetuning된 모델, 예컨대 Libero와 Simpler-WidowX에서 각각 94.2%와 55.7%를 달성하는 π0에 필적하며, X-VLA의 강력한 적응 능력을 보여준다.

5.3 심층 분석(In-Depth Analysis)

우리는 정성적·정량적 결과 모두를 통해 soft prompt의 효과를 한층 명료하게 규명한다. 우선 우리는 혼합 데이터 레시피(그림 3)로 사전학습한 뒤 학습된 soft prompt를 T-SNE로 시각화한다. 그림 8은 prompt들이 서로 다른 하드웨어 구성과 밀접하게 정렬되는 잘 구조화된 군집(cluster)을 형성함을 드러내어, 이들이 embodiment별 정보를 성공적으로 포착함을 나타낸다. 더욱 흥미롭게도, Droid 데이터에서 유래한 두 Franka 설정(좌·우 시점)은 분리되지 않고 서로 뒤섞여 있는데, 이는 이들이 지정된 주 시점(main view)에서만 차이가 나기 때문이다. 이 관찰은 soft prompt가 데이터 소스를 단순 무식하게(brute-force) 분할하기만 하는 것이 아니라, cross-embodiment 유사성을 활용함을 시사한다. 나아가 우리는 사전학습된 soft prompt가 사전학습에서 보지 못한 단일 팔 로봇 WidowX로의 효율적 적응을 어떻게 촉진하는지 평가한다. 우리는 Simpler에서 PEFT 실험을 수행하여 세 가지 설정을 비교한다: (1) 무작위로 초기화되어 동결된 soft prompt, (2) 다른 단일 팔 플랫폼(예: UR5)에서 온 사전학습된 prompt를 동결한 것, (3) 우리의 2단계 적응 메커니즘으로 적응된 soft prompt. 그림 9에서, 학습된 prompt가 더 빠르게 수렴하고 최종적으로 더 높은 성공률에 도달하는 반면, 무작위 prompt는 느린 적응과 저하된 성능으로 이어지는 것은 놀랍지 않다. 그러나 동결된 사전학습 prompt가 UR5와 WidowX 간의 부분적 유사성 덕분에 초기 단계에서 강한 전이 이점을 제공한다는 점은 반가운 결과인데, 다만 불가피한 도메인 간극이 최종 성능을 제한한다. 이는 cross-embodiment 전이를 위한 유망한 길을 부각시킨다: 더 다양한 로봇 플랫폼에서 사전학습하면, soft prompt는 가장 가까운 하드웨어 설정에 정렬된 prompt를 검색(retrieve)함으로써 zero-shot/few-shot 일반화를 가능케 할 수 있다.

6. 결론(Conclusion)

본 논문에서 우리는 이질적 로봇 플랫폼 전반에서 동작할 수 있는 범용 Vision-Language-Action 프레임워크인 X-VLA를 도입했다. 세심하게 설계된 학습 파이프라인, 적응 방법, 향상된 데이터 처리를 통해, 우리의 가장 큰 모델 X-VLA-0.9B는 광범위한 벤치마크에 걸쳐 SOTA 성능을 달성하여, 수백 개의 평가 설정에 걸쳐 상당한 이득과 함께 새로운 기록을 세운다. 특히, 최소한의 튜닝 가능 파라미터만으로도 X-VLA-0.9B는 완전 finetuning된 SOTA 모델에 필적하는 결과를 낸다. 중요하게도, Soft Prompt 메커니즘에 힘입어 X-VLA는 모델 크기, 데이터 다양성, 데이터 부피의 세 축 모두를 따라 확장 가능한 학습 추세를 보이며, 우리의 가장 큰 시험 구성(0.9B 파라미터, 290K 에피소드, 7개 데이터 소스)에서조차 포화의 조짐이 없다. 이는 더 큰 모델과 데이터셋으로의 추가 확장 잠재력을 부각시켜, 더 강력한 VLA 모델을 향한 길을 연다. 한계와 향후 과제는 부록 N에서 논의한다.

Vision-Language-Action 모델. 물리 세계와 상호작용할 수 있는 에이전트를 개발하려면 세 가지 필수 modality를 통합해야 한다: 환경을 이해하는 시각 지각, 과제 지시를 해석하는 언어 이해, 그리고 실행 가능한 제어 신호를 생성하는 action 생성. VLA 모델 연구는 이 modality들을 통합하여 embodied 에이전트가 자연어 명령과 시각 관측에 조건부로 복잡한 과제를 수행하도록 하는 데 초점을 두어 왔다. 이 모델들은 전형적으로 대규모 vision-language 코퍼스로 사전학습된 VLM 위에 구축된다. VLM으로부터 강한 시각 근거와 범용 추론 능력을 물려받음으로써, VLA 모델은 다양한 조작 과제에서 인상적인 결과를 달성한다. 보다 최근에는 연구자들이 범용 vision-language 추론과 embodied 과제 요구 사이의 본질적 간극을 인식했다. 이를 다루기 위해 다양한 접근이 탐구되었는데, 예컨대 modality 주입을 통해 embodiment별 prior(3D 공간 근거, instruction-following, 이력 추론 등)를 통합하거나, 도메인 관련 데이터셋을 확장하거나, 추가 지도를 더하거나, 특화된 모델을 설계하는 것이다. 그럼에도 현재 VLM의 본질적 한계로 인해 이러한 전략들은 복잡한 시각 입력을 지닌 embodied 과제에 필요한 수준의 일반화된 추론을 달성하는 데 종종 미치지 못한다. 본 논문에서 우리는 입력 스트림에 대한 단순하지만 효과적인 수정이 VLM의 일반화 잠재력을 더 잘 활용하여 유의미한 성능 이득으로 이어질 수 있음을 보인다.

이질적 사전학습(Heterogeneous Pretraining). 대규모 데이터셋에서의 학습은 최근 embodied foundation model 진보의 핵심 요인이었다. 그러나 대규모 사전학습에 이용 가능한 로봇 데이터는 action space에서뿐만 아니라 하드웨어 설정에서도 강한 이질성을 보이는 경우가 많다. 이를 다루기 위해, 어떤 연구는 세심하게 설계된 아키텍처 수정과 함께 이질적 데이터 혼합으로 표준 Transformer를 사전학습할 것을 제안하여, 유망한 확장 거동과 전이가능성(transferability)을 입증했다. 보다 최근에는 사전학습된 VLM이 이미 도메인 전반의 다양한 vision-language 입력을 다루는 강한 일반화 능력을 지녔음이 관찰되었다. 결과적으로 초점은 action space의 이질성 해소로 옮겨 갔다. action space를 수동으로 재구성하거나 이질적 action label을 수용하도록 모델 아키텍처를 수정하는 것을 넘어, latent action 모델링이나 표현 학습을 통해 의미론적 수준에서 action을 정렬하는 여러 접근이 제안되었다. 그럼에도 이질적 데이터 소스로부터 policy를 학습하려면 단순히 action label을 정렬하는 것 이상이 필요한데, 하드웨어 설정의 변이가 관측이 action으로 매핑되는 방식에 직접 영향을 미치므로 embodiment별·proprioceptive를 인식하는 추론이 요구된다. 이러한 embodiment별 요인들을 명시적으로 모델링하지 않고 이질적 데이터를 공유 backbone에 단순히 투입하면 종종 불안정한 학습과 부실한 cross-domain 일반화로 이어진다. 본 논문에서 우리는 embodiment별 변이를 명시적으로 흡수하는 한편 일반 추론을 위한 공유 backbone을 보존하는 soft-prompt 메커니즘을 도입한다. 각 하드웨어 구성을 학습 가능한 prompt 임베딩과 연관시킴으로써 모델은 도메인별 지식을 유연하게 포착할 수 있고, 따라서 안정적인 대규모 사전학습을 가능케 한다.

Soft Prompt 학습. soft prompt 개념은 원래 완전 모델 finetuning에 대한 파라미터 효율적 대안으로 NLP 공동체에서 도입되었다. 사전학습된 모델의 모든 파라미터를 갱신하는 대신, 작은 학습 가능 임베딩 집합을 입력 시퀀스 앞에 덧붙이고 하류 과제에 대해 최적화한다. 이 접근은 최소한의 추가 파라미터로 LLM을 다양한 과제에 적응시키는 데 매우 효과적임이 입증되었으며, modality 전반의 prompt 기반 전이 학습에 관한 광범위한 연구를 촉발했다. 이 토대 위에서 soft prompt는 멀티모달·multi-task 학습 설정으로 확장되었다. meta-learning 철학과 결합되면, soft prompt는 도메인별·과제별 정보의 경량 운반체(carrier)로 기능할 수 있다. backbone의 사전학습된 표현을 덮어쓰지 않으면서 이를 안내하는 학습 가능 임베딩을 주입함으로써, 이들은 도메인 이질성을 다루기 위한 유연하고 확장 가능한 메커니즘을 제공한다. 본 연구에서 우리는 하드웨어 구성과 action space 같은 embodiment 차이로부터 이질성이 발생하는 로봇공학에 soft prompt 패러다임을 채택한다. 우리는 soft prompt가 embodiment별 변이를 효과적으로 흡수하여 backbone이 embodiment에 구애받지 않는 범용 policy 학습에 집중하도록 함을 입증한다.

D.1 대안적 아키텍처 설계

본 절에서 우리는 개발 중 탐구한 대안적 아키텍처 설계의 추가 결과를 제시한다. 우리의 최종 모델은 X-VLA 파이프라인을 채택하지만, 비교를 위해 흔히 쓰이는 몇 가지 backbone 아키텍처도 구현했다. 이 기준선들은 부록 I에 서술된 예비 실험과 일관되게 동일한 실험 설정 하에서 평가되었다.

Standard DiT Decoder. 사전학습된 vision-language encoder가 추출한 멀티모달 feature에 조건부로 action을 생성하는 Diffusion Transformer(DiT) decoder의 직접 적용이다. 이는 DiT를 embodied 설정으로 확장하는 가장 간단한 방식이다.

Standard MM-DiT Decoder. 서로 다른 입력 modality에 별도의 파라미터를 할당하고 이를 attention을 통해 통합하는 DiT의 멀티모달 변형이다. 우리는 action modality를 vision-language 입력으로부터 분리한다. 이 설계는 modality 간 의미론적 간극을 줄이려 시도하지만, 종종 학습을 불안정하게 만들고 이질적 데이터셋 및 하류 적응에서 열등한 결과로 이어진다.

π0-Style Decoder. 선행 연구를 따라, 이 설계는 vision-language 처리를 위한 사전학습된 VLM과 나란히 병렬 MLP-Mixer 기반 action 모듈을 사용한다. 이는 조밀한 feed-forward 네트워크로 효과적으로 표현될 수 있는 action 입력의 조밀한 성질을 활용하지만, 추가된 아키텍처 복잡성이라는 비용을 치른다.

이 backbone들 전반의 비교 결과는 표 4에 요약되어 있으며, 우리가 제안한 X-VLA가 안정적 최적화 동역학을 유지하면서 일관되게 최고의 검증 성능을 달성한다.

D.2 cross-embodiment 일반화 policy 구축 잠재력

soft prompt에 힘입어, X-VLA는 이질적 데이터셋에서 효율적이고 안정적인 학습을 가능케 하여, 도메인 변이를 효과적으로 흡수하고 embodiment에 구애받지 않는 policy 학습을 촉진한다. 이 능력을 토대로, 우리는 X-VLA가 단일한 새로운 embodiment뿐만 아니라 다양한 데이터 소스의 시연에 대한 공동 finetuning을 통해 여러 embodiment에 동시에 적응될 수 있음을 보인다. 구체적으로, 우리는 Libero, BridgeData, Calvin-ABC를 포함한 하류 데이터셋 혼합에 대해 공동 finetuning 실험을 수행하는데, 이는 데이터 수집·배포 모두에 대해 두 개의 서로 다른 embodiment와 세 개의 하드웨어 설정을 포함한다. 부록 M에 상술된 다른 finetuning 실험과 동일한 학습 레시피로 공동 finetuning한 뒤, 우리는 표 5에 결과를 보고한다.

표 5는 multi-domain 적응 결과를 보여준다. X-VLA는 공동으로 적응될 때 평가된 모든 embodiment에서 일관되게 강한 성능을 유지하여, single-domain 특화를 넘어 확장하는 능력을 입증한다. 흥미롭게도, 공동 적응은 각 도메인 내 성능을 보존할 뿐만 아니라 일부 경우에는 single-domain finetuning 대비 성공률을 오히려 개선하여, 긍정적인 cross-domain 전이를 시사한다. 이는 soft-prompt 메커니즘이 embodiment별 변이를 흡수할 뿐만 아니라 이질적 embodiment 전반의 상보적 지식 공유(complementary knowledge sharing)를 가능케 함을 나타낸다.

부록 E. 이질성 흡수를 위한 실패한 시도들(Failure Attempts)

본 논문의 핵심 동기는 혼합 데이터 소스 전반의 이질성을 완화하고 범용의 embodiment 무관 policy를 개발하는 전략을 탐구하는 것이다. meta-learning 철학에서 영감을 받아, 우리는 처음에 이 문제를 이질적 파라미터 학습(heterogeneous parameter learning)의 관점에서 접근했다. 구체적으로, 우리는 각 도메인마다 별개의 파라미터 집합을 할당했는데, 이 도메인 특화 파라미터가 도메인 변이를 흡수하는 한편 공유 backbone이 도메인 전반의 일반화 가능한 지식을 증류하리라 기대했다. 궁극적으로 우리는 제안한 soft-prompt 메커니즘이 이 난제에 대한 효과적 해법을 제공함을 발견했다. 본 절에서 우리는 실무적 함정을 부각시키고 이 방향의 향후 연구에 영감을 주고자, 성공하지 못한 두 가지 시도를 제시한다.

이질적 Low-rank Adapter. soft prompt 이외에, 우리는 다른 파라미터 효율적 학습 방법을 이질적 사전학습에 통합하는 것을 탐구했다. 구체적으로, 우리는 도메인 특화 adapter를 공유 backbone과 병렬로 도입하는 Low-Rank Adaptation(LoRA) 스타일 모듈을 실험했다. 우리의 직관은 이 adapter들이 효율적 매개변수화로 embodiment별 변이를 포착하는 한편 주 backbone이 embodiment 무관 feature를 인코딩하리라는 것이었다. 그러나 우리는 추가된 adapter가 종종 backbone의 최적화 동역학과 충돌하여 불안정성과 도메인 전반의 저하된 일반화로 이어짐을 관찰했다.

이질성 유도 MoE 프레임워크. 우리는 또한 추론 비용을 통제하면서 모델 용량을 확장하는 데 널리 쓰여 온 mixture-of-experts(MoE) 접근을 실험했다. MoE의 희소 활성화(sparse activation) 메커니즘은 multi-task 학습, cross-domain 학습, 멀티모달 로봇 behavior cloning에서 효과적임이 입증되었다. 이러한 성공에 힘입어, 우리는 embodiment별 단서에 기반해 전문가(expert)를 활성화하려는 이질성 유도 라우팅(routing) 전략을 설계했다. 이론적 매력에도 불구하고, 우리는 router가 붕괴(collapse)하는 경향이 있음을 발견했는데, 대부분의 입력을 소수의 전문가에게만 일관되게 라우팅하고 다른 전문가는 활용되지 못한 채 남겨, 용량을 낭비하고 한계적 성능 이득만을 낳았다. 이를 완화하기 위해 우리는 load-balancing 정규화(regularization)를 도입해 다시 시도했으나, 그 결과 전문가 간의 빠른 전환이 종종 최적화를 불안정하게 만들고 전반적 학습 동역학을 저하시켰다.

시연 수집 전략. 인간은 천을 격식 없이 빠르게 접을 수 있으며, 겉보기에 무작위인 방식으로 매우 다양한 방법을 사용하는 경우가 많다. 그러나 이러한 가변성은 로봇 policy 학습에 상당한 난제를 제기하는데, 서로 다른 접기 전략이 종종 뚜렷이 다른 행동 모드(behavioral mode)에 대응하고 모든 전략이 학습에 똑같이 적합하지는 않기 때문이다. 인간 시연의 비일관성을 줄이기 위해, 우리는 접기 과제를 두 단계로 분해한다: (1) 고도로 흐트러진 상태에서 천을 펴 매끄럽게 만들기, 그리고 (2) 매끄럽게 편 천을 깔끔하게 접기. 우리는 첫 단계가 특히 도전적임을 발견했는데, 흐트러진 천이 고도로 무작위인 동역학을 보여 policy가 펴기(unfolding)를 위한 보편적 전략을 포착해야 하기 때문이다. 이를 다루기 위해, 우리는 천의 두 모서리나 두 끝 같은 유의미한 keypoint가 뚜렷이 드러날 때까지 반복적으로(repetitive) 1단계 시연을 수집한다. 그 시점에 우리는 흔드는(swinging) 동작을 사용해 매끄럽게 펴는 단계를 완료한 뒤 2단계로 전이한다. 이는 천 접기에 결정적인데, 1단계에서 구조화되지 않았거나 무작위로 수집된 시연은 policy를 비일관적 행동에 얽히게 하여 불안정한 학습 동역학을 초래하고 2단계로의 진행을 방해하기 때문이다. 2단계의 경우, 천이 매끄럽게 펴진 뒤에는 덜 무작위로 거동하므로 데이터 수집이 훨씬 쉬워진다. 평균적으로 하나의 완전한 접기 에피소드는 약 1.5분이 걸리며, 재설정과 실패 시도 폐기에 드는 시간을 포함해 한 시간의 수집으로 20–25개 에피소드를 얻는다. 최종 데이터셋은 그림 11에 보인 것처럼 1,200개 에피소드를 포함한다.

DAgger 스타일 데이터 수집. 제한된 에피소드로 천 접기 같은 장기 지평(long-horizon) dexterous 과제를 학습하기 위해, 우리는 DAgger 스타일 데이터 수집 전략을 채택하는 것이 필수적임을 발견했다. 구체적으로, 우리는 수집된 에피소드 100개마다 ACT를 학습시키고, 그 실패 모드를 식별한 뒤, 이 실패를 다루기 위한 표적 시연을 수집한다. 이 반복적 정제는 단 1,200개 에피소드만을 사용하여, 훨씬 큰 데이터셋으로 학습되었을 폐쇄형 모델에 필적하는 천 접기 성능을 달성하게 해 준다.

X-VLA-0.9B의 정성적 결과. 여기서 우리는 그림 12에 X-VLA-0.9B의 완전한 접기 진행 과정을 시각화한다. 하나의 완전한 접기는 단순한 Localization, Pick, Place부터 고도로 동적인 Swing 동작에 이르는 다양한 기술을 포괄하여, 천 접기 과제의 난도를 보여준다.

부록 G. 사전학습 세부 사항(Pretraining Details)

X-VLA-0.9B의 사전학습은 64개 NVIDIA A100 GPU에서 전역 배치 크기(global batch size) 1024로 약 4일에 걸쳐 수행되었다. 학습은 이질적 데이터셋 전반의 안정성과 효율적 수렴을 보장하도록 세심하게 조정된 레시피를 따랐다.

표 7은 사전학습에 사용된 핵심 하이퍼파라미터를 요약한다. 우리는 모멘텀 파라미터 β1=0.9, β2=0.95, 학습률 1×10−4, 가중치 감쇠(weight decay) 0.01의 AdamW optimizer를 채택한다. 학습은 혼합 정밀도(bfloat16)로 200K iteration 동안 수행되었다. 시각 입력의 경우, 이미지는 224×224로 크기 조정되고 일반화를 개선하기 위해 ColorJitter로 완만한 섭동(perturbation)을 가해 증강된다.

optimizer 구성 외에, 사전학습의 결정적 측면 하나는 이질적 데이터셋의 균형을 맞추는 것이다. 서로 다른 소스는 규모와 품질 모두에서 크게 다르므로, 우리는 세심하게 설계된 셔플링 파이프라인과 결합된 가중 샘플링(weighted sampling) 전략을 채택한다. §4.2.1에서 강조한 것처럼, 여기에는 cross-domain 및 cross-trajectory 셔플링이 포함되어, 매 iteration마다 모델이 다양하고 균형 잡힌 샘플 혼합에 일관되게 노출되도록 보장한다. 우리는 이 설계가 대규모 사전학습 동안 최적화를 안정화하고 도메인 과적합을 방지하는 데 결정적임을 발견했다. 표 8은 데이터 소스, 이용 가능한 궤적, 적용된 샘플링 가중치를 요약한다.

검증 세트 구성. 우리는 사전학습 수렴을 모니터링하고 서로 다른 아키텍처·방법 간의 공정한 비교를 보장하기 위해 개방 루프(open-loop) 검증 실험을 수행한다. 검증 손실이 하류 과제 성능에 대한 명료하고 신뢰할 수 있는 지표로 기능하도록 보장하기 위해, 우리는 전용 검증 세트를 세심하게 구성한다. 구체적으로, 우리는 AGIBOT-beta에서 학습 분할(training split)에 포함되지 않은 궤적을 표집하여, cross-embodiment 지식 공유와 일반화를 더 잘 평가할 수 있게 한다. 검증 세트는 189개 과제에 걸치며, 과제당 3개의 궤적을 표집한다. 평가에서 우리는 예측 궤적과 정답 궤적 사이의 평균 ℓ1 오차를 보고한다.

부록 H. Finetuning 세부 사항(Finetuning Details)

본 절에서 우리는 적응 실험에 대한 추가 학습 세부 사항을 제공한다. 별도로 명시하지 않는 한, optimizer 설정(β1=0.9, β2=0.95의 AdamW), 가중치 감쇠(0.01), 모델 정밀도(bfloat16), 학습률(1×10−4)은 사전학습 단계와 일관되게 유지된다. 모든 모델은 우리가 제안한 2단계 절차로 적응된다. 처음 1,000 iteration 동안에는 soft prompt와 action head만 갱신되고 다른 모든 파라미터는 동결된 채로 유지되며, 이어서 1,000 iteration의 warm-up 단계가 공동 학습을 위해 학습률을 기본값으로 점진적으로 회복시킨다.

표 9는 벤치마크별 하이퍼파라미터를 요약한다. 명료성을 위해, Abs EEF는 절대 end-effector 위치 제어 인터페이스를 의미하며, Rel XYZ + Abs Rotation은 상대 데카르트 병진(translation)과 절대 회전의 결합을 가리킨다. 모든 회전은 6D 표현으로 매개변수화되고, gripper 상태는 이진화되어 sigmoid 활성화를 통해 예측된다. 사전학습된 backbone으로부터의 지식 전이를 극대화하기 위해, 우리는 대부분의 하류 벤치마크에서 정렬된 action 표현(Abs EEF)을 채택한다. 그러나 시각 변이에 대한 견고성을 시험하기 위해 카메라 설정이 의도적으로 변경된 Simpler-Google 벤치마크에서는, 절대 매개변수화가 지각의 도메인 이동에 민감하므로 Rel XYZ + Abs Rotation 제어 인터페이스를 채택한다.

부록 I. 예비 실험을 위한 학습 세부 사항

본 절에서 우리는 예비 실험에 대한 추가 세부 사항을 제공한다. 우리는 vision-language encoder로 Florence-Base를 채택하고, 비교 가능성을 보장하기 위해 backbone을 표준 DiT-Base(12개 Transformer layer, hidden size 768, AdaLN conditioning 포함)로 구성한다. 학습은 8개 NVIDIA A100 GPU에서 전역 배치 크기 256으로 200K iteration 동안, 선별된 이질적 데이터 혼합에서 수행된다. 별도로 명시하지 않는 한, 나머지 모든 설정(optimizer, 가중치 감쇠, 증강, 셔플링 전략)은 부록 G에 서술된 사전학습 설정과 일관되게 유지된다. 아래에서 우리는 기준선 방법들에 대한 추가 구현 세부 사항을 제공한다.

HPT 스타일 방법. 선행 연구를 따라, 우리는 도메인 특화 관측을 DiT decoder에 입력하기 전에 공유 표현 공간으로 매핑하는, cross-attention 기반 resampler를 구현한다. 각 도메인에는 자체 resampler와 전용 action head가 할당되는 한편, 핵심 Transformer backbone은 모든 도메인에 걸쳐 공유된 채로 유지된다. 이 설계는 추론 backbone을 일반적으로 유지하면서 관측 이질성을 완화하는 것을 목표로 한다.

언어 prompt. 이 설정에서 우리는 각 도메인의 하드웨어 구성과 카메라 설정을 인코딩하는 embodiment 인식 텍스트 서술을 제공한다. 이 서술들은 과제 지시와 연결되어 Florence-Base encoder로 처리되며, 모델이 embodiment별 변이에 명시적으로 주의를 기울일 수 있게 한다. 표 10은 도메인 전반에 사용된 언어 prompt 템플릿을 나열한다.

부록 J. 실세계 실험의 평가 세부 사항

우리는 실세계 평가 설정에 대한 상세한 서술을 제공한다. 우리는 X-VLA-0.9B를 세 가지 서로 다른 로봇 embodiment에 적응시키며, 각각은 모델 적응력의 서로 다른 측면을 검증하도록 선택되었다.

WidowX — pick-and-place 실험용. 구체적으로, BridgeData에서 finetuning된 X-VLA-0.9B가 소형(compact) 플랫폼에서 견고한 조작을 수행하는 능력을 평가하기 위해 직접 배포된다. 우리는 그림 13에 예시된 것처럼 실세계 설정에서 조작 성능과 언어 지시 따르기(instruction following)를 모두 평가하는 포괄적 평가를 수행하며, 각 과제는 10회 평가된다.

AgileX — dexterous 조작 과제용. 부록 F에서 논의한 것처럼, 이 설정은 wrist-mounted 카메라를 갖춘 양팔 플랫폼에서 dexterous하고 세밀한 제어를 시험하도록 설계되었다.

AIRBOT — 파라미터 효율적 finetuning 실험용. AIRBOT은 사전학습 중 보지 못한 것이다. 우리는 천 집기(cloth-picking) 과제를 위해 단 200개의 시연만 특별히 수집하여, 도전적인 저자원(low-resource) 설정으로 만든다. 이 실험은 엄격한 데이터·자원 제약 하에서 우리 2단계 적응 절차의 적응력을 부각시킨다.

그림 14는 이 실험들의 하드웨어 설정을 보여준다. 각 embodiment는 서로 다른 카메라 구성을 갖추어, 우리가 검증을 위한 이질적 배포 환경을 구성할 수 있게 한다.

부록 K. 실세계 실험 기준선의 학습 세부 사항

본 절에서 우리는 실세계 기준선의 학습 세부 사항을 제공한다.

천 접기 과제의 π0는 부록 F에 서술된 Soft-Fold 데이터셋을 사용하여 공식 base π0 모델로부터 finetuning된다. 모델은 4개 A100 GPU에서 총 배치 크기 32로 학습되며, 150,000 gradient step을 완료하는 데 약 60시간이 소요된다.

PEFT 실험의 π0는 공식 LoRA 구성을 사용하여 공식 π0 base 모델로부터 finetuning된다. 우리는 PaliGemma-2B VLM 내의 attention 및 FFN 모듈 모두에 rank 16, α=16의 LoRA를 적용한다. action expert의 경우 rank 32, α=32를 사용한다. 학습은 4개 A800 GPU에서 총 배치 크기 32로 수행되며, 30,000 gradient step을 완료하는 데 약 7시간이 소요된다.

천 접기 과제의 ACT는 부록 F에 서술된 Soft-Fold 데이터셋을 사용하여 처음부터 학습된다. 모델은 8개 A100 GPU에서 총 배치 크기 256으로 학습된다. ACT의 모델 용량은 X-VLA-0.9B나 π0 같은 대형 모델만큼 높지 않으므로, 우리는 더 나은 학습을 위해 ACT를 약 1M gradient step 학습시킨다.

부록 L. 자율주행 시뮬레이션 벤치마크의 평가 세부 사항

우리는 대규모 실세계 자율주행 벤치마크 NAVSIM에서 폐쇄 루프(closed-loop) 평가를 사용하여 우리 방법을 평가한다. 공식 평가 프로토콜을 따라, 우리는 PDM score(높을수록 성능이 좋음)를 보고하는데, 이는 다섯 가지 핵심 지표를 집계한다: NC(무충돌률, no-collision rate), DAC(주행 가능 영역 준수, drivable area compliance), TTC(충돌 시간 안전, time-to-collision safety), Comfort(가속도/저크 제약), EP(자차 진행, ego progress). 모든 방법은 공식 폐쇄 루프 시뮬레이터 하에서 시험되며, 결과는 공개 테스트 분할에 대해 평균낸다. end-to-end VLA 모델로서, 우리 방법은 자율주행을 위해 설계된 특화 방법들을 능가하는 우수한 성능을 달성하며, 상세 점수는 표 11에 보고한다.

부록 N. 한계 및 향후 과제(Limitations and future works)

본 절에서 우리는 연구의 한계를 논의하고 향후 연구를 위한 잠재적 방향을 개괄한다.

더 넓은 데이터·모델 크기로의 X-VLA 확장. X-VLA-0.9B는 강한 성능을 달성하지만, 그 규모는 vision-language 및 언어 영역의 대형 foundation model에 비하면 여전히 소박하다. 이 한계는 주로 연산 제약과 고품질 로봇 데이터의 제한된 가용성에서 기인한다. 오픈소스 데이터셋을 수집·선별하려는 우리의 노력에도 불구하고, 현재 로봇 코퍼스의 다양성과 규모는 여전히 언어 또는 vision-language 영역의 것에 미치지 못한다. backbone을 확장하거나 더 강한 사전학습 VLM을 활용하여 X-VLA를 더 큰 용량으로 확장하고, 더 넓고 다양한 로봇 데이터셋으로 학습하면 일반화와 견고성을 한층 향상시킬 수 있다. 이러한 확장은 또한 VLA 모델의 확장 법칙(scaling law)과 embodiment별 변이가 모델 용량과 어떻게 상호작용하는지에 관한 열린 질문을 제기한다.

대규모 로봇 사전학습을 위한 지도 신호 강화. 데이터 소스 전반의 이질성을 완화하고 일반화된 지식 학습을 위해 action space를 정렬하려는 우리의 노력에도 불구하고, 저차원 action label이 제공하는 지도는 정보 내용 면에서 본질적으로 제한적이다. 이러한 label은 직접 제어에는 필수적이지만, 기저의 과제 구조에 대한 좁은 관점만을 포착하며 고수준 추론, 의도, 다단계 의존성을 전달하지 못하는 경우가 많다. 본 연구에서 우리는 단순한 시간적 downsampling 전략이 action 의도를 추상화하여 더 효율적인 사전학습을 촉진할 수 있음을 보인다. 그러나 이러한 휴리스틱은 지도를 근본적으로 풍부하게 하지는 못하므로 문제를 부분적으로만 다룬다. 향후 방향에는 3D 공간 추론 단서, 물리 동역학, 중간 하위 목표(subgoal) 주석 같은 더 풍부한 지도 신호를 통합하는 것이 포함된다. 또 다른 유망한 길은 원시 입력 스트림으로부터의 자기지도(self-supervised) 목적을 활용하여 희소한 action label을 보완함으로써, 이질적 실세계 로봇 설정에서 표현 학습을 강화하고 확장성을 개선하는 것이다.

하류 과제에 매끄럽게 배포되는 범용 모델을 향하여. 우리의 X-VLA는 다양한 하류 과제에서 우수한 성능을 보이며, finetuning 하에서 강한 적응력과 효율적 특화를 나타낸다. 그러나 추가 엔지니어링이나 재학습 없이 임의의 하류 과제에 매끄럽게 배포될 수 있는 진정한 범용 embodied 모델이라는 비전을 실현하는 것은 여전히 열린 난제이다. 현재 배포는 여전히 embodiment별 적응에 의존하며, 전형적으로 사후 학습(post-training)을 위한 소수의 시연 수집을 수반한다. 이러한 전략들은 완전 재학습에 비하면 경량이지만, 그럼에도 오버헤드를 도입하고 모델이 실세계 응용에서 진정한 plug-and-play 해법으로 기능하는 것을 막는다. 나아가, embodiment별 데이터에 대한 의존은 고품질 시연이 희소하거나 비싸거나 수집에 위험이 따르는 플랫폼으로 확장할 때 문제가 된다. 따라서 향후 연구는 매끄러운 배포에 더 가까워지는 접근에 초점을 두어야 한다. 본 논문의 실증적 발견에 근거하면, 유망한 방향 하나는 통합된 embodiment 표현을 탐구하는 것이다: 명시적인 embodiment 무관 추상화(예: 보편적 운동학 서술자, 물리 정보 prior)를 통합하여 과제 특화 적응에 대한 의존을 줄이는 것이다.
