## 번역·조판 원칙

초록부터 결론, 부록 A·B까지 active source를 생략 없이 번역했다. 참고문헌은 원문 번호 순서와 영문 제목을 유지했다. 6개 그림은 arXiv source-native PDF/PNG에서 고해상도 raster로 변환했고, 3개 표는 HTML 표로 재구성했으며, 9개 수식은 build-time MathML로 조판했다. 프로젝트 페이지의 영상 4건은 로컬 사본·썸네일·원본 URL을 함께 보존했다.
