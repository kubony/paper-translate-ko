초록

대규모 Vision-Language-Action(VLA) 모델의 발전은 language-guided task 실행과 보지 못한 scenario에 대한 generalization 측면에서 robot manipulation을 크게 개선했다. Pretrained 대규모 Vision-Language Model(VLM)에서 적응한 기존 VLA는 유망한 generalizability를 보였지만, 서로 다른 환경에서 task 성공률이 낮다는 점에서 알 수 있듯 task 성능은 여전히 만족스럽지 못하다.

본 논문은 VLM에서 파생된 새로운 고급 VLA architecture를 제시한다. 단순한 action quantization으로 VLM을 action prediction에 직접 전용하던 선행 연구와 달리, VLM 출력에 조건화된 전문 action module을 갖는 componentized VLA architecture를 제안한다. Action module의 설계를 체계적으로 연구하고, action sequence modeling에 Diffusion Action Transformer를 사용하면 성능이 크게 향상되며 scaling 거동도 우수함을 보인다. 또한 다양한 설계의 모델 효용을 평가하기 위해 포괄적인 실험과 ablation study를 수행한다.

Simulation과 real world의 다섯 robot embodiment에서 평가한 결과, 본 모델은 task 성능에서 기존 VLA를 크게 능가할 뿐 아니라 새 robot에 놀랍도록 잘 적응하고 보지 못한 object와 background에도 generalize한다. 크기가 비슷한 7B OpenVLA보다 simulation 평균 성공률은 35% 넘게, 실제 robot 실험에서는 55% 넘게 높다. 또한 55B 대형 RT-2-X보다 simulation 절대 성공률이 18% 높다. Code와 model은 project page에서 제공한다.

1. 서론

최근 visual capability를 갖춘 robot control model에 대한 관심이 급증했다. 그중에서도 대규모 VLA의 발전은 특히 유망하다. 이는 robot이 natural-language instruction에 따라 복잡한 task를 수행하고, training distribution에서 벗어난 object나 environment도 잠재적으로 다룰 수 있게 한다. 또한 finetuning을 통해 새로운 task와 embodiment에 빠르게 적응한다.

대규모 VLA의 두드러진 generalization capability는 상당한 model size와 기반이 되는 강력한 VLM 양쪽에서 비롯된다. 이러한 VLM은 보통 Internet-scale image-text pair로 pretraining되며, 새로운 object와 의미적으로 다양한 instruction에 대한 VLA generalization을 높이는 데 핵심 역할을 한다.

기존 대규모 VLA는 흔히 VLM을 단순한 방식으로 action prediction에 적응시키며, 이는 task 성능을 가로막는 여러 문제를 낳는다. 예를 들어 RT-2와 OpenVLA는 VLM의 next-token prediction 방식에 맞추어 robot action의 continuous spectrum을 discrete bin으로 직접 quantize한다. 그러나 image나 audio용 정교한 tokenizer와 달리 이런 단순 quantization은 action learning을 어렵게 하고 action precision을 제한한다. RoboFlamingo는 LSTM 같은 action head를 덧붙여 VLM 출력을 action으로 변환한다. 하지만 regression 기반 learning으로 옮겨 가면 action의 probabilistic하고 multimodal한 성질, 즉 하나의 task를 완수하는 여러 가능한 trajectory가 존재한다는 사실을 간과한다.

본 논문은 VLM에서 파생한 새로운 VLA architecture를 제안한다. Pretrained VLM을 action prediction에 전용하지 않고, VLM이 추출한 cognitive information으로 전문 action module의 action prediction 과정을 안내한다. Continuous하고 multimodal하며 시간적으로 상관되고 높은 precision이 필요한 action signal의 본질적 특성을 처리하기 위해, attention mechanism으로 VLM 출력에 사전 조건화한 고급 diffusion-based transformer(DiT)를 action module로 채택한다.

설계의 직관은 “cognition” capability와 “action” capability의 분리이다. 대규모 VLM은 방대한 text와 image에서 학습한 폭넓은 visual·semantic knowledge를 축적하지만, 그 cognitive capability 및 출력 language modality와 dense robot action 사이에는 근본적인 간극이 있다. VLM을 직접 전용하는 대신 dedicated action module을 갖는 componentized VLA 설계를 지지한다. 인간 뇌에도 visual cortex, language-relevant cortex, motor cortex가 있고 마지막 것은 신체 운동 제어에 전담된다는 점은 흥미로운 유추이다. Action module은 cognition model 출력을 precondition으로 받아 action signal modeling에 특화된다. End-to-end training 또는 finetuning으로 cognition과 action capability를 협응시킨다. 따라서 이 접근을 CogACT라 명명한다.

Action module의 여러 backbone architecture와 model size scalability를 체계적으로 연구해 주목할 통찰을 얻었다. Diffusion transformer를 이용한 sequential modeling은 single-step action prediction을 크게 능가한다. 더 중요하게는 Diffusion Transformer action module의 유리한 scaling 거동을 확인했다. 7B VLM base에 비하면 작은 수억 개 parameter를 추가하는 것만으로 성능이 크게 향상된다. 이는 전문 action module의 장점과 더 효율적인 VLA scaling 방식을 시사한다.

Action module 설계 연구 외에도 독립적으로 흥미로운 알고리즘을 제시한다. 과거 action prediction을 adaptive하게 융합하는 Adaptive Action Ensemble(AAE)은 눈에 띄는 성능 향상을 가져온다. Open X-Embodiment dataset으로 VLA를 학습하고 simulation과 real-robot benchmark에서 평가한다. 포괄적인 평가와 비교 결과 본 모델은 기존 VLA를 큰 폭으로 능가한다.

본 연구의 기여

  • Action diffusion process를 대규모 VLA model에 통합한다.
  • Componentized VLA architecture를 제안하고 대형 action module의 설계와 scaling 거동을 연구한다. 가장 큰 action DiT는 300M parameter이다. 대형 LLM/VLM과 비교하면 작아 보일 수 있으나 여기서 다루는 7D robot action vector space를 감안하면 크다.
  • 단순하지만 temporal fusion에 효과적인 adaptive action ensemble algorithm을 제안한다.
  • 이전 VLA보다 훨씬 높은 성능을 달성하며 새 robot과 task에 빠르게 적응하고 보지 못한 object와 background에 효과적으로 generalize한다. Code와 model을 모두 공개한다.

2. 관련 연구

Vision-Language-Action 모델

LLM과 VLM의 성공은 VLM capability를 action generation 통합으로 확장한 VLA 개발을 촉진했다. RoboFlamingo는 OpenFlamingo에 action-prediction head network를 넣고 MSE loss로 최적화한다. RT-2는 7D action을 discrete token으로 tokenize하고 VLM PaLI-X가 language token처럼 autoregressive하게 예측하게 한다. OpenVLA도 유사하게 action을 tokenize하여 Prismatic VLM을 Open X-Embodiment dataset으로 학습한다. 이 모델들은 VLM capability 덕분에 유망한 성능과 인상적인 generalization을 보이지만, action이 본질적으로 continuous하고 temporal하여 language와 다른 modality라는 점을 고려하지 않는다. 또 다른 방법군은 pretrained VLM 없이 large-scale video generative pretraining을 사용해 visual robot manipulation learning을 개선하며 유망한 결과를 냈다.

대형 Action 모델

본 연구와 동시에 generalist robot을 위한 large action model을 탐색한 시도가 있다. Diffusion Transformer Policy는 221M diffusion transformer를, RDT-1B는 action model을 1B까지 확장했다. 둘 다 pretrained·frozen vision/language encoder로 instruction과 image를 처리하고, VLA data로 action model이 입력을 통합해 action을 예측하도록 학습한다. 이와 달리 이들은 Internet-scale vision-language aligned data로 pretraining된 강력한 VLM의 generalization 및 instruction-following capability를 활용하지 못한다.

Diffusion 기반 Robot Policy

최근 연구는 robot action modeling의 새로운 방식으로 diffusion model을 도입했다. Diffusion policy는 robot action distribution의 multi-mode 성질과 주어진 task를 완수할 다양한 feasible trajectory를 포착하는 강한 능력을 보였다. Octo는 transformer backbone에 3M의 작은 diffusion head를 보태 robot마다 action output을 적응시킨다. 그러나 작은 head는 정밀한 action distribution 포착에 부족하고, 전체 접근도 web-scale data로 pretraining된 강한 VLM의 이점을 얻지 못한다. 반면 본 연구는 Diffusion Transformer architecture의 크고 전담된 action module—단순한 “head”가 아님—을 연구하며, 강한 generalization capability를 가진 VLM foundation model에서 파생한 대규모 VLA에 관심을 둔다.

3. 방법

문제 정식화

목표는 서로 다른 robot이 visual observation과 language instruction을 받으면서 다양한 task를 물리적으로 실행하게 하는 VLA model을 개발하는 것이다. 시간 t의 language instruction l과 visual observation ot가 주어지면 model π는 desired task를 실행할 temporal action sequence를 예측한다.

π: (l, oₜ) → (aₜ, aₜ₊₁, …, aₜ₊N).                         (1)

일반적으로 at는 서로 다른 control mode와 end-effector의 다양한 robot action을 나타낼 수 있지만, 본 연구는 7 degree of freedom(DoF) gripper action space를 고려한다.

aₜ = [Δx, Δy, Δz, Δφ, Δθ, Δψ, g].                        (2)

Δx, Δy, Δz는 end effector의 상대 translation offset, Δφ, Δθ, Δψ는 rotation change이며, g∈{0,1}은 gripper open/close state이다.

3.1 Vision 및 Language Module

Vision/language module은 OpenVLA와 유사하게 총 약 7B parameter의 기존 Prismatic VLM에서 적응한다.

Vision Module

Raw image input을 perceptual token 집합으로 처리한다. Internet-scale image data로 pretrained된 강력한 vision transformer DINOv2와 SigLIP으로 관찰의 풍부한 visual feature와 포괄적 semantic understanding을 포착한다. 각 timestep t에서 image observation oₜ를 두 모델에 넣어 downsampled feature map fₜDINO와 fₜSig를 얻는다. Channel dimension을 따라 concatenate하고 linear projection layer를 거쳐 직렬화하여 길이 NV의 visual perceptual token V={v₁,v₂,…,vNV}를 만든다. Default NV=256이다.

Language Module

Visual information과 language instruction을 통합하고 cognitive reasoning을 수행하며 LLAMA-2를 backbone으로 쓴다. LLAMA-2 tokenizer로 instruction l을 linguistic token T={l₁,l₂,…,lNT}로 변환한다. 이 token들을 visual token V 및 추가 learnable cognition token c 하나와 concatenate한 뒤 causal attention으로 처리한다. 그 결과 cognition token에 대응하는 output hidden feature fₜc는 현재 task에서 실행할 action을 결정하는 통합 정보를 encode한다. 바로 이 cognition feature가 뒤따르는 action module이 desired action을 해석하고 도출하는 condition이 된다.

3.2 Diffusion Action Module

Action module은 cognition feature를 input condition으로 받아 식 (1),(2)의 action series를 생성한다. 실제 physical action은 continuous하고 흔히 multi-modal이므로 diffusion modeling process로 예측한다. 복잡하고 temporally correlated한 action을 modeling하기 위해 강력한 Diffusion Transformer(DiT)를 action decoding backbone으로 사용한다.

구체적으로 action module은 cognition feature fₜc와 noisy action series (aₜⁱ,…,aₜ₊Nⁱ)를 입력으로 받으며 i는 현재 denoising step이다. 여러 denoising step으로 최종 action을 예측한다. Cognition feature와 noisy action은 transformer block의 input token이고 step information i는 sinusoidal positional encoding으로 cognition feature에 더한다. Current action뿐 아니라 여러 future action도 예측하도록 강제한다. 이는 timestep마다 predicted action의 전반적 smoothness를 높이고 task 성공률을 높인다. 실제로 N=15를 default로 하여 action module context length는 N+2=17이다. 따라서 diffusion process는 매우 효율적이고 전체 framework에 큰 computational cost를 더하지 않는다.

3.3 학습 목적함수

Vision, language, action module을 모두 end-to-end로 train/finetune하며, action module의 predicted noise와 ground-truth noise 사이 MSE를 최소화한다.

L_MSE = E_{ε~N(0,1), i} || ε̂ⁱ − ε ||₂.                    (3)

ε̂ⁱ는 i번째 denoising step의 noisy action sequence에 대한 predicted noise이고 ε는 대응하는 ground truth이다.

3.4 Adaptive Action Ensemble

Inference에서 모델은 여러 timestep의 action을 예측한다. 단순한 방법은 현재 observation oₜ에 근거해 이들을 연속 실행하는 Action Chunking이다. 그러나 매 timestep의 visual information을 충분히 활용하지 못해 motion이 덜컥거릴 수 있다. Current timestep action aₜ만 실행해도 trajectory가 덜 smooth하고 성능이 낮아진다.

ACT의 temporal ensemble은 현재와 과거 prediction에서 현재 timestep용으로 예측한 action들을 preset aggregation weight로 결합한다. 그러나 feasible action은 서로 다른 mode에 속할 수 있고, 단순 aggregation은 어느 mode에도 맞지 않는 suboptimal action을 낳는다.

이에 aggregation할 action 사이 similarity를 고려하여 다른 mode action의 부당한 결합을 피하는 adaptive ensemble을 제안한다. aₜ|oₜ를 현재 observation에 따른 현재 timestep action prediction, {aₜ|oₜ₋K,…,aₜ|oₜ₋₁}을 historical observation에 기반한 해당 action prediction이라 하면 최종 action은 다음과 같다.

âₜ = Σ(k=0…K) wᵃᵈᵃ_k · (aₜ | oₜ₋k).                      (4)

wᵃᵈᵃk는 current prediction과 더 비슷한 past prediction에 더 큰 중요도를 주는 adaptive scalar이다.

wᵃᵈᵃ_k = exp(α · ⟨aₜ|oₜ, aₜ|oₜ₋k⟩).                    (5)

⟨·,·⟩는 두 action의 cosine similarity이며 α=0.1이다. Past prediction은 cache할 수 있어 추가 inference cost가 거의 없으면서 task 성공률을 효과적으로 높인다.

4. 실험

Training Dataset 및 구현 세부사항

주 training dataset으로 Open X-Embodiment(OXE)를 쓴다. 60개 dataset에서 수집한 실제 robot trajectory 100만 개 이상과 22개 robot embodiment를 포함한다. Octo와 OpenVLA와 유사한 2,250만 frame subset으로 학습한다.

Batch size 256, sample당 diffusion step 8로 학습하고 pretrained vision/language weight는 OpenVLA에서 초기화한다. DINOv2와 SigLIP, LLAMA-2, action module을 모두 end-to-end로 학습하며 constant learning rate 2×10⁻⁵로 135K iteration 이상 수행한다. NVIDIA A100 16장과 PyTorch FSDP로 약 5일 걸린다. Default action model은 DiT-Base이다. Ensemble window K는 frame당 이동거리와 반비례하며 robot motion speed와 observation frequency로 유추한다. 실제로 training action standard deviation을 이용해 Google Robot RT-1 dataset에는 K=2, WidowX BridgeDataV2에는 K=7을 쓴다.

4.1 Simulation 평가

환경. 학습 후 SIMPLER에서 평가한다. Google robot과 WidowX robot 같은 실제 조건을 충실히 복제해 real-to-sim control 및 visual gap을 줄이는 platform이다. 여러 VLA test에서 SIMPLER 성능과 real-world 결과가 강하게 상관했다.

설정. Visual Matching은 simulation/real 차이를 최소화하고, Variant Aggregations는 background, lighting, distractor, table texture를 바꾼다. Google robot은 양쪽 설정에서 ① Coke can pick, ② move near, ③ drawer open/close, ④ top drawer를 열고 apple 놓기를 수행한다. WidowX는 Visual Matching에서 ① spoon을 towel 위에, ② carrot을 plate 위에, ③ green block을 yellow block 위에 쌓기, ④ eggplant를 yellow basket에 넣기를 수행한다. Metric은 success rate이다.

5. 결론

Action modeling에 특별히 초점을 맞춘 대규모 VLA를 제시했다. Vision-language model을 action prediction에 단순 적응시키는 기존 VLA와 달리 CogACT는 cognition과 action capability를 분리하고, 고급 Diffusion Transformer를 dedicated action module로 사용한다. 이는 robot action의 continuous, multimodal, temporally correlated한 성질을 효과적으로 다루어 성능과 generalization을 크게 향상한다. 대규모 VLM이 cognitive foundation을 맡고 DiT action module이 정밀한 sequential action prediction을 처리하는 componentized VLA의 이점을 결과가 보여준다. Action module은 소폭의 parameter 증가로 큰 성능 이득을 얻는 유리한 scaling 거동을 보인다. 광범위한 실험에서 기존 VLA보다 task 성능이 크게 높고 unseen object와 background에 뛰어난 generalization capability를 보였다.

A.2 실제 Robot 실험 Finetuning Data

Realman setup

Hardware는 그림 I과 같다. 어깨에 각각 7 DoF인 Realman arm 두 개를 단 robot을 만들었다. Left arm에 1-DoF gripper를 연결하고 모든 실험에서 이 arm만 쓴다. Intel RealSense camera로 RGB image를 포착하고 camera 이동 때마다 hand-eye calibration한다. Training action은 모두 camera coordinate system으로, model-generated action은 robot coordinate system으로 변환한다. Viewpoint generalization 평가를 위해 실험 전 camera를 무작위 이동한다. Mobile base도 각 실험 전에 무작위 재배치한다.

Franka setup

7 DoF arm을 table에 단단히 고정하고 오른쪽 Kinect DK camera로 RGB image를 포착한다. 전체 pipeline의 action은 robot coordinate system을 쓴다.

Data 수집

Meta Quest 2 touch controller로 두 robot을 teleoperate하여 demonstration을 수집한다. Controller translation/rotation을 gripper 3D motion에 mapping하고 button으로 gripper open/close를 제어한다. Realman은 30 Hz, Franka는 5~6 Hz로 video frame을 기록한다. Full video에서 segment를 수작업 trim하고 task를 설명하는 language instruction을 붙인다.

전처리

두 finetuning dataset 모두 OXE format을 따른다. Image를 crop/resize해 224×224로 만들고 action을 relative translation offset과 rotation change로 변환한다. Rotation change는 rotation matrix에서 계산한 뒤 training용 Euler angle로 바꾼다. Training에서 Realman data는 frame 간격 0.2초인 5 Hz로 무작위 subsample한다. Franka data는 그대로 사용한다.

A.3 Data Augmentation 및 Normalization

Random crop, brightness, contrast, saturation, hue augmentation을 사용한다. Demonstration 길이를 넘는 future action은 stationary action으로 padding한다. Action은 [-1,1]로 normalize한다. Gaussian N(0,1) normalization도 시도했지만 개선이 없었다.

B. 평가 세부사항

B.1 Simulation 평가

연구마다 hardware, environment, task가 달라 robot manipulation 평가가 어렵다. 표준화한 real-world setup은 유익하지만 시간과 자원이 많이 든다. SIMPLER는 실제 성능 평가 정확도를 보존하면서 실제 data로 학습한 manipulation policy를 simulation에서 평가하는 system이다. 따라서 재현하기 쉽고 완전히 공정한 framework로 SIMPLER를 사용한다.

Task 정의

SIMPLER가 제공하는 모든 variant를 쓴다. Google setup은 ① “pick Coke can”, ② “move {obj1} near {obj2}”, ③ “(open/close) (top/middle/bottom) drawer”, ④ “open top drawer; place apple into top drawer”이다. WidowX는 ① “put the spoon on the towel”, ② “put carrot on plate”, ③ “stack the green block on the yellow block”, ④ “put eggplant into yellow basket”이다. Google은 VM과 VA, WidowX는 VM만 제공한다. WidowX 원 trial이 task당 24개로 적어 각 trial을 다른 random seed로 5회 반복해 통계적 유의성을 높인다.

구현 세부사항

모든 simulation 평가는 NVIDIA A6000 한 장 또는 A100 한 장에서 한다. Inference에는 sampling step 10인 DDIM과 coefficient 1.5인 classifier-free guidance(CFG)를 사용한다. 모든 모델에 α=0.1인 unified adaptive action ensemble을 적용한다. Dataset별 control frequency와 robot speed가 다르므로 window K도 adaptive해야 한다. Dataset 사이에서 timestep당 6D action의 평균 standard deviation(std)과 K의 곱이 일정하도록 K를 고른다.

C = K × std,   C = 0.2.                                      (I)

C는 최근 K step 동안 robot이 이동·회전한 거리/각도를 뜻하며 모든 실험에서 0.2로 두고 K를 도출한다.

Google robot의 이전 방법 성공률은 SIMPLER 평가값을 가져오되, 거기에 없던 OpenVLA는 official repository weight로 직접 평가한다. WidowX에서 RT-1-X는 SIMPLER 보고값이고 OpenVLA는 같은 방식으로 평가한다. Octo-Base/Small은 probabilistic sampling 변동성을 줄이기 위해 random seed를 늘려 5회 재시험한다. 본 모델의 모든 configuration도 Octo와 같은 test 수로 평가한다. WidowX RT-2-X는 보고되지 않았고 공개 weight도 없다.
