# 산출물 예시

이 폴더에는 스킬이 실제로 무엇을 만드는지 보여주는 **번역 결과 한 편**이 들어 있다.

- [KOFFVQA — arXiv:2503.23730](./papers/2503.23730_KOFFVQA-Korean-Free-form-VQA-Benchmark/) — 12쪽 · benchmark, VLM, Korean

원본 11쪽이 12쪽으로 재구성됐고, 2단 학술 레이아웃·그림 3개·47개 VLM 평가표가
그대로 남아 있다. 표지 다음의 「번역 메모」에서 `judge model`·`free-form`·
`ground truth` 같은 용어를 어떻게 처리했는지 밝히는 것도 이 스킬의 출력 규약이다.

## 왜 한 편만 있나

번역 산출물은 원문 저작권자가 각각 다르고, 웹 출처 번역은 원문 영상까지 함께
보관해서 한 건이 수 GB가 되기도 한다. 그런 자산은 저장소가 아니라 **각자의**
오브젝트 스토리지에 두는 것이 이 스킬의 정책이다(SKILL.md 「미디어 자산 정책」).
여기에 예시를 잔뜩 쌓으면 저장소를 무겁게 만들면서 특정인의 버킷에 링크가
묶이므로, 레이아웃·표·용어 처리를 확인하기에 충분한 최소한만 둔다.

## 직접 만들면 어디에 쌓이나

스킬을 실행하면 이 폴더와 같은 규칙으로 결과가 쌓인다.

```
artifacts/
  papers/   # arXiv·학회 논문 PDF 번역
  web/      # 기업·연구소 블로그, 챌린지 페이지 등 웹 아티클 1편 번역
  sites/    # 웹사이트 전체(여러 route) 아카이브 번역
```

폴더명 규칙과 폴더 내부 구성은 SKILL.md 「산출물 보관 규칙」을 따른다.
